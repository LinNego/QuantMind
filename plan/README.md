## 2 规则

| # | 规则 |
|---|---|
| 1 | **内容不缩，日历弹性。** 时间是可压缩的，条目不是。 |
| 2 | **先出 v0。** 交付物能看就发，v1 靠修出来，不靠憋出来。 |
| 3 | **不提前给详细计划。** 节点 N 结算通过，才写 N+1。 |
| 4 | **每周留 3 个数字。** 没有数字的一周等于没跑。 |
| 5 | **顺延不删条目。** 没跑完就整体后推；连着两周都推，说明强度定高了，降回 1–2 小时/天。 |

## 3 结算与解锁

**过关** = 三样交付物 + 三个问题答得上 + **一个你自己犯的错**。

- 过关 → 写下一个节点的详细计划，总时长不变。
- 没过 → 只调整当前节点，**不延长总时长**（延了就会一路推到 3 月）。

「一个自己犯的错」这条最硬：能指出来，说明你在判断；指不出来，说明这半个月在收集知识。
