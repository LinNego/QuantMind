| 数据 | 字段 | 口径 |

## 7 常见问题

**Q：为什么 A3 要用不复权？**
前复权的 `close` 被除权因子重算过，而 `amount` 是原始成交额，两者不同口径；不复权的 `close×volume` 才是「真实成交金额（元）」，除以万元单位的 `amount` 才得到 1e4。

**Q：数据没有断层、也没有退市股，是不是数据很干净？**
恰恰相反。没有缺口说明补齐过；没有退市股说明**只含活下来的票**——回测里你永远买不到那些退市前的股票，收益自然虚高。

**Q：回测器为什么那么慢（约 1 分钟）？**
它每次从 parquet 读全市场十年数据建透视表。调试阶段可以用 `--start 20200101` 缩小范围；跑正式结果再放开。

**Q：`out/` 里的文件要提交 git 吗？**
建议提交（这是你的过程证据）。数据本身在 `data/quantdb`，被 `.gitignore` 排除，不要提交。
