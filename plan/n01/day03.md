## 1 先纠正一个直觉（重要）

很多人以为「前复权、后复权、不复权」三种会算出三个不同的收益率。**错**。

设原始价 `raw_t`，累计复权因子 `F_t`（随除权递增）：

- 后复权：`B_t = raw_t · F_t / F_0`
- 前复权：`F_t^p = raw_t · F_t / F_T`（`F_T` 是今天的因子）

同一条 `lookback` 日收益：

```
前复权: (raw_t·F_t)/(raw_{t-k}·F_{t-k}) · (F_T/F_T)
后复权: (raw_t·F_t)/(raw_{t-k}·F_{t-k}) · (F_0/F_0)
```

**完全相等**——两者只差一个与时间无关的常数缩放。所以「复权三兄弟」的收益率差异，实际只有一组：**复权（前=后） vs 不复权**。真实的坑在另外两处：价格**水平**被缩放（影响阈值类规则）、以及口径混用（复权价配原始成交额）。

## 2 实测：复权 vs 不复权差多少

```bash
cd /root/QuantMind && source .venv/bin/activate
python - <<'PY'
import sys; sys.path.insert(0, 'plan/n01/tools')
import qm, pandas as pd

rows = []
for code in ['600036.SH', '000858.SZ', '300750.SZ']:
    def r20(adj):
        s = qm.kline(adj=adj, symbols=[code], columns=['time', 'close']).set_index('time')['close']
        return s / s.shift(20) - 1
    f, b, u = r20('forward'), r20('backward'), r20('unadjusted')
    c = pd.DataFrame({'forward': f, 'backward': b, 'unadjusted': u}).dropna()
    c['f_minus_b'] = c.forward - c.backward
    c['f_minus_u'] = c.forward - c.unadjusted
    i = c.f_minus_u.abs().idxmax()
    print(f"{code}  前-后最大差 {c.f_minus_b.abs().max()*1e4:.1f}bp   "
          f"前-不复权最大差 {c.f_minus_u.abs().max()*1e4:.1f}bp @ {i.date()}  "
          f"(前 {c.forward.loc[i]*100:+.2f}% / 不复权 {c.unadjusted.loc[i]*100:+.2f}%)")
    c.to_csv(f'plan/n01/out/a4_{code}.csv')
    rows.append(c)
PY
```

## 3 那「未来信息」到底在哪？

不在收益率里，在**价格水平**里。

前复权的历史价会随**每一次未来的除权**被重写：2016 年的前复权价，今天看和当年看不是同一个数。所以：

- 用复权价算**收益率**：前复权和后复权等价，都不引入未来信息（因子同时作用于分子分母）；
- 用复权价做**价格水平规则**：比如「股价 < 5 元不买」「昨日收盘 ≥ 涨停价」「按价格分位数分组」——用前复权价会把 2016 年之后的除权信息带进 2016 年的判断，这才是未来函数；
- 更隐蔽的：**复权价 × 原始成交额**（A3 已经踩过，比值从 1e4 掉到 5,800）。

D1 里写口径时，建议固定成：

> 收益/净值：`daily_forward` 收益（等价 `daily_backward`）；
> 价格类阈值（涨跌停、低价过滤）：`daily_unadjusted` + 当日复权因子现场换算，不用前复权。

- 不复权的除权跳空会让「跌得多的票」看起来更便宜，20 日反转信号如果用不复权价，会系统性买入刚除权的票；
