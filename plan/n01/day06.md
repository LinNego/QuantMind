## 2 算「成本吃掉多少」——先算再跑

年换手 `T`（单边）意味着一年买卖总成交额约 `2T` 倍净值，成本拖累 ≈ `2T × cost`。

- 本例 `T ≈ 10.6`，所以 **每 10bp 单边成本 ≈ 2.1%/年**；
- 从 -0.34% 起，10bp 后约 **-2.4%/年**，30bp 后约 **-6.7%/年**。

跑完对照：实际值应该接近这个估算（差 0.5 个点以内）。差太多说明成交假设或换手统计有问题。

## 3 找「年化归零」的档位

策略在 0 成本时年化已经是负的，所以严格说**任何正成本都让它更差、没有归零点**。这本身就是答案的一部分，但要写清：

- 若把「归零」定义为「年化 = 0」，那么这份策略在 **负成本**（即需要返佣/收益增强）才可能归零；
- 更有意义的问法：**年化从 -0.34% 掉到 -5% 需要多少成本？** 按 2.1%/10bp 推，约 **22bp 单边**；
- 换个策略（比如手续费更低的 ETF 轮动、或年换手 2x 的策略），同一个公式算出来的归零成本会完全不同——公式比数字重要。

用代码验证一下：

```bash
python plan/n01/tools/backtest.py --cost 0.0022 --out plan/n01/out/b3_nav_22bp.csv
```
