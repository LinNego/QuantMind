## 2 填表（每个差值都要有符号）

| 假设 | 年化 | 相对基准差 |
|---|---|---|
| 基准：T+1，10bp | | — |
| 改「当日收盘成交」 | | +? bp |
| 加「涨停不买」 | | −? bp |
| 加「停牌不交易」 | | −? bp |

**怎么读**

- 「当日收盘成交」通常是**最乐观**的一档：信号当日收盘就能成交，实际做不到；它比基准高出的部分，就是「偷跑」的收益；
- 「涨停不买」影响一般不大（反转选的是跌得多的票，次日很少涨停），但**方向必须正确**：加了规则年化不能变高；
- 「停牌不交易」更多影响极端小票，样本内影响小，但装上它才接近实盘。

## 3 一个容易忽略的点

回测器里「不可交易的票，权重留现金」——这是**保守**处理（没有把钱硬塞给别的票）。如果实盘你把没买到的钱分给其他票，结果会再偏一点。报告里写清你采用的是哪种。
