## 2 下午：B1 手算成本（约 1.5h）

规则（A 股现实口径，写清出处，别用「大概」）：

- 佣金：万 2.5，**单笔最低 5 元**（买卖都收）
- 印花税：**卖出单边 0.05%**（2023-08 后为 0.05%）
- 过户费：0.001%，**双边**
- 滑点：先估 **0.05%**（写「估的」）

### 2.1 手算表（先自己算，再对下面的参考答案）

| 资金 | 方向 | 佣金 | 印花 | 过户 | 滑点 | 合计（元） | 成本率 |
|---|---|---|---|---|---|---|---|
| 100,000 | 买 | 25.00 | 0 | 1.00 | 50.00 | 76.00 | **0.076%** |
| 100,000 | 卖 | 25.00 | 50.00 | 1.00 | 50.00 | 126.00 | **0.126%** |
| 10,000 | 买 | 5.00 | 0 | 0.10 | 5.00 | 10.10 | **0.101%** |
| 10,000 | 卖 | 5.00 | 5.00 | 0.10 | 5.00 | 15.10 | **0.151%** |

**关键差别**：佣金最低 5 元，在 10 万上是 0.005%，在 1 万上是 **0.05%** —— 凭空多出 4.5bp。所以小资金「看着收益率更高」，是因为固定成本被摊薄得少。

### 2.2 用代码复核一遍（避免手算错）

```bash
cd /root/QuantMind && source .venv/bin/activate
python - <<'PY'
def cost(amount, buy=True, comm_rate=2.5/1e4, stamp=0.0005, transfer=1e-5, slip=0.0005):
    comm = max(amount * comm_rate, 5.0)
    fee = comm + amount * transfer + amount * slip
    if not buy:
        fee += amount * stamp
    return fee, fee / amount

for a in (100_000, 10_000):
    for buy in (True, False):
        fee, rate = cost(a, buy)
        print(f"{a:>7,} {'买入' if buy else '卖出'}  费用 {fee:8.2f} 元  成本率 {rate*100:.3f}%")
PY
```

**预期**：与上表一致（10 万买入 76.00 / 0.076%，1 万买入 10.10 / 0.101%）。
