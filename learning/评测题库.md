# 评测题库：24 题，量一量你到哪了

> 用途：**自测 + 给 Agent 当判卷标准**。不是考试，是定位。
> 用法：先自己答一遍（不看手册），再让 Agent 按下面的「判分要点」打分。
> 基线：第 1 周测一次，之后每 4 周重测。

---

## 0 评分规则（0–3 分）

| 分 | 标准 |
|---|---|
| **0** | 空白，或核心概念错 |
| **1** | 关键词对，但不完整、没有数字 |
| **2** | 完整，有数字或例子 |
| **3** | 完整 + 能指出**失效条件/边界**（什么情况下不成立） |

**24 题满分 72。** 参考线：< 30 = L0，30–45 = L1，45–58 = L2，58–66 = L3，> 66 = L4。

---

## 01 市场、成本与数据（4 题）

**1. 前复权 / 后复权 / 不复权分别用在哪？混用会怎样？**
> 判分要点：前复权→收益/因子；不复权→成交价/涨跌停/市值；后复权→长期对比。混用 → 除权日假跳变（3 分要说出 ±30% 级别的假收益）。

**2. 为什么 t 值不能直接用 `ICIR × √2400`？**
> 判分要点：5 日标签重叠 → 相邻 IC 相关 → 有效样本 ≈ 天数/5 → t 虚高约 √5 ≈ 2.2 倍。解法：非重叠采样或 Newey-West。（3 分要说出「虚高多少倍」。）

**3. 一笔 10 万元的买卖，总成本多少？1 万元呢？差在哪？**
> 判分要点：10 万 ≈ 102 元（0.102%）；1 万 ≈ 15.2 元（0.152%）。差在**最低佣金 5 元**——小资金被它收隐形税。（3 分要说出「单笔金额越小，费率越高」。）

**4. 怎么用数据查幸存者偏差？**
> 判分要点：按年统计「上年有、下年无」的股票数；为 0 说明只保留了活下来的；退市股集中在低价/小市值，恰好是微盘策略重仓区。（3 分要说出「对微盘策略影响最大」。）

## 02 因子研究（4 题）

**5. 好因子的五个条件是什么？**
> 判分要点：有逻辑、IC 稳定、分层单调、换手可承受、容量够。（3 分要给出量级：IC ≥ 0.02~0.03、ICIR ≥ 0.2。）

**6. 中性化之后 IC 下降了，为什么反而更可信？**
> 判分要点：原始 IC 里混了行业/市值 beta；中性化只留增量；行业和市值的收益不该算成你的 α。（3 分要说出「降多少算正常」——通常腰斩。）

**7. 分层不单调说明什么？还能用吗？**
> 判分要点：只有尾部有效（极值策略），不能线性加权；可做「只买最高组」或「多空两端」。（3 分要说出「不能再做等权多因子合成」。）

**8. 一票否决的六条是什么？**
> 判分要点：无逻辑、分年符号乱、成本 > 毛收益 1/3、与已有因子相关 > 0.7 且无增量、容量 < 目标资金 3 倍、只在单板块/单年有效。（3 分要能各举一个例子。）

## 03 组合与风险（4 题）

**9. 为什么均值方差优化经常还不如 Top-N 等权？**
> 判分要点：`μ` 估计误差大，优化器重仓噪声；`Σ` 在 N>T 时不可逆；约束过拟合。（3 分要说出「IC 只有 0.03 时，μ 的信噪比极低」。）

**10. N_eff 怎么算？前 5 大权重占 60% 说明什么？**
> 判分要点：`HHI = Σw²`，`N_eff = 1/HHI`；前 5 占 60% → N_eff 可能只有 8，**以为分散了其实没有**。（3 分要说出「和名义持仓数的差距」。）

**11. 归因怎么做？怎么判断 α 显著？**
> 判分要点：Brinson（配置/选择/交互）或回归（市场+规模+价值+动量）；`α` 的 t 值 > 2 且经济上说得通；`R²` 高说明收益大部分被风格解释。（3 分要说出「β 和风格占一半以上是常态」。）

**12. 容量怎么估？微盘为什么只有几百万？**
> 判分要点：`单票容量 = ADV × 参与率（1%~5%）`；`组合容量 = 持仓数 × 单票`；微盘 ADV 小 + 参与率低 → 千万级以内。（3 分要说出「超过容量 1/3，冲击非线性上升」。）

## 04 择时与配置（4 题）

**13. 择时为什么统计上更难？给出样本量算术。**
> 判分要点：选股 2500 个截面 vs 择时 20~50 次状态切换；`√2500=50` vs `√30≈5.5`，功效差约 9 倍。（3 分要说出「非平稳 + 路径依赖」的叠加。）

**14. 择时版收益更低、夏普更高，怎么解释？**
> 判分要点：用收益换稳定性；降低尾部风险；不是免费午餐。（3 分要说出「如果收益也更高，先怀疑未来函数」。）

**15. 波动率目标怎么算？代价是什么？**
> 判分要点：`仓位 = 目标波动 / 已实现波动`，封顶 1；代价是牛市少赚（低波时封顶）、震荡市频繁调仓。（3 分要说出「它降尾部，不增 α」。）

**16. 广度 < 30% 就降仓，是增收益还是降回撤？**
> 判分要点：主要降回撤；广度是风控开关，不是收益引擎；极端值才有效。（3 分要说出「中间区域没有信息」。）

## 05 ML 与 AI（4 题）

**17. 为什么随机切分是数据泄漏？purged CV 解决什么？**
> 判分要点：时间顺序；随机切 → 训练集见过测试期；purged 删除与测试标签重叠的训练样本 + embargo。（3 分要说出「embargo 至少一个标签窗口」。）

**18. 标签重叠怎么影响 t 值？**
> 判分要点：相邻样本共享收益窗口 → 有效样本减少 → t 虚高；解法同第 2 题。（3 分要说出「重叠度 = 标签窗口长度」。）

**19. LLM 和 ML 的分工？LLM 的三条红线？**
> 判分要点：LLM 在 L1 造列，ML 在 L2 排序；红线：evidence 必填、禁止推断、版本入库。（3 分要说出「LLM 直接打分当信号为什么不可审计」。）

**20. 搜了 1000 个因子表达式，怎么防过拟合？**
> 判分要点：真 holdout（最后 2 年不参与搜索）、多重检验校正、相关性去重、经济逻辑筛查、换手/成本筛查、换市场复现。（3 分要说出「搜得越多，最好的那个越可能是噪声」。）

## 06 实盘与赚钱（4 题）

**21. `IR ≈ IC × √BR`：IC 0.05、N_eff 15、月调仓，年化超额多少？**
> 判分要点：`BR = 12×15 = 180`；`IR = 0.05×√180 ≈ 0.67`；× 主动风险 10% ≈ 6.7%；实际打折到 4%~5%。（3 分要说出「提高 BR 比提高 IC 更有效，但换手成本会吃回去」。）

**22. 年化 15% 想年入 20 万，需要多少本金？-25% 回撤是多少钱？**
> 判分要点：≈ 133 万；-25% ≈ -33 万；先问「扛不扛得住绝对值」。（3 分要说出「回撤是入场费，不是故障」。）

**23. kill criteria 至少写哪几条？**
> 判分要点：回撤 > 历史 1.2 倍、滚动 6 月 IC < 0 连续 3 月、跟踪误差 > 3%/月 连续 3 月、成本超预算 50%、关键因子连续 2 年负、个人状态。（3 分要说出「上实盘前就写死」。）

**24. 上实盘 12 项清单里，你最可能挂哪一项？为什么？**
> 判分要点：能诚实指出自己的短板（通常是样本外只跑一次、容量、或成本后收益）；能说出补救计划。（3 分要说出「挂的那项对应手册哪一章」。）

## 怎么用 Agent 判卷

给 Agent 的指令模板：

```text
你是量化学习教练。下面是第 N 题、评分要点、我的回答。
按 0-3 分打分，只输出：
1) 分数
2) 我答对的要点（引用我的原话）
3) 我漏掉的要点（对应手册哪一节）
4) 一个追问（逼我说出失效条件）
不要直接给我标准答案。
```

**先自己答，再看 Agent 的反馈**；否则你练的是「阅读理解」，不是「判断」。
