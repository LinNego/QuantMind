## 0 三条实验纪律

1. **先预测，再跑。** 跑之前写下「我预计 IC 是 0.0X」，跑完对比。这是校准判断力的唯一方法。
2. **记录命令和数字。** 三个月后你要能复现，不是「我记得跑过」。
3. **一次只改一个变量。** 同时改窗口和股票池，你不知道是哪个起的作用。

## 2 三个必做实验的读法

### 2.1 数据体检（10 分钟）

```bash
# 在仓库根目录
duckdb -init research/qdb.sql
```

```sql
-- 1) 规模
SELECT COUNT(DISTINCT symbol) AS stocks, COUNT(DISTINCT time) AS days,
       MIN(time), MAX(time) FROM kf;

-- 2) 每日股票数（看有没有断层）
SELECT time, COUNT(*) AS n FROM kf GROUP BY 1 ORDER BY 1 DESC LIMIT 20;

-- 3) 量纲自检：应 ≈ 1e4
SELECT AVG(close * volume / amount) FROM kf WHERE amount > 0 LIMIT 100000;

-- 4) 每年消失的股票（幸存者偏差）
WITH y AS (SELECT symbol, YEAR(time) AS yr FROM kf GROUP BY 1, 2)
SELECT yr, COUNT(*) FROM y GROUP BY 1 ORDER BY 1;
```

**你要看到的**：股票数从 3000 涨到 5000；`close*volume/amount` 在 1e4 附近；
每年「消失」的股票数不为 0（为 0 说明数据只保留了活下来的）。

### 2.2 最小回归：`00_mini.py`（真实输出）

```bash
/root/quant/.venv/bin/python3 learning/labs/00_mini.py
```

实际输出（2026-11 本机）：

```
拿到 5,773,953 行数据
训练：3,506,063 行（2022 ~ 2024）
测试：2,241,755 行（2025 ~ 2026）

学到的公式：未来5日收益 ≈ 1.0447 + -0.019764 × RSI

训练集上的 IC：+0.0313   ← 看起来多好
测试集上的 IC：+0.0099   ← 真实水平
差距：+0.0215            ← 这个差距就是「过拟合」
```

**读法**：

- 这是 **Pearson 相关**，不是 rank IC；量级会比正式检验略高。
- 只用了 **1 个特征**，所以 0.01 的样本外 IC 很正常——单因子本来就很弱。
- 训练 0.0313 → 测试 0.0099，**衰减 68%**。这就是「样本内看起来能用，样本外基本没用」。
- 结论不是「RSI 有效」，是「单特征线性模型几乎不赚钱」。**这正是你需要多因子/非线性模型的原因。**

### 2.3 四情景：`01_ml_intro.py`（最重要）

```bash
/root/quant/.venv/bin/python3 learning/labs/01_ml_intro.py
```

脚本跑四行：

本机实际输出（2026-11，6 特征、2024 前训练）：

| 行 | 情景 | 平均 IC | ICIR | t（已校正） | 说明 |
|---|---|---|---|---|---|
| **A** | 诚实：样本外 | 0.0811 | 0.397 | 4.63 | 这套特征的真实水平 |
| **B** | 自欺：样本内 | 0.0879 | 0.638 | 8.89 | 比 A 高，但只高 8% |
| **C** | 泄漏：混入未来 1 日收益 | **0.4186** | 3.175 | 36.98 | 未来函数 |
| **D** | 安慰剂：标签打乱（3 种子） | +0.0151 | — | — | 区间 -0.051 ~ +0.056 |

**读法**：

- **A = 0.08 属于偏高**，因为这是线性模型 + Pearson 口径，比 rank IC 乐观。
  真实可交易的 rank IC 通常只有它的一半左右。**不要拿这个数去对标「IC 0.05 很强」的判据。**
- **B 只比 A 高 8%**：6 个特征、样本量大，过拟合空间有限。
  **特征越多、样本越少，A/B 的差距才会拉开**——这是你后面加因子的风险来源。
- **C 是 5 倍跳变**：从 0.08 到 0.42。**只要 IC 突然变得很高，第一反应是「泄漏了」。**
- **D 的区间跨过 0**：单次安慰剂可能碰巧显著，必须多跑几个种子看区间。

## 3 三个待补实验（自己写，20~40 行）

### 3.1 择时开关（对应 04）

```python
# 1) 算广度：每天站上 MA20 的股票占比
# 2) 广度 < 30% → 仓位系数 0.3；否则 1.0
# 3) 用指数收益 × 仓位系数，得到择时净值
# 4) 对比：年化、最大回撤、夏普、空仓天数
```

判据：回撤下降、夏普上升；如果收益也大幅上升，**先怀疑未来函数**。

### 3.2 成本敏感性（对应 01/03）

同一策略跑三档成本：0 / 0.1% / 0.3%（单边），画三条净值。
判据：找到「收益归零」的成本档位——这就是你的成本安全边际。

### 3.3 容量估算（对应 03）

按持仓股的日均成交额分位数，算「参与率 1% 时能买多少」，再加总。
判据：目标资金 ≤ 容量 / 3。

## 5 一句话

> **实验的目的不是「跑出好结果」，是「让你对数字的直觉变准」。**
> 你预测 0.04、跑出 0.038，比跑出 0.08 更有价值——前者说明你开始懂这个市场了。
