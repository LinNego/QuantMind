## 0. 先建立一张地图

量化研究不是“写个策略跑个回测”，而是一条流水线：

```text
数据 → 假设 → 信号 → 回测 → 评估 → 样本外 → 实盘 → 监控
```

每一环都可能让结论失真。研究者的工作，本质上是在回答三个问题：

1. **这个收益是真的吗？** —— 数据对不对？有没有未来函数、幸存者偏差、成本漏算？
2. **赚的是 alpha 还是 beta？** —— 是选股/择时的本事，还是承担了市场/规模/价值等风险？
3. **未来还能用吗？** —— 样本内好看，样本外还行吗？是不是过拟合？

### 0.1 现在只需要记住 5 个问题

这份文档不是教材，是**地图**。不要从第 1 章啃到第 9 章；先记住 5 个问题，遇到具体问题时按索引查。

1. **我赌的是什么？** —— 因子/规模/价值/动量？经济逻辑是什么？是 alpha 还是 beta？
2. **回测是真的吗？** —— 有没有未来函数、幸存者偏差、PIT 问题、成本/整手漏算？
3. **是 alpha 还是 beta？** —— 用 beta-matched 基准回归，α 显著吗？
4. **未来还能用吗？** —— 有没有真 OOS？试了多少组？安慰剂/留一年/多重检验过了吗？
5. **我能执行吗？什么时候停？** —— 容量、滑点、整手、现金拖累、回撤、kill criteria。

这五个问题 AI 可以帮你算，但**判断和责任是你的**。

## 1. 收益与风险：先把语言统一

### 1.1 收益率

- **简单收益**：`r_t = P_t / P_{t-1} - 1`
- **对数收益**：`ln(P_t / P_{t-1})`，可加、便于统计，但不要和简单收益混用。

回测里通常用简单收益做净值：`NAV_t = NAV_{t-1} × (1 + r_t)`。

### 1.2 CAGR vs 算术平均

- **CAGR（复合年化）**：`(NAV_end / NAV_start)^(1/年数) - 1`
- **算术平均年化**：`mean(月收益) × 12`

两者不一样。波动越大，CAGR 越低于算术平均（波动拖累）：

```text
CAGR ≈ 算术平均 - 0.5 × 波动率²
```

例子：年化算术 20%、波动 30% → CAGR 约 `20% - 0.5×0.09 = 15.5%`。所以看到“年化 20%”要先问：是 CAGR 还是算术平均？

### 1.3 波动率

`vol = std(月收益) × √12`（年化）。

波动率是“不确定性”的度量，不分好坏；但它会进入 Sharpe、仓位和回撤。

### 1.4 最大回撤与水下时间

```text
回撤_t = NAV_t / max(NAV_0..t) - 1
最大回撤 = min(回撤_t)
```

- **最大回撤（MDD）**：从高点到低点的最大跌幅。
- **水下时间**：从高点到下一次创新高的时间；比 MDD 更能反映“熬不熬得住”。

月频回测的 MDD 只看到月末，盘中回撤可能更深；日频/分钟频数据才能看到真实路径。

### 1.5 夏普、Sortino、Calmar

| 指标 | 公式 | 怎么读 |
|---|---|---|
| **Sharpe** | `(年化收益 - 无风险利率) / 年化波动` | 每承担 1 单位波动，赚多少超额 |
| **Sortino** | `(年化收益 - 无风险利率) / 下行波动` | 只惩罚下跌波动 |
| **Calmar** | `CAGR / |最大回撤|` | 每承担 1 单位回撤，赚多少年化 |
| **胜率** | 盈利期数 / 总期数 | 高胜率不等于赚钱（盈亏比也重要） |
| **盈亏比** | 平均盈利 / 平均亏损 | 和胜率一起看 |
| **换手** | 每期买卖金额 / NAV | 换手越高，成本越重 |

经验区间（股票策略）：

| Sharpe | 大致感觉 |
|---|---|
| <0 | 不如无风险 |
| 0–0.5 | 一般 |
| 0.5–1 | 不错 |
| 1–2 | 很好 |
| >2 | 极好，但要警惕过拟合/杠杆/不可持续 |

### 1.6 一个例子

```text
月均净收益 1.2%，月波动 6.0%，无风险 2%/年
Sharpe = (1.2%×12 - 2%) / (6.0%×√12) = (14.4%-2%)/20.8% ≈ 0.60
```

如果 CAGR 是 15%，Calmar 用 `15% / 24% = 0.625`。

> **检查清单**
> - [ ] 说的是 CAGR 还是算术平均？
> - [ ] 波动是年化还是月度？
> - [ ] MDD 是月末还是日内？
> - [ ] Sharpe 的无风险利率是多少？
> - [ ] 换手和成本扣了吗？

## 2. Alpha 与 Beta：你赚的是本事还是行情

### 2.1 回归

把策略收益对基准收益回归：

```text
r_strategy = α + β × r_benchmark + ε
```

- **β（Beta）**：市场暴露。β=1 表示跟基准同涨同跌；β=1.2 表示放大 20%；β=0 表示无关。
- **α（Alpha）**：截距。基准不涨不跌时，策略还能赚的那部分，代表“扣掉 beta 后的本事”。
- **ε**：残差/噪声。

### 2.2 例子

小盘指数涨 10%，策略涨 14%，β=1.2：

```text
beta 贡献 = 1.2 × 10% = 12%
alpha = 14% - 12% = +2%
```

如果策略只涨 12%，alpha=0，全是 beta。

### 2.3 因子模型

多因子模型把收益拆成：

```text
r = α + β_market·MKT + β_size·SMB + β_value·HML + β_mom·MOM + ε
```

- 市场、规模、价值、动量等都是**因子 beta**；
- 承担这些因子暴露，长期可能获得**因子溢价**（risk premium）；
- 但因子溢价不是“免费的 alpha”，它会周期性失效、回撤、拥挤。

### 2.4 为什么“小市值”是 beta 不是 alpha

我们的 15 只策略，收益主要来自“最小市值”这个暴露：

- 池子等权年化 2.34%（国证 2000 择时口径）；
- 最小 15 只年化 16.30%；
- **差额 ~14pp 是规模因子溢价（beta）**，不是选股 alpha。

真正的 alpha 是：扣掉规模、价值、反转等暴露后，还剩多少。我们测过：在 size 之内加 PB/反转/低波/ROE，超额都是负的——所以这个策略没有明显的选股 alpha，它是**size beta**。

> **检查清单**
> - [ ] 基准选对了吗？（要 beta-matched，不是随便拿沪深 300）
> - [ ] α 的 t 值 >2 吗？
> - [ ] 收益里有多少是 beta、多少是 alpha？
> - [ ] 因子溢价会不会拥挤/失效？

## 3. 因子研究：IC、ICIR、分层与尾部

### 3.1 因子是什么

因子是“对未来收益有预测力的横截面变量”，例如：

- 价值：PB、PE、股息率；
- 规模：总市值；
- 反转：过去 1 个月收益；
- 质量：ROE、毛利率；
- 波动：过去 20 日波动；
- 动量：过去 6 个月收益（剔除最近 1 个月）。

### 3.2 IC 的定义

每个截面（月/日），算因子值和下期收益的**秩相关**（Spearman）：

```python
ic_t = factor_t.rank().corr(fwd_ret_t.rank())
```

- IC>0：因子值越大，下期收益越高；
- IC<0：反过来；
- IC 的绝对值越大，预测力越强（但要用对方向）。

### 3.3 IC 均值、ICIR、t 值

```text
IC 均值 = mean(IC_t)
ICIR   = mean(IC_t) / std(IC_t)      # 稳定性
t 值   = ICIR × √N                  # N = 期数
```

- IC 均值：预测力大小；
- ICIR：预测力稳不稳定；
- t 值：统计显著性，>2 才勉强算“不是噪声”。

经验区间（月频，A 股）：

| 指标 | 差 | 一般 | 好 |
|---|---|---|---|
| IC 均值 | <0.02 | 0.02–0.05 | >0.05 |
| ICIR | <0.2 | 0.2–0.5 | >0.5 |
| t 值 | <1.5 | 1.5–2 | >2 |

### 3.4 IC>0 胜率 vs |IC|>0.02 比率（最容易误读）

- **IC>0 胜率**：`mean(IC_t > 0)`，方向稳定的比例；>55% 才算有点稳定。
- **|IC|>0.02 比率**：`mean(|IC_t| > 0.02)`，只说明“波动大”，**不说明方向**。

一个因子这个月 IC=+0.03、下个月 -0.03，`|IC|>0.02` 可以 100%，但均值约 0、方向来回翻——不能用。

**看到 |IC|>0.02 很高、IC 均值却很低，第一反应应该是“符号不稳定”，不是“因子很强”。**

### 3.5 分层/分位价差与单调性

把股票按因子分 5 组（Q1–Q5），看每组下期平均收益：

- 单调性：Q1<Q2<Q3<Q4<Q5（或反过来）；
- 多空价差：Q5-Q1 的均值和 t 值；
- 如果只有最极端一组有效、中间不单调，说明是**非线性/尾部因子**。

### 3.6 尾部价差：IC 低但尾部强

IC 是“整条截面的平均线性相关”，会低估**极端分位**的收益。

案例：我们的 size 因子（池子内，2017–2026，117 个月）：

| 指标 | 数值 |
|---|---|
| IC 均值 | **0.0035** |
| ICIR | **0.018** |
| IC>0 胜率 | 51.3% |
| t 值 | **0.20** |
| \|IC\|>0.02 比率 | 88.9% |
| **最小 15 只 vs 池子等权** | **月均 +1.24%，年化 +14.9%，t=2.57，胜率 60.7%** |

单看 IC，size 像随机因子；但尾部价差很大。原因：规模溢价集中在最小的一小撮，中间是平的/噪声的。

**结论：判断因子好坏，IC 只是第一关，第二关是分层/尾部价差。**

### 3.7 IC 衰减、换手、容量

- **IC 衰减**：因子在 1/5/10/20 日后的 IC；衰减慢适合低频；
- **换手**：因子排名变化越快，换手越高，成本越重；
- **容量**：小市值/低流动性因子容量小，资金大了会失效。

### 3.8 因子相关性与增量

新因子要和已有因子做相关性/回归：

- 相关性 >0.7：大概率是重复暴露；
- 回归残差 IC 才是增量 alpha；
- 不要只看单因子 IC，要看“加了它组合有没有变好”。

### 3.9 经济逻辑

问自己：**为什么这个因子该预测收益？**

- 价值：便宜的公司长期修复；
- 规模：小公司风险高、流动性差，要求溢价；
- 反转：短期过度反应；
- 质量：盈利稳定的公司风险低。

没有逻辑、只在回测里有效的因子，大概率是数据挖掘。

### 3.10 一个因子体检表

| 项目 | 看什么 | 不合格就放弃 |
|---|---|---|
| IC 均值 | 预测力 | <0.02（线性因子） |
| ICIR | 稳定性 | <0.2 |
| t 值 | 显著性 | <1.5 |
| IC>0 胜率 | 方向稳定 | <52% |
| 分层单调性 | 是否单调 | 完全乱序 |
| 尾部价差 | 极端分位 | 头尾差不显著 |
| 衰减 | 适合的频率 | 1 日后就没了 |
| 换手/成本 | 净收益 | 扣成本为负 |
| 子区间/OOS | 稳健性 | 只有一段有效 |
| 经济逻辑 | 为什么 | 讲不清 |

> **检查清单**
> - [ ] IC 是秩相关还是 Pearson？
> - [ ] 用的是 IC>0 还是 |IC|>0.02？
> - [ ] 看过分层/尾部价差吗？
> - [ ] t 值算对了吗（N 是多少）？
> - [ ] 换手/成本扣了吗？
> - [ ] 有没有样本外？

## 4. 回测的坑：为什么很多回测是假的

### 4.1 未来函数（Look-ahead）

**用了当时还不可能知道的信息。**

常见形式：

- 用 `fwd_ret.notna()` 筛股（下个月有没有价格，今天不知道）；
- 用最新财报回填历史（财报还没公告）；
- 用当前指数成分股回测历史（成分股是后来定的）；
- 用 `shift(-N)`、`bfill`、全样本标准化；
- 用收盘价信号、却按当天收盘成交。

案例：我们旧版 `universe()` 里有一行 `& panel.fwd_ret.notna()`，用“下个月退出时有没有价格”筛当月股票。只去掉这一行，2024 年从 **+6% 掉到 -5%**，年化 10.52%→9.92%。这就是未来函数的威力。

### 4.2 幸存者偏差

**数据里只有“活到现在”的股票，退市的被删了。**

- 低价/微盘是退市重灾区；
- 回测会高估收益、低估回撤；
- 我们的数据 5,228 只全活到 2026，实际 2016–2026 退市约 272 只（主板 210 只）；
- 作者估算年化要再打 **2–4pp**。

### 4.3 PIT（Point-in-Time）数据

- 财报要用**公告日**可见的版本，不是报告期；
- ST 状态、指数成分、行业分类都要按当时；
- 复权因子要用当时已知的。

### 4.4 复权、分红、拆股

- 收益用**后复权**（含分红送转）；
- 涨跌停判断用**不复权**（真实价格）；
- 两者混用会把除权日误判成涨跌停。

### 4.5 T+1、涨跌停、停牌

- A 股 T+1：今天买，明天才能卖；
- 信号日收盘出信号，**次日开盘**成交；
- 次日一字涨停买不进、一字跌停卖不出；
- 停牌无法交易，复牌可能补跌。

### 4.6 交易成本

| 项目 | 费率 | 买入 | 卖出 |
|---|---|---|---|
| 佣金 | 万 0.875（免 5） | 0.00875% | 0.00875% |
| 印花税 | 万 5 | — | 0.05% |
| 过户费 | 万 0.1 | 0.001% | 0.001% |
| 滑点（假设） | 0.1%/边 | 0.1% | 0.1% |
| **合计** | | **0.10975%** | **0.15975%** |

- 单边成本不是对称的：卖出多一个印花税；
- 回测用一个 `cost` 时，要么用平均，要么分开算；
- “免 5”= 没有 5 元最低佣金；小单友好。

### 4.7 整手、现金拖累、容量

- A 股买入必须 **100 股整数倍**；
- 小资金会出现“买不满”，留下现金；
- 现金拖累 = 现金比例 × 策略收益；
- 容量：单日成交额 × 参与率；微盘容量小。

案例：2.5 万跑 15 只，每只 1,667；整手后现金 13.4%，权重 3.5%–6.6%，实际年化约 18.4%，不是回测的 21.2%。

### 4.8 数据挖掘/多重检验

- 试了 100 个参数，挑最好的一个，它大概率是运气；
- 试了 20 个因子，总有一个 t>2；
- 修正：Bonferroni、Deflated Sharpe、预注册、OOS。

### 4.9 回测检查清单

> - [ ] 信号只用了 T 日及之前的数据？
> - [ ] 成交在 T+1，不是 T 日收盘？
> - [ ] 退市股补了吗？
> - [ ] 财报/ST/成分股是 PIT 吗？
> - [ ] 复权价和真实价用对了吗？
> - [ ] 涨跌停/停牌处理了吗？
> - [ ] 佣金/印花/过户/滑点扣了吗？
> - [ ] 整手/现金拖累算了吗？
> - [ ] 参数试了多少组？多重检验修正了吗？

## 5. 过拟合与样本外：怎么判断不是运气

### 5.1 样本内 vs 样本外

- **样本内（IS）**：用来找规则/调参数的数据；
- **样本外（OOS）**：找规则时完全没看过的数据；
- OOS 是“高考”，IS 是“平时作业”。

关键：**看了 OOS 再改规则，OOS 就变成 IS 了。**

### 5.2 时间序列切分

- 简单切分：前 70% 训练，后 30% 测试；
- Walk-forward：滚动训练/测试，更接近实盘；
- 不要随机打乱时间序列（会泄露未来）。

### 5.3 安慰剂/随机化

把规则应用到“随机月份/随机股票/随机方向”，看效果分布：

- 如果随机也能做到，规则不特殊；
- 如果规则在分布尾部，才有戏。

案例：1/4 空仓在 66 个月份对里排第 1，中位对只有 11.96%——样本内很突出；但样本外 2025-07~2026-10 少赚 9.3pp。

### 5.4 留一年/子区间

- 留一年：剔除任一年，看结论是否还成立；
- 子区间：2017–2021 vs 2022–2026；
- 如果只有某一年有效，就是脆弱。

### 5.5 Bootstrap/置信区间

对月度收益有放回重采样，算 CAGR/Sharpe/MDD 的分布：

```python
idx = np.random.randint(0, len(r), len(r))
cagr = np.prod(1 + r[idx]) ** (12/len(r)) - 1
```

- 看 90% CI 是否包含 0；
- 看最坏 5% 的情景；
- 注意：bootstrap 假设样本可交换，真实市场有自相关/厚尾。

### 5.6 多重检验

- 试了 m 个独立假设，Bonferroni 阈值 = α/m；
- 例如 66 个月份对，阈值 0.05/66 ≈ 0.00076；
- Deflated Sharpe 会按“试了多少次”调整；
- 预注册：先写下规则，再看数据。

### 5.7 纸面交易

- 用真实信号、模拟成交，跑 3–6 个月；
- 记录滑点、未成交、整手、现金；
- 对得上再上小资金。

### 5.8 案例：1/4 空仓

| 检验 | 结果 | 判断 |
|---|---|---|
| 样本内 | 21.20% → 23.81% | 很好 |
| 留一年 | +6.0~+9.4pp | 稳 |
| 安慰剂 66 对 | 1/4 排 1/66 | 样本内突出 |
| 子区间 | 2017–19 +6.4pp；2020–25 +11.1pp | 稳 |
| **真 OOS 2025-07~2026-10** | **-9.3pp** | **没过** |
| 市场 beta 对照 | 等权也 +4.6pp | 大部分是 beta |

结论：样本内很强，样本外失败；只能当“待验证假设”，不能当稳定 alpha。

> **检查清单**
> - [ ] 有没有真 OOS（不是同一段数据反复调）？
> - [ ] 试了多少组参数/因子？
> - [ ] 做了安慰剂/留一年/子区间吗？
> - [ ] Bootstrap CI 包含 0 吗？
> - [ ] 纸面跑过吗？

## 6. 组合构建：从信号到持仓

### 6.1 持仓数

- 10 只：集中、弹性大、回撤/退市风险高；
- 15 只：折中；
- 30–40 只：分散、容量大、单票影响小。

没有“越多越好”：太多会稀释 alpha；太少会放大 idiosyncratic 风险。

### 6.2 权重

- **等权**：简单、稳健、对小市值友好；
- **市值加权**：偏向大票，和“小市值”矛盾；
- **风险平价/反波动**：降低高波票权重，可能提高 Sharpe，但会偏离原始信号；
- **分层权重**：按分数/排名加权，需防止过拟合。

### 6.3 再平衡频率

- 月频：成本低、信号衰减慢；
- 周频：信号快、成本高；
- 日频：成本/冲击最大，适合高容量策略。

换手 × 成本 = 摩擦；先算清楚再决定频率。

### 6.4 单票/行业上限

- 单票 ≤10%；
- 同行业 ≤3 只；
- 避免组合被一个行业/一只票主导。

### 6.5 现金/整手/小资金

- 整手导致现金拖累；
- 小资金权重偏离；
- 资金越大，拖累越小；
- 2.5 万跑 15 只：现金 13.4%，实际收益打 87 折。

> **检查清单**
> - [ ] 持仓数和资金匹配吗？
> - [ ] 等权还是加权？为什么？
> - [ ] 再平衡频率和成本匹配吗？
> - [ ] 单票/行业上限？
> - [ ] 整手/现金拖累算了吗？

## 7. 从回测到实盘

### 7.1 容量

```text
容量 ≈ 日均成交额 × 参与率 × 持仓数 × 建仓天数
```

- 微盘 2,000 万/日、5% 参与率、15 只、3 天 → 约 0.3 亿；
- 超过容量，滑点会吃掉收益；
- 小资金（5 万）容量没问题，但整手现金拖累大。

### 7.2 执行

- 信号日收盘出信号，次日开盘成交；
- 限价单，不要市价单砸开盘；
- 先卖后买，留现金缓冲；
- 涨停不追、跌停不硬卖、停牌保留。

### 7.3 监控

每月记录：

- 收益、换手、滑点、未成交；
- 持仓数、现金、行业集中度；
- 回撤、vs 基准；
- 规则有没有被临时改。

### 7.4 Kill criteria

- 连续 12 个月跑输基准 >10pp；
- 回撤 >35%；
- 季节规则连续 2 年反向；
- 数据/执行出现系统性问题。

### 7.5 心理与纪律

- 规则一改，回测作废；
- 不要因为一个月跑输就改参数；
- 不要用杠杆；
- 只用能承受回撤的闲钱。

## 8. 案例复盘：主板微盘 15 只

### 8.1 策略定义

- 池：沪深主板、非 ST、1.5–10 元、10–50 亿、5 日均额 ≥2000 万、上市 ≥120 天、剔立案；
- 选：总市值升序前 15，等权；
- 择时：国证 2000 在 MA200 下方半仓；1 月半仓、4 月空仓；
- 调仓：月末收盘信号，次日开盘成交；
- 成本：单边 0.175%（保守）/ 0.135%（实际佣金）。

### 8.2 回测结果（2017–2026，国证 2000）

| 版本 | 年化 | 夏普 | 最大回撤 |
|---|---|---|---|
| 基准 15 只 | 16.30% | 0.69 | -22.31% |
| 4 月空仓 | 19.64% | 0.83 | -24.31% |
| **1 月半仓/4 月空仓** | **21.20%** | **0.91** | **-24.31%** |
| 1/4 全空 | 23.81% | 1.04 | -24.31% |

### 8.3 因子归因

- size 线性 IC 0.0035、ICIR 0.018、t=0.20——像随机；
- 但最小 15 只 vs 池子：+1.24%/月、+14.9%/年、t=2.57——尾部强；
- 低波 IC 0.099、低 PB 0.058、反转 0.048，线性都比 size 好，但加到组合里都跑输——因为它们稀释了 size 尾部；
- 结论：这是 **size 尾部 beta**，不是选股 alpha。

### 8.4 过拟合检验

- 1/4 全空 OOS -9.3pp；1 月半仓/4 月空仓 -6.2pp；
- 留一年 +6~+9pp；子区间都为正；
- 安慰剂 1/4 排 1/66；
- 但 2026 年 1/4 月都是正收益，规则已经反向一次。

### 8.5 实盘版本

- 推荐：15 只 + MA200 半仓 + 1 月半仓/4 月空仓；
- 2.5 万：现金 13.4%、权重 3.5–6.6%、实际约 18.4%，规划 13–15%；
- 5 万（半仓 5 万、总资金 10 万）：现金 5–8%，规划 14–17%；
- 1/4 全空：先纸面，等 2027 OOS。

### 8.6 经验教训

1. **回测数字是上限**：退市、成本、整手、执行都会打折。
2. **IC 低不等于因子没用**：尾部价差才是关键。
3. **IC 高不等于组合能变好**：低波/低 PB 的线性 IC 更好，但加到 size 尾部里反而拖累。
4. **样本外是唯一裁判**：1/4 规则样本内很强，OOS 失败。
5. **小资金先解决整手/现金**：2.5 万跑 15 只，实际是“打了 87 折”的策略。

### 9.2 练习

1. **指标**：给 60 个月收益，算 CAGR、年化波动、Sharpe、MDD、Calmar；比较算术平均与 CAGR。
2. **Alpha/Beta**：给策略和基准收益，回归求 α/β/t；解释“α 不显著”意味着什么。
3. **IC**：给因子值和下期收益，算 IC 均值、ICIR、t、IC>0 胜率、|IC|>0.02 比率；判断因子好坏。
4. **尾部**：按因子分 5 组，算 Q1–Q5 收益和 Q5-Q1 价差；如果 IC 低但 Q5-Q1 高，怎么解释？
5. **未来函数**：找出 `fwd_ret.notna()`、`bfill`、全样本标准化、收盘信号收盘成交。
6. **幸存者偏差**：如果数据只有活着的股票，回测会偏向哪类策略？
7. **过拟合**：同一规则试了 20 组参数，最好的一组年化 30%，你怎么验证？
8. **整手**：2.5 万、15 只、股价 3–10 元，算实际投入/现金/权重偏离。
9. **执行**：一字涨停/跌停/停牌，分别怎么处理？
10. **实盘**：写一张规则卡（池、选、调、成本、风控、kill criteria）。

```text
CAGR = (NAV_end/NAV_start)^(1/年数) - 1
年化波动 = std(月收益) × √12
Sharpe = (年化收益 - rf) / 年化波动
Sortino = (年化收益 - rf) / 下行波动
Calmar = CAGR / |MDD|
MDD = min(NAV / cummax(NAV) - 1)
IC_t = rank(factor_t).corr(rank(fwd_ret_t))
ICIR = mean(IC) / std(IC)
t_IC = ICIR × √N
Alpha: r = α + β·r_b + ε；t_α = α / SE(α)
```

## 附录 B：Python 片段

```python
import numpy as np, pandas as pd

def metrics(nav: pd.Series):
    r = nav.pct_change().dropna()
    years = len(r) / 12
    cagr = nav.iloc[-1] ** (1 / years) - 1
    vol = r.std() * np.sqrt(12)
    sharpe = (r.mean() * 12 - 0.02) / vol
    mdd = (nav / nav.cummax() - 1).min()
    calmar = cagr / abs(mdd) if mdd else np.nan
    return dict(cagr=cagr, vol=vol, sharpe=sharpe, mdd=mdd, calmar=calmar)

def ic_series(df, factor_col, ret_col):
    out = []
    for dt, g in df.groupby("dt"):
        g = g[[factor_col, ret_col]].dropna()
        if len(g) >= 50:
            out.append(g[factor_col].rank().corr(g[ret_col].rank()))
    return pd.Series(out)

def alpha_beta(r, rb, rf=0.0):
    x = rb - rf
    y = r - rf
    X = np.column_stack([np.ones(len(x)), x])
    b = np.linalg.lstsq(X, y, rcond=None)[0]
    resid = y - X @ b
    s2 = resid @ resid / (len(y) - 2)
    cov = s2 * np.linalg.inv(X.T @ X)
    alpha_ann = b[0] * 12
    t_alpha = b[0] / np.sqrt(cov[0, 0])   # 截距的 t 值，不是斜率的
    return alpha_ann, b[1], t_alpha
```
