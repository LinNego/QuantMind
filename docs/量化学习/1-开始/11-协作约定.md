## 三、边界（核心）

### 三个阶段，三种分工

```
阶段 0（D09/D11/D12）
  你做：跑命令、看数据、写结论
  我做：给命令、给判断标准、判读你贴回来的结果
  铁律：我不代跑。你贴结果，我判读。

阶段 1–3（D13–D69）
  你做：① 写策略规格（一页纸中文）
        ② 按 5 问答验收
        ③ 决定要不要继续
  我做：① 写代码
        ② 写检查脚本
        ③ 解释结果、提出归因假设

阶段 4（D70–D87）
  默认跳过。要做的理由必须你自己说得出。
```

### 一张表说清

| 事情 | 谁 | 备注 |
|---|---|---|
| 写代码 | **AI** | 快、少打错字 |
| 写规格（策略到底怎么定义） | **你** | 说不清 → AI 必然实现错 |
| 跑验收脚本 | **你** | 5 问，见 [10-验收清单](../4-工具/10-验收清单.md) |
| 判断结果真假 | **你** | AI 无法判断自己错没错 |
| 决定做不做 | **你** | 只有你知道能承受多大回撤 |
| 解释为什么、提假设 | 一起 | 你出方向，我出证据 |
| 阶段 0 的数据体检 | **你** | 不亲手摸，永远只能"看起来对" |

## 四、每天怎么走

### 阶段 0（现在，到 D12）

```
白天 45 分钟   读当天格子指定的文档
晚上 60 分钟   敲命令 → 看结果 → 写一句结论
```

**不做的事**：不看净值、不调参数、不问"这个策略能不能赚钱"。

### 阶段 1 起（D13 以后）

```
白天 45 分钟   读概念 + 想「这策略到底怎么定义」
白天 10 分钟   写【策略规格】（模板见 10-验收清单附录）
白天  5 分钟   把规格发给 AI

晚上 10 分钟   拿到代码，先不看结果
晚上 30 分钟   跑 5 问
晚上 15 分钟   5 问全过 → 才允许看净值
晚上  5 分钟   填验收记录表
```

## 五、三条硬规矩

1. **Gate 过不了不许往下走。** 前面错了会以「结果还不错」的形式藏到后面。
2. **样本外只跑一次。** 跑第二次它就变成样本内了。
3. **AI 跑完的结论，你要能自己复现一遍。** 复现不了 = 不算做过了。
