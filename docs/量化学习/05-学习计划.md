# 05 · 学习计划（24 周主线）

> **这份文档是你的主线。其它文档都是它的补充阅读。**
> 用法：每周打开它，勾掉做完的项，过不了 Gate 不许往下走。

---

## 0. 三个前提

1. **时间预算**：默认每周 **10 小时**（工作日两个晚上 + 周末半天）。如果你只有 4 小时，看 [第 8 节压缩版](#8-如果每周只有-4-小时压缩版)。
2. **只用手上的 Python + 数据目录**：前 16 周**不碰** Docker、前端、QuantBot。
3. **顺序是死的**：规则策略 → 因子 → 组合 → 最后才 ML。**顺序反过来，你会浪费三个月。**

### 环境准备（一次性）

```powershell
pip install pandas duckdb pyarrow matplotlib
# 阶段 4 才需要
# pip install lightgbm
```

数据目录通过环境变量指向（详见 [01-数据获取与迁移.md](01-数据获取与迁移.md)）：

```powershell
$env:QM_QUANTDB_DATA_DIR = "D:\quantmind_data\quantdb"
```

## 2. 阶段 0：数据与环境（第 1-2 周）

**目标**：不是「把系统跑起来」，是**能一行命令读出全市场日线，并且说清每个字段什么意思**。

### 任务

- [ ] 拿数据：L0 精简档（15~20GB），放在 `D:\quantmind_data\quantdb`
- [ ] `pip install pandas duckdb pyarrow matplotlib`（**就这四个**）
- [ ] 写 `research/01_load_data.py`，输出一份「数据体检报告」
- [ ] 读 [quantdb_datasets.py](../../backend/shared/quantdb_datasets.py)（29 个数据集是干什么的）
- [ ] 读 [quantdb_hub.py](../../backend/services/engine/data_platform/quantdb_hub.py) 开头的列名映射

### 数据体检报告必须包含

```python
# 最少这 6 项
1. 多少只股票、多少个交易日、时间范围
2. 每天有数据的股票数（会看到从 3000 涨到 5000）
3. 各字段缺失率
4. 异常记录：收盘价 <= 0、成交量为 0
5. 异常记录：单日涨跌幅 > ±11%（超过涨跌停，说明有数据问题或未复权）
6. 每年「消失」的股票数（验证是否含退市股 → 幸存者偏差）
```

### Gate 1（必须能答出来）

- [ ] `daily_forward`（前复权）/ `daily_backward`（后复权）/ `daily_unadjusted`（不复权）分别用在哪？
- [ ] 你的数据有多少只股票、多少交易日、哪一年缺得最厉害？
- [ ] 举出 3 个你发现的数据异常，说明它会不会影响回测

### 典型走偏

> 一上来 `docker compose up`、纠结镜像、想搞懂整个仓库结构。**这三件事对现在的你价值为零。**

## 3. 阶段 1：第一个策略 + 成本（第 3-4 周）⭐ 最关键

**目标**：跑通 `截面排名 → 组合 → 扣成本 → 净值` 这条完整链路。
**这一阶段的价值超过后面所有阶段之和。**

### 任务

- [ ] 策略极简：`score = 1 / PE`（或 20 日反转 `-mom20`），**每天截面排名取前 30 只，每 20 个交易日调一次仓**
- [ ] 先写**零成本版**，得到一条净值曲线
- [ ] 再加成本，分三档跑：
  - 佣金 万 2.5（双边）
  - 印花税 千 1（**只卖出收**）
  - 滑点 0.1%
- [ ] 算换手率，画三条曲线：`成本 0` / `成本 0.1%` / `成本 0.3%`
- [ ] 计算指标：年化收益、年化波动、夏普、最大回撤、卡玛、月胜率、年换手
- [ ] 加基准：等权全市场（同样月度调仓、不计成本）
- [ ] 读 [回测费用配置说明](../回测费用配置说明.md)
- [ ] 翻 [ashare_matcher.py](../../backend/services/simulation/services/ashare_matcher.py) 前 100 行（看涨停为什么买不进）

### 时刻记着

> **信号用 T 日收盘算，成交用 T+1。** 用当天收盘价算分数、又用当天收盘价成交，能做出年化 100%，实盘必死。

### Gate 2（必须能答出来）

- [ ] 你的策略在**多高的成本**下收益归零？
- [ ] 印花税为什么只在卖出时收？只收一边对高频策略意味着什么？
- [ ] 你今天是按「昨天收盘价」还是「今天收盘价」成交的？

### 典型走偏

- 用当天收盘价算分数 + 当天收盘价成交（未来函数）
- 忘了月末才调仓，写成每天都换
- PE 为负数或缺失时没处理（ST 股、亏损股）

## 4. 阶段 2：因子研究（第 5-8 周）

**目标**：能独立判断「一个因子到底有没有用」。

### 任务

- [ ] 自己写三个工具函数（**不许用现成库**，因为你要知道它怎么算）：

  ```python
  rank_ic(factor, fwd_ret)      # 每天截面算 Spearman 相关，再对时间求均值
  layer_returns(factor, n=5)    # 分 5 组，看收益是否单调
  factor_turnover(factor)       # 排名变化率
  ```

- [ ] 用这套工具检验 5 个因子：**20 日反转、60 日动量、20 日波动率、换手率、市值**
- [ ] 每个因子必须回答三个问题：**IC/ICIR 多少？分层单调吗？换手多少？**
- [ ] 每个因子**按年拆开**看 IC，不是只看全样本
- [ ] 对照仓库已算好的 `features_daily`，看你的实现和它是否一致（**最好的实现正确性检验**）
- [ ] 读 [因子与特征参考](../QuantMind_因子与特征参考.md)，了解 Alpha158 是什么

### 阶段验收

- [ ] 一张表：`5 个因子 × (IC, ICIR, 分层单调性, 换手率, 扣成本后收益)`
- [ ] 能对每个因子说一句「**它的钱是从哪来的**」（风险溢价？纠正错误？还是纯粹在挖数据？）
- [ ] 能对「为什么某因子 2017 年好、2021 年差」给出至少一个**可检验的假设**

### 自检红线

> 算出来的 IC 绝对值超过 **0.15**，**先假定是 bug**，别高兴。详见 [03-常见陷阱与自检红线.md](03-常见陷阱与自检红线.md)。

## 5. 阶段 3：组合与稳健性（第 9-12 周）

**目标**：从「一个因子」变成「一个能活的策略」。

### 任务

- [ ] **多因子合成**：先等权 z-score，再试 IC 加权
- [ ] **行业中性**：用 `2_base_sector/sector_concept` 或 `instrument_detail` 的行业字段，确保不是全买同一个行业
- [ ] **换手控制**：只换掉排名掉出前 N 名的（缓冲带），而不是全换
- [ ] **参数敏感性**：`topk ∈ {10,20,30,50}` × `调仓周期 ∈ {5,10,20,60}`，画一张热力图
- [ ] **样本外**：2016-2021 用来设计，**2022-2024 只跑一次，跑完不许改再跑**
- [ ] **对照组**：拿 [as26_low_vol_core.py](../../strategy_templates/as26_low_vol_core.py)（低波）同区间对比

### Gate 3

- [ ] 热力图上，**哪些格子是悬崖**？（相邻参数差距巨大 = 策略在边缘上，很脆）
- [ ] 样本外 vs 样本内，收益衰减了多少？**超过 50% 就说明过拟合**
- [ ] 你的策略 vs as26，差在收益、回撤、还是换手？

### 典型走偏

- 看热力图挑最亮的那个格子（**这就是过拟合的定义**）
- 在样本外反复调参直到好看（**样本外被你用成了样本内**）

## 6. 阶段 4：ML 那一小块（第 13-16 周）

**目标**：把「你手写的权重」换成「从数据里学出来的权重」。**只替换这一步，别的都不变。**

先读 [04-ML要不要学.md](04-ML要不要学.md)，确认自己能回答那 6 个自测题。

### 任务

- [ ] `pip install lightgbm`
- [ ] **按时间切分**：前 70% 训练，后 30% 测试。**绝不随机切分**
- [ ] 标签：未来 5 日收益的**截面排名**（或 z-score）
- [ ] 特征：阶段 2 的那 5 个因子
- [ ] 训练 → 得到「模型分」→ **套用阶段 3 的组合流程**（关键：组合逻辑完全复用）
- [ ] 看特征重要性，反推「哪几个因子真的有用」

### 阶段验收

- [ ] 模型版 vs 规则版的**样本外**对比表
- [ ] 能回答 [04-ML要不要学.md](04-ML要不要学.md) 里的 6 个自测题
- [ ] **如果样本外 IC 只提升了 0.005，你要敢说「模型没带来价值」**——这是正常且诚实的结果

### 典型走偏

- 随机切分（数据泄漏）
- 用测试集调参
- 觉得 IC 0.05 太小（日频 A 股已经不错）
- **忍不住上深度学习**

---

## 7. 阶段 5：模拟盘 + 复盘（第 17-24 周）

**目标**：让策略在「活着」的状态下跑满 3 个月。

### 任务

- [ ] 每天生成信号，记录：**信号价 → 实际可成交价 → 滑点 → 是否涨停/停牌**
- [ ] 每周复盘：模拟净值 vs 回测净值的偏差，**归因到具体原因**
- [ ] 建一个「策略死法清单」：什么市场状态下它会失效
- [ ] 持续填实验日志（见 [06-实验日志模板.md](06-实验日志模板.md)）

### 阶段验收

- [ ] 3 个月**跟踪误差报告**
- [ ] 一份「我知道它什么时候会死」的清单
- [ ] 一个决定：上不上实盘

> **没有这 3 个月，后面所有事都是纸上谈兵。**

### 阶段 6（可选）：小资金实盘

- 建议起步 1~2 万，先跑 6 个月，全程对比模拟盘
- 注意 [通达信实盘桥部署指南](../通达信实盘桥_完整部署指南.md) 是参考实现，**券商权限与合规要自己搞定**
- 仓库默认 `ENABLE_REAL_TRADING=false`

## 11. 六条走偏清单（贴在墙上）

1. ❌ **先搭 Docker 全家桶** → 你会花两周在运维上
2. ❌ **先学深度学习** → 你会花两个月，换来更差的样本外
3. ❌ **先玩 RD-Agent / AI 选股** → 那是成品功能，不是学习路径
4. ❌ **追求年化 50%+** → 那是过拟合的体温计
5. ❌ **只做回测不做模拟** → 你永远不知道成本和滑点有多狠
6. ❌ **不做实验日志** → 半年后你会发现自己在原地转圈
