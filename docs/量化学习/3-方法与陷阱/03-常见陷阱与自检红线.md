## 1. 陷阱一：模型分没做截面标准化（量纲吞并）

这是最容易犯、最难发现的一类 bug，而且**它的原话就写在仓库里**。

### 1.1 原文

[as16_momentum_20.py](../../../strategy_templates/as16_momentum_20.py) 的 `_adjust_signal` 注释：

> 「模型分必须先做截面标准化：pred 的量纲随模型而变（本批模型 per-date std≈0.0035），直接加 [-1,1] 的动量因子等于把排名完全交给动量（**实测 as11 年化从 55% 掉到 10%**）。标准化后 `momentum_weight` 才真正是「动量的相对权重」。」

### 1.2 翻译成人话

> 你的模型给每只股票一个「看好程度」分数。你又想叠加一个动量因子。**但你把两个数量级差了几百倍的数字直接相加了**，结果动量把模型分彻底压死——你以为在「融合两个信号」，实际在「扔掉模型分，只用一个 20 日动量」。

### 1.3 为什么量纲差那么多

| | 典型标准差 | 数量级 |
|---|---|---|
| 模型分（LightGBM 之类） | **0.0035** | 千分之三 |
| 动量因子（z-score 后截断到 [-1,1]） | **0.3 ~ 0.6** | 十分之几 |
| **倍数差** | **约 100~200 倍** | |

`score + factor` 之后，那个 0.0035 的贡献在 0.5 面前**等于不存在**。5000 只股票的排序结果 99.99% 由动量决定。

### 1.4 8 行代码验证（不需要任何数据）

```python
import numpy as np
from scipy.stats import spearmanr

score  = np.random.normal(0, 0.0035, 5000)   # 模型分
factor = np.random.normal(0, 0.5,    5000)   # 动量因子

fused = score + factor
print("融合后 vs 模型分的排名相关性:", spearmanr(fused, score).statistic)    # ≈ 0.007
print("融合后 vs 动量因子的排名相关性:", spearmanr(fused, factor).statistic)  # ≈ 0.9999
```

**看到 0.9999 就懂了：这不是「融合」，这是「覆盖」。你的模型白训了。**

用工程语言说，这等价于：

```python
score = user_reputation_score * 0.0001 + click_count   # 排序完全由点击量决定
```

或者：**把「延迟（秒）」和「延迟（毫秒）」直接相加，然后说这是「综合延迟」。**

### 1.5 为什么年化从 55% 掉到 10%

因为退化成「纯动量」之后，**策略身份被换掉了**：

- **有模型分时（55%）**：模型从几百个特征里学了东西，动量只贡献一点方向性偏好
- **模型分被压死时（10%）**：策略 == 「买过去 20 天涨最多的 30 只，3 天换一次」

而 A 股 20 日动量在那段区间本身就不是好因子（A 股短周期上「反转」往往更强）。所以 10% 是「纯动量策略」的真实成绩。

> **55% 和 10% 的差距，不是模型变强了，是策略身份被换掉了。**
> 另外注意模板自己的免责声明：单一区间单一模型的成绩只用于验证链路与相对比较，不等于未来收益。

### 1.6 正确写法（4 行）

```python
std  = score.std(ddof=1)                            # 当天的截面标准差
base = (score - score.mean()) / std                 # 先把模型分也变成 z-score（±1 量级）
fused = base.add(factor * self.momentum_weight)     # 量纲一致后，weight 才真是权重
```

### 1.7 为什么必须「每天、截面内」标准化

```python
std = score.std(ddof=1)   # score 是「当天这 5000 只股票」的分数
```

- **不能全局标准化**（所有日期、所有股票混在一起算）：市场整体涨跌会污染结果，你比的就不只是「今天谁更好」
- **更不能把 std 写死成常数**：模型每次重训输出分布就变一次，今天 0.0035、下个月可能 0.008。**写死的权重会在模型重训那天悄悄失效——又一个静默降级**

### 1.8 通用规则

> **任何要相加、加权、比较的分数，必须在「同一天、同一批标的」内先转成排名或 z-score。**

## 2. 陷阱二：未来函数（look-ahead bias）

### 2.1 最常见的三种

```python
# ❌ 用当天收盘价算信号，又用当天收盘价成交
signal = close.pct_change()        # 用了今天收盘才知道的信息
trade_price = close                # 却在今天收盘成交 → 实盘不可能

# ❌ 用未来窗口当特征
factor = close.shift(-5) / close - 1

# ❌ 用了「事后才知道」的静态数据
# 例如用今天仍在上市的股票名单回测 2015 年（见幸存者偏差）
```

### 2.2 正确姿势

```
T 日收盘后：用截至 T 日收盘的信息算因子 → 得到信号
T+1 日：开盘/收盘成交
```

**判断口诀**：问自己「**在那一刻，我真的能看到这个数吗？**」看不到，就是未来函数。

### 2.3 数据侧的隐蔽来源

> ⚠️ **这个仓库里最阴的一处**：`6_ml_datasets/features_daily` 自带 `future_return_1d / 3d / 5d / 10d / 20d / 60d` 六列（79 列里真名就长这样）。它们是**标签**，不是特征。你 `SELECT *` 或直接 merge 整表，这六列就会跟着进模型/进打分 → 回测年化轻松几十个百分点，且全程不报错。**读 features_daily 时第一件事就是把 `future_return_*` 显式排除。**

| 来源 | 说明 |
|---|---|
| **复权口径** | 前复权序列**随每次除权全量重写**（今天看到的历史价 ≠ 当时看到的），价格水平也不是当年真实成交价 → 用于算收益率可以，用于判涨跌停/整手/成交价就错；反过来用不复权价算收益率，会把除权日当成「暴跌」 |
| **财务数据发布日** | 用报告期（`2024Q1`）而不是公告日，会提前知道财报 |
| **指数成分股** | 用「今天的沪深300成分」回测 2015 年 |

## 3. 陷阱三：幸存者偏差

**问题**：你只用「今天还在交易」的股票回测过去 10 年。退市、被并购、ST 到退市的那些**被自动排除**，而它们恰恰是亏钱的那批。

**后果**：收益系统性虚高，尤其在回测长周期、小市值策略时最严重。

**检查**：

```python
# 每年的股票数是否单调递增？如果是，说明只保留了活下来的
df.groupby(df.trade_date.dt.year)["symbol"].nunique()
```

**正常的形态**应该是：股票数随上市数量增长，但**每年都有一部分股票消失**。如果一只都没少，说明你的数据里没有退市股。

**处理**：
- `6_ml_datasets/features_daily` 里有 `is_st`、`is_quit_risk` 两个标记列（见 [quantdb_hub.py](../../../backend/services/engine/data_platform/quantdb_hub.py) 的 `_NUMERIC_STRING_COLUMNS`），可以用来识别风险股
- **但注意**：回测时应**包含已退市标的**，只在"当天是否可交易"上做约束；如果直接把今天的成分股名单套到十年前，偏差无法修复
- 最保守的做法：任何回测结论都问一句「如果我当年真的只能看到当时的股票池，结论还成立吗」

## 4. 陷阱四：过拟合（在历史上调参到完美）

### 4.1 三种典型形态

| 形态 | 表现 |
|---|---|
| **参数挑最亮的格子** | 扫了 20 组参数，选了回测最好的那组 |
| **反复用样本外调参** | 「样本外」被你用了 30 次，它已经变成样本内了 |
| **因子越加越多** | 加到 50 个因子，回测越来越好，样本外越来越差 |

### 4.2 判断标准

| 指标 | 危险信号 |
|---|---|
| 样本内 vs 样本外收益差 | 衰减 **> 50%** 就说明严重过拟合 |
| 参数热力图 | 相邻格子差异巨大 = 你在悬崖边上 |
| 因子数量 vs 样本量 | 因子越多、区间越短，越容易假 |

### 4.3 正确做法

1. **先设计，后回测**：参数范围在跑之前就定死
2. **样本外只跑一次**：跑完不许改再跑
3. **看参数的「平台」而不是「尖峰」**：一片区域都好 > 一个点特别好
4. **滚动窗口验证（WFA）**：分段训练、分段验证，看稳定性

> ⚠️ **样本外反复调参 = 把样本外变成了样本内。** 这是最常见、最自欺的一种。

## 5. 陷阱五：成本与可成交性没算清

**这是散户策略「从年化 25% 变成年化 3%」的真正原因。**

### 5.1 必须算进去的东西

| 项 | 大致量级 | 说明 |
|---|---|---|
| 佣金 | 万 2.5 双边 | 券商不同 |
| 印花税 | **万 5（0.05%）**，**仅卖出** | 2023-08-28 起由千 1 减半；只收一边，对高频策略杀伤极大 |
| 过户费 | 万 0.1（0.001%） | 沪深双向，已并入口径 |
| 滑点 | 0.05%~0.2% | 你买不到回测价 |
| **涨跌停不可成交** | — | 涨停买不进、跌停卖不掉 |
| **停牌** | — | 想动动不了 |
| **T+1** | — | 今天买的明天才能卖 |
| **整手（100 股）** | — | 小资金买贵股买不满 |

### 5.2 必做实验

> 同一策略，画出「成本 0% / 0.1% / 0.3%」三条净值曲线，**找到收益归零的那个成本水平**。

如果策略在 0.2% 成本下就归零，那它在真实市场里活不下来（因为你还没算滑点和不可成交）。

### 5.3 参照物

- [回测费用配置说明](../../回测费用配置说明.md)
- [ashare_matcher.py](../../../backend/services/simulation/services/ashare_matcher.py)（涨跌停钳制、停牌、整手、T+1 的真实实现）

## 6. 陷阱六：静默降级（工程视角的元凶）

前面几个陷阱的共同特征，正是软件工程里最阴的那一类：

| 特征 | 说明 |
|---|---|
| **不报错** | 没有异常、没有 NaN、类型全对、能跑完全程 |
| **静默降级** | 功能还在，但实际行为已经变成别的东西 |
| **结果反而「正常」** | 曲线不崩，甚至还行，所以你不会去查它 |

**防它靠断言，不靠眼睛看曲线。**

```python
# 融合前后：两个组分贡献是否在同一量级
ratio = factor.std() / base.std()
assert 0.1 < ratio < 10, f"量纲不匹配，融合无效 (ratio={ratio:.1f})"

# 融合信号与各组分的一致性，防止「覆盖」
print("与模型分相关性:", fused.corr(score,   method="spearman"))   # 期望 0.5~0.8
print("与因子分相关性:", fused.corr(factor,  method="spearman"))   # 期望 0.5~0.8
# 任何一个 ≈ 0.999 → 你只是换了个名字
```

**你要把工程能力优先投在「证伪」上，不是「建模」上**：写校验脚本、数据体检、成本对照、参数敏感性扫描。这些活儿你能做得比 90% 的量化研究员好，而且它们直接决定你赚不赚钱。

## 7. 四条自检红线

**贴在屏幕上。任何一条触发，先停下来查，别庆祝。**

| # | 现象 | 先怀疑 | 立刻做什么 |
|---|---|---|---|
| **1** | IC 绝对值 **> 0.15** | **未来函数** | 检查 shift 方向、复权口径、财务公告日、成交价时点 |
| **2** | 年化 **> 50%** 或夏普 **> 3** | 回测有 bug | 查成本、涨停可成交性、幸存者偏差、是否用了当天收盘成交 |
| **3** | 样本外衰减 **> 50%** | **过拟合** | 减少参数、拉长区间、只保留逻辑最硬的因子 |
| **4** | 融合信号与某组分相关性 **≈ 0.999** | **量纲吞并** | 见 [陷阱一](#1-陷阱一模型分没做截面标准化量纲吞并) |

### 关于「IC 0.03 是不是太垃圾」

**不是。** 日频 A 股，IC 0.03~0.08 就是有用的好因子。

- IC 0.03 ≈ 每天有 3% 的排名信息量，长期复利很可观
- IC 0.5 意味着「几乎预知未来」——那只有一种可能：**你用了明天的数据**

## 8. 每阶段的防作弊检查清单

### 阶段 1（第一个策略）

- [ ] 信号用的是 T 日收盘，成交用的是 T+1
- [ ] PE / 因子为负或缺失时，是剔除还是保留？想清楚了吗
- [ ] 成本三档都跑了，知道归零点在哪
- [ ] 换手率算出来了，知道一年交易多少次

### 阶段 2（因子研究）

- [ ] 每个因子都按年拆开看 IC，不是只看全样本
- [ ] 剔除了 ST / 停牌 / 上市不满 N 天的新股
- [ ] 分层收益是单调的（非单调不等于没用，但要能解释）
- [ ] IC 超过 0.15 的因子，逐个查过未来函数

### 阶段 3（组合与稳健性）

- [ ] 参数热力图上，好区域是「一片」还是「一个点」
- [ ] 样本外只跑了一次
- [ ] 持仓的行业分布检查过，不是全押一个行业
- [ ] 和 as16 / as26 在同区间、同费率下对比过

### 阶段 4（ML）

- [ ] 训练/测试是**按时间**切的，不是随机切
- [ ] 标签用的是未来收益，且与特征窗口不重叠
- [ ] 特征重要性前 10 名，能否逐个说出「为什么有用」
- [ ] 模型版样本外不如规则版时，**敢于承认**

### 阶段 5（模拟盘）

- [ ] 记录了「信号价 → 实际成交价」的滑点
- [ ] 统计了涨停买不进、跌停卖不掉的次数
- [ ] 模拟净值与回测净值的偏差，归因到了具体原因
