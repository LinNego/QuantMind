# 06 · 实验日志模板

> **在量化里，没有记录的实验等于没做。**
> 半年后你必须能复现任何一次实验，否则会在同一个坑上反复踩，而且不记得自己踩过。

配套文件：[experiments.csv](../experiments.csv)

---

## 1. 为什么必须记

| 不记的后果 | 具体表现 |
|---|---|
| **重复劳动** | 三个月后重新发现「原来这个因子在 2021 年就失效了」 |
| **无法定位问题** | 收益变差时，不知道自己改过什么 |
| **无意识过拟合** | 同一个参数被反复调了 20 次，却以为只调了 2 次 |
| **无法归因** | 不知道收益来自因子、行业、还是运气 |
| **无法说服自己** | 没有记录，你永远只能凭感觉判断 |

**这是量化研究里唯一「零成本、高回报」的纪律。** 每次实验多花 2 分钟。

---

## 2. 字段说明

| 字段 | 说明 | 示例 |
|---|---|---|
| `date` | 实验日期 | `2026-03-15` |
| `hypothesis` | **这次要验证什么假设**（一句话，别写「跑一下试试」） | `20日反转在剔除ST后仍有效` |
| `data_version` | 数据版本 | `L0-20260301` / `features_daily/daily_forward` |
| `factor` | 因子定义（公式，可复现） | `-(close/close.shift(20)-1)` |
| `params` | 关键参数 | `topk=30;reb=20;n_drop=0` |
| `period` | 回测区间 | `2018-01-01~2021-12-31` |
| `ic` | Rank IC 均值 | `0.0412` |
| `icir` | IC 均值 / IC 标准差 | `0.38` |
| `annual` | 年化收益（**含成本**） | `11.8%` |
| `sharpe` | 夏普 | `0.72` |
| `mdd` | 最大回撤 | `-18.4%` |
| `turnover` | 年化换手率 | `420%` |
| `cost` | 成本假设 | `万2.5+千1+滑点0.1%` |
| `conclusion` | **结论**（一句话，明确「成立 / 不成立 / 待验证」） | `成立但样本外衰减严重` |
| `next` | 下一步要验证什么 | `看 2022-2024 样本外` |

**最重要的两列是 `hypothesis` 和 `conclusion`。** 没有假设的实验是瞎跑，没有结论的记录是废纸。

---

## 3. 两条示例记录

| date | hypothesis | factor | params | period | ic | annual | conclusion |
|---|---|---|---|---|---|---|---|
| 2026-03-15 | 20日反转剔除ST后仍有效 | `-(close/close.shift(20)-1)` | `topk=30;reb=20` | 2018-2021 | 0.0412 | 11.8% | 成立，但换手 420% 太高，成本吃掉一半 |
| 2026-03-22 | 加 60 日动量能否提升稳定性 | `-rev20 + 0.5*mom60` | `topk=30;reb=20` | 2018-2021 | 0.0388 | 13.2% | IC 略降但回撤改善 4pct，**待查是否过拟合** |

**注意第二条的写法**：结论写的是「待查是否过拟合」，不是「效果更好」。
**这种「不确定」的记录比「成功」的记录更有价值。**

---

## 4. 反例：这些记录等于没记

| ❌ 无效记录 | 为什么无效 |
|---|---|
| `跑了一下动量，还行` | 没有因子定义、没有区间、没有指标 |
| `调参后年化从 12% 提到 15%` | 没说调了什么参数、调了几次 |
| `IC 0.06，不错` | 没有成本、没有样本外、没有对照 |
| `策略有效` | 没有区间、没有失效条件 |

---

## 5. 使用流程（每次实验 2 分钟）

```
1. 跑实验前：先写下 hypothesis（这一栏必须最先填）
2. 跑实验：记录 params / period / data_version
3. 看结果：填 ic / annual / sharpe / mdd / turnover / cost
4. 写结论：成立 / 不成立 / 待验证 + 原因
5. 写下一步：next
6. 追加一行到 experiments.csv
```

**第 1 步和第 4 步是关键。** 先有假设再有实验，是研究；先有结果再编假设，是自欺。

## 6. CSV 用法

### 追加一行（推荐用脚本）

```python
import csv, datetime

row = {
    "date": datetime.date.today().isoformat(),
    "hypothesis": "20日反转剔除ST后仍有效",
    "data_version": "L0",
    "factor": "-(close/close.shift(20)-1)",
    "params": "topk=30;reb=20",
    "period": "2018-01-01~2021-12-31",
    "ic": "0.0412", "icir": "0.38",
    "annual": "11.8%", "sharpe": "0.72",
    "mdd": "-18.4%", "turnover": "420%",
    "cost": "万2.5+千1+滑点0.1%",
    "conclusion": "成立，但换手过高",
    "next": "查 2022-2024 样本外",
}

with open("experiments.csv", "a", newline="", encoding="utf-8-sig") as f:
    csv.DictWriter(f, fieldnames=row.keys()).writerow(row)
```

### 回看（按指标排序，找最好的几次）

```python
import pandas as pd

df = pd.read_csv("experiments.csv")
df["annual_num"] = df["annual"].str.rstrip("%").astype(float)
print(df.sort_values("annual_num", ascending=False).head(10)[["date", "hypothesis", "annual", "conclusion"]])
```

### 统计「我调了多少次参」

```python
print("本月实验数:", len(df[df.date >= "2026-03-01"]))
# 如果一个月超过 30 条，说明你在刷参数，不是在研究
```

> **一个月超过 30 条实验，是一个危险信号**：说明你在用工程手段刷结果，而不是在验证假设。

---

## 7. 一条纪律

> **任何让你「惊喜」的结果，先记下来，然后去证明它是错的。**
> 记不下来又证明不了的，就是自欺。
