## 第 ① 问：这段代码用了未来数据吗？哪一行在保证时序？

### 为什么要问

未来函数是唯一能让策略「年化 34817%」的东西，而且**不报错**。你已经亲眼见过一次。

### 查什么

| 危险写法 | 说明 |
|---|---|
| `shift(-1)` / `shift(-5)` | 负数是往未来看，**一行就能毁掉全部结论** |
| `w * ret`（没有 shift） | 用当天收盘算的信号，去吃当天白天的涨跌 |
| `close.iloc[i+1]` | 直接用下一行 |
| 用「今天的成分股名单」回测过去 | 静态数据的事后信息 |
| `fillna(method='bfill')` | 向后填充 = 用未来的值补当前的洞 |

### 怎么验（跑这个对比）

```python
# 同一份数据，三种时序，跑出三个结果
print("无 shift  :", ((w        * ret).sum(axis=1).add(1).cumprod().iloc[-1]))
print("shift(1)  :", ((w.shift(1) * ret).sum(axis=1).add(1).cumprod().iloc[-1]))
print("shift(2)  :", ((w.shift(2) * ret).sum(axis=1).add(1).cumprod().iloc[-1]))
```

**判读标准：**

| 现象 | 结论 |
|---|---|
| `无 shift` 比 `shift(1)` 高好几倍 | **有未来函数**，必须修 |
| `shift(1)` 比 `shift(2)` 高很多 | 假设了「收盘算完立刻成交」，偏乐观 |
| 三者接近 | 时序处理基本干净 |

### 合格标准

- [ ] 代码里**没有** `shift(-N)`
- [ ] 权重和收益之间**至少隔了 1 天**
- [ ] 你能指着**某一行**说「就是这里保证的」

## 第 ② 问：股票池怎么过滤？ST / 停牌 / 新股 / 涨跌停怎么办？

### 为什么要问

**这四项是「你能不能真的买到」的问题。** 不处理，回测会买到现实中买不到的票。

### 逐个查

#### ST（亏损/风险警示股）

```sql
-- 数据在哪：features_daily.is_st（从 2016 年就有）
SELECT dt, count(*) AS n, count(*) FILTER (WHERE is_st = 1) AS n_st
FROM read_parquet('/opt/quantmind/data/quantdb/6_ml_datasets/features_daily/*/data.parquet',
                  hive_partitioning = true)
WHERE dt = 20241231 GROUP BY dt;
```

**怎么判**：如果代码里没有 `is_st` 过滤，检查你的股票池有没有把 ST 股算进去。ST 股涨跌停是 ±5%，而且经常停牌。
**这份数据的实测值**：2024-12-31 全市场 **100 只** ST 股。

#### 停牌

```sql
-- 停牌日的特征：有行、有收盘价、但成交量 = 0
SELECT count(*) FROM read_parquet(
  '/opt/quantmind/data/quantdb/1_kline_data/daily_unadjusted/*/data.parquet',
  hive_partitioning = true) WHERE volume = 0;
-- → 254 条
```

**怎么判**：停牌日的价格不动，如果你不剔除，`pct_change()` 会给出 0% 收益，而且你「买」了它。

#### 新股

```sql
-- list_date 在 features_daily 里，是字符串 'YYYYMMDD'
SELECT symbol, list_date, dt
FROM read_parquet('/opt/quantmind/data/quantdb/6_ml_datasets/features_daily/*/data.parquet',
                  hive_partitioning = true)
WHERE dt = 20241231 AND list_date > '20241001' LIMIT 5;
```

**怎么判**：新股上市前 5 天无涨跌幅限制，且波动极大。**至少剔除上市不满 60 个交易日**的。
**实测值**：2024-12-31 有 **22 只** 上市不满 3 个月的股票。

#### 涨跌停

```sql
-- zt_price / dt_price 是最准的（按板块算好了），但只有 2026 年之后才有
SELECT symbol, dt, zt_price, dt_price
FROM read_parquet('/opt/quantmind/data/quantdb/6_ml_datasets/features_daily/*/data.parquet',
                  hive_partitioning = true)
WHERE dt = 20261023 AND symbol = '600036.SH';
```

**历史区间没有这两列**，得自己按板块算：

| 板块 | 涨跌停 |
|---|---|
| 主板（60/00 开头） | ±10% |
| 创业板（30）/ 科创板（68） | ±20% |
| 北交所（43/83/87/88/92） | ±30% |
| ST | ±5%（2026-07 后主板改 ±10%） |

### 合格标准

- [ ] 代码里能看到 **4 个过滤条件**（ST、停牌、新股、涨跌停）
- [ ] 每个过滤都能说出「剔掉了多少只/多少行」
- [ ] 你能回答：**如果涨停买不进，我的回测会少赚多少？**

### 常见的错

| 错法 | 后果 |
|---|---|
| 完全不剔 | 买入一堆买不到的票，收益虚高 |
| 只在选股时剔，持仓时不剔 | 停牌股一直挂着，权重失真 |
| 用今天的 ST 名单回测 2016 年 | ST 状态是会变的，要按日期查 |

## 第 ③ 问：成本哪几项算进去了？滑点假设多少？

### 为什么要问

**这是「年化 25% 变成 3%」的直接原因。**

### 四项必须齐

| 项 | 费率 | 方向 | 代码里叫什么 |
|---|---|---|---|
| 佣金 | 万 2.5（0.025%），**最低 5 元/笔** | 买卖双向 | `commission` |
| 印花税 | 万 5（0.05%） | **仅卖出** | `stamp_duty` / `stamp` |
| 过户费 | 万 0.1（0.001%） | 买卖双向 | `transfer_fee` |
| 滑点 | 0.05%~0.2%/边 | 买卖都有 | `slippage` |

### 怎么验

```python
# 看成本占总收益的比重
total_gross = (gross_ret * 100).sum()
total_cost  = (cost * 100).sum()
print(f"毛收益 {total_gross:.1f}%  成本 {total_cost:.1f}%  占比 {total_cost/total_gross:.0%}")
```

**判读：**

- 成本占比 < 10% → 换手很低，成本不敏感
- 成本占比 30%~60% → 正常
- **成本占比 > 100% → 策略是负的，别看了**

### 三个常见错

| 错法 | 后果 |
|---|---|
| 只算佣金，漏印花税 | 少算卖出时 0.05%，高频策略完全失真 |
| 印花税按双向算 | 多算一倍，好策略被误杀 |
| 漏滑点 | 假设你能按收盘价成交，实际不能 |
| 用「万分之几」当「元」 | 单位错了 1 万倍 |

### 合格标准

- [ ] 4 项都能在代码里找到
- [ ] 你能说出 **一年换手多少次**
- [ ] 你能说出 **成本吃掉了多少年化收益**

## 第 ④ 问：回测区间从哪到哪？热启动怎么处理？

### 为什么要问

**前 20 天是空的**，如果你按整个区间算年化，会被稀释；如果你让它参与统计，结果是假的。

### 怎么查

```python
# 第一个有信号的日期
first_signal = w.abs().sum(axis=1).gt(0).idxmax()
print("第一个有持仓的日期:", first_signal)
print("距回测起点多少个交易日:", list(w.index).index(first_signal))
```

**合格：** 这个数字应该 ≈ 因子窗口长度（20 日因子 → 约 20 天）。

### 取数区间 vs 统计区间

```python
# ❌ 错：区间 2020-2024，只取 2020 起
WHERE dt BETWEEN 20200101 AND 20241231

# ✅ 对：多取 2 个月喂因子
WHERE dt BETWEEN 20190901 AND 20241231
```

**记住：取数要比统计区间早「因子窗口 + 调仓周期」那么多天。**

### 合格标准

- [ ] 能说出 **取数区间** 和 **统计区间** 两个数字
- [ ] 热启动期被**剔除**，不参与年化计算
- [ ] 知道 2025 之后的数据是 holdout，**设计时不许看**

## 第 ⑤ 问：这个结果如果是假的，会在哪个数字上露馅？

### 为什么要问

**先想好怎么证伪，再看结果。** 否则你会被好看的曲线说服。

### 四条红线（任一触发，立刻停下查）

| # | 现象 | 先怀疑 | 立刻做什么 |
|---|---|---|---|
| 1 | IC 绝对值 **> 0.15** | 未来函数 | 查 `shift` 方向、复权口径、成交价时点 |
| 2 | 年化 **> 50%** 或夏普 **> 3** | 回测有 bug | 查成本、涨停可成交性、幸存者偏差 |
| 3 | 样本外衰减 **> 50%** | 过拟合 | 减参数、拉长区间、只留最硬的因子 |
| 4 | 融合信号与某组分相关性 **≈ 0.999** | 量纲吞并 | 标准化后再融合 |

### 必做的三个对照

```python
# 对照 1：和「等权全市场」比 —— 你跑赢基准了吗？
# 对照 2：和「随机选 30 只」比 —— 你比瞎选强吗？
# 对照 3：和 as16 / as26 比 —— 同区间同费率
```

**如果跑不赢「随机选」，那你的因子就是噪音。**

### 合格标准

- [ ] 你能提前说出「如果这个结果是假的，我第一眼会看到什么」
- [ ] 有一个明确的对照组
- [ ] 样本外只跑过一次（想跑第二次时，先在日志里写「我现在要用掉样本外了」）
