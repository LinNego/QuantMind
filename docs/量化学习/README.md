## 四、一分钟摘要

1. **这个仓库是成品系统，不是教材。** 把它当「数据源 + 参照物 + 对照组」。
2. **数据免费，11 GB，你手上已有 23 张表**（2016-01-04 ～ 2026-10-23）。
3. **量化不是编程问题，是统计问题。** 会写代码不构成优势，反而是「做出漂亮假回测」的高危人群。
4. **不要先学 ML。** 前 12 周学的是「怎么不被自己骗」。
5. **三道 Gate 不许跳。** 过不了就停在原地补。

## 五、自检红线（贴在屏幕上）

| 现象 | 先怀疑什么 |
|---|---|
| IC 绝对值 > 0.15 | 未来函数 |
| 年化 > 50% 或夏普 > 3 | 回测有 bug（成本 / 涨停 / 幸存者偏差） |
| 样本外衰减 > 50% | 过拟合 |
| 融合信号与某组分相关性 ≈ 0.999 | 量纲吞并 |

**在量化里，"结果太好"是 bug 报告，不是好消息。**
