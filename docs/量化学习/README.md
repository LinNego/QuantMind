# QuantMind 量化学习文档（零金融 / 零 ML 背景版）

> 面向对象：**有后端软件开发背景，但没有金融、没有机器学习背景**，想借这个仓库系统入门量化、深入、并最终尝试稳定盈利的人。

这套文档是从一次完整的讨论整理出来的，**不是 QuantMind 的产品文档**，也不介绍怎么部署整套系统。它只回答四个问题：

1. 这个仓库到底是什么，我能从里面拿什么？
2. 那 60GB 数据怎么最快弄到手、怎么搬到另一台机器？
3. 量化到底在干什么，我需要哪些概念？（软件工程师视角）
4. 我该怎么一步步学，怎么判断自己没在骗自己？

---

## 一分钟摘要（如果只看五句）

1. **这个仓库是成品系统，不是教材。** 把它当「数据源 + 参照物 + 对照组」，核心研究用 `pandas + qlib` 自己写。
2. **数据是免费的（ModelScope，约 60GB），增量才收费。** 你 90% 的场景只需要其中 15~20GB 的一个子集。
3. **量化不是编程问题，是统计问题。** 你会写代码不构成优势，反而是「做出漂亮假回测」的高危人群。
4. **不要先学机器学习，更不要碰深度学习。** 前 12 周学的是「怎么不被自己骗」，第 13 周才轮到模型。
5. **三道 Gate 不许跳。** 过不了就停在原地补，往前冲的代价是几个月的时间和真金白银。

## 这套文档的三条规矩

### 规矩一：Gate 是硬门禁

[05-学习计划.md](05-学习计划.md) 里有三道 Gate。**过不了不许往下走**，因为后面每个阶段都建立在前面的正确性上。跳过去的代价，是三个月后你发现全部要重做。

### 规矩二：自检红线贴在屏幕上

来自 [03-常见陷阱与自检红线.md](03-常见陷阱与自检红线.md)：

| 现象 | 先怀疑什么 |
|---|---|
| IC 绝对值 > 0.15 | 未来函数 |
| 年化 > 50% 或夏普 > 3 | 回测有 bug（成本/涨停/幸存者偏差） |
| 样本外衰减 > 50% | 过拟合 |
| 融合后信号与某个组分相关性 ≈ 0.999 | 量纲吞并（等于删掉了另一个组分） |

**在量化里，"结果太好"是 bug 报告，不是好消息。**

### 规矩三：实验日志从第一次实验就开始记

见 [06-实验日志模板.md](06-实验日志模板.md) 与 [experiments.csv](experiments.csv)。半年后你必须能复现任何一次实验，否则会在同一个坑上反复踩，而且不记得自己踩过。

## 关于这个仓库的两个前提

**① 免费的部分足够你学满 12 周。**
全量数据走 ModelScope 公开数据集，纯 HTTP、不需要任何 API Key；只有「每日增量」才需要付费的 `QUANTDB_API_KEY`。而且日线级别的增量还有一条免费兜底链（baostock / akshare），详见 [01-数据获取与迁移.md](01-数据获取与迁移.md)。

**② 许可证是 AGPL v3。**
自己学习、研究、甚至自用交易都没问题。但如果你将来想基于它做**闭源产品**或对外提供服务，AGPL 要求你开源修改。要商业化，趁早规划自研替代方案。
