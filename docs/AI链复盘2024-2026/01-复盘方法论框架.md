# 2024–2026 A股 AI 链大行情 · 复盘方法论与系统框架

> 版本 v0.1（框架稿，未接数据）
> 复盘对象：2024-01 至 2026-10 的 AI 产业链行情，含 10 倍股 / 5 倍股群体
> 本文件只解决一件事：**复盘怎么做才算复盘，而不是把涨幅榜和新闻重讲一遍。**

---

## 0. 复盘的定义：先定"要回答什么问题"

绝大多数"复盘"失败在两个地方：**只有事实层（谁涨了多少）没有机制层**，以及**用今天的信息解释昨天的决策（后视镜偏差）**。

我们这次复盘只回答四类问题，每类都要有可证伪的答案：

| 编号 | 问题 | 产出 | 不合格的表现 |
|---|---|---|---|
| Q1 | **涨了什么、怎么涨的**：谁、多少倍、什么节奏、什么路径 | 事实表 + 时间轴 | 只报"最高涨幅"，不讲回撤和路径 |
| Q2 | **为什么是它、为什么是那时**：业绩、估值、产业事件各贡献多少 | 归因表 | "因为 AI 景气"这种同义反复 |
| Q3 | **当时能不能看出来**：什么信号领先、什么信号滞后、什么信号是噪音 | 信号表（含失效信号） | 只用事后才知道的信息 |
| Q4 | **下次怎么用**：能写成 if-then 的规则，和明确的反例 | 规则库 | "要选龙头""要拿得住"这种废话 |

**判定标准**：每条结论必须能被"当时的可获得信息集"支持；做不到的，标注为"事后归因"，单独放一章。

## 1. 一句话骨架

> **一条主线、两个时钟、三层切分、四张表、五道检验。**

```
                 ┌──────────── 两个时钟 ────────────┐
 产业时钟（季度）   capex → 订单 → 收入 → 利润 → 产能
 市场时钟（周-月）  流动性 → 风险偏好 → 资金 → 拥挤 → 反转
                 └──────────────────────────────────┘
                              ↓ 对齐
 一条主线：产业景气 → 业绩兑现 → 估值重估 → 资金正反馈 → 拥挤 → 分化/双杀
                              ↓
 三层切分：时间轴（阶段） × 横截面（环节/龙头） × 纵深（EPS vs PE）
                              ↓
 四张表：事实表 / 归因表 / 信号表 / 规则表
                              ↓
 五道检验：基准 / 幸存者 / 反事实 / 可执行 / 样本外
```

**两个时钟是这套框架的核心。** 这轮行情里最常见的错误，是拿"市场时钟"（情绪、资金、政策）去解释一个"产业时钟"（capex、订单）驱动的行情——于是每次回调都喊结束，每次反弹都喊第二波。复盘要把两个时钟分开测，再测它们的**领先滞后关系**（经验上股价领先基本面拐点 1–2 个季度，但需要本数据验证，不能预设）。

## 2. L0 基准与样本：先堵住三个偏差

这一层不产出结论，只产出"可信度"。跳过这层，后面所有数字都不可信。

### 2.1 三个必须处理的偏差

| 偏差 | 表现 | 处理办法 |
|---|---|---|
| **后视镜偏差** | 用 2026 年的"AI 链名单"去回看 2024 年，天然选出赢家 | **Point-in-time 股票池**：以 2024-01-01 当天已上市、且当时主营可归入 AI 链的股票为池；后续新上市的单独列"次新组"，不混入统计 |
| **幸存者偏差** | 只统计涨的，不统计退市、ST、腰斩的 | 失败样本必须入表：同期 AI 概念池里涨幅 <50%、或先涨后腰斩的，单列一章 |
| **口径偏差** | 前复权/后复权/不复权混用；除权、送转、定增导致"看起来 10 倍" | 口径写死（见 2.3），全文一个口径；送转造成的价格跳变单独标注 |

### 2.2 样本池怎么划（关键，决定结论上限）

不要用概念板块标签（"CPO 概念"220 只、"人工智能"1075 只），噪音太大。用**主营业务卡位**，按产业链位置分层：

| 层 | 环节 | 代表性子行业 | 归类依据 |
|---|---|---|---|
| **A. 海外算力链** | 光互联 | 光模块、光芯片、光纤连接器、CPO/硅光 | 海外大客户收入占比 |
| | 承载 | 高多层 PCB、HDI、覆铜板、铜连接/线缆 | AI 服务器/交换机料号 |
| | 整机与配套 | AI 服务器代工、电源、液冷、机柜 | 订单可见度 |
| **B. 国产算力链** | 芯片 | GPU/NPU、CPU、ASIC、存储 | 国产替代/信创订单 |
| | 制造与设备 | 晶圆代工、封测、半导体设备/零部件/材料 | 产能与资本开支 |
| | 基础设施 | IDC、智算中心、交换机、光通信设备 | 集采/招标 |
| **C. 应用与终端** | 端侧 | AI 手机/PC、AI 眼镜、SoC、模组 | 出货量 |
| | 软件应用 | Agent、办公、医疗、传媒、营销 | 付费/DAU（多数证伪） |
| **D. 配套** | 电力与散热 | 变压器、UPS、柴发、液冷、温控 | 智算中心配套 |

**归类规则**：
1. 以 2024-01-01 的主营收入结构为准（用当期年报/半年报），不用后来的转型故事；
2. 一家公司只归一个主环节，避免重复计数；
3. 主业占比 <30% 的，标为"沾边"，单独统计（这组的表现本身就是重要结论：**沾边股在行情末段才涨，且回撤最深**）。

### 2.3 涨幅口径（写死，否则全文数字互相打架）

| 指标 | 定义 | 用途 |
|---|---|---|
| **区间收益** | 首日收盘 → 末日收盘，**后复权**（含分红送转） | 主指标，可比 |
| **最大涨幅（max drawup）** | 区间内 最低收盘 → 其后 最高收盘 的最大比值 | 对应"10 倍股"叙事，必须同时给出**起止日期** |
| **真实路径涨幅** | 从"起涨点"到"最高点"，且起涨点须满足"前 60 日跌幅 >20%"或"创新低后首根放量阳线"，防止把任意低点当起点 | 更接近可交易收益 |
| **最大回撤** | 区间内峰值到谷底的最大跌幅 | 区分"能拿住"和"拿不住" |
| **年化 / 上涨天数占比 / 主升段斜率** | 主升段定义为连续 20 日收益 >X% 且成交放大 | 刻画节奏，不用来看收益 |

> **口径提示**：本数据集里 `daily_backward` 与 `daily_forward` 的比值一致（同为含分红的总收益口径），但不复权价格会因送转出现"假 10 倍"。所有榜单统一用后复权，另附不复权价供对照。

### 2.4 终点倍数 vs 峰值倍数：两个问题，两套答案（v0.2 新增）

这是本套文档最容易出错的地方，单列一节。

| 口径 | 公式 | 回答的问题 | 适合的结论 |
|---|---|---|---|
| **终点倍数 [终]** | 末日收盘 ÷ 起点收盘 | "一直拿到今天能赚多少" | 评价持有收益、β 收益 |
| **峰值倍数 [峰]** | 区间最高收盘 ÷ 起点收盘 | "卖在最高点能赚多少" | 评价产业弹性、α 上限 |
| **真实路径 [径]** | 起涨点 → 最高点，且起涨点需满足放量条件 | "一个可交易的人能赚多少" | 评价策略可实现性 |

**同一批股票，三种口径能差 5 倍：**

| 指标 | [终] | [峰] |
|---|---|---|
| >5 倍 | 115 只 | **576 只** |
| >10 倍 | 15 只 | **108 只** |

**纪律：**
1. 全文所有倍数必须带口径标签，不带的不引用；
2. 讲"产业弹性"用 [峰]，讲"能不能赚到"用 [终] 或 [径]；
3. **[峰] 与 [终] 的差值本身就是结论**——差值越大，说明"卖点比买点更重要"。

> 本轮 [峰] 576 只 vs [终] 115 只，差 4 倍——**这个差距量化了"不会卖"的代价**。

## 3. L1 事实层：时间轴 + 横截面

### 3.1 时间轴切分：两套方法互相校验

**方法 A：事件锚点法（外生）**——先列候选锚点，再用数据筛掉"市场没反应"的：
- 产业侧：北美四大 CSP capex 指引上修、英伟达业绩/指引、台积电月度营收、光模块大厂出货指引、国产 GPU 流片/量产、运营商集采
- 市场侧：政策转向、关税/出口管制、DeepSeek 类技术冲击、指数级别放量突破
- 流动性侧：降准降息、两融政策、汇金/平准

**方法 B：数据锚点法（内生）**——不预设事件，用状态机切段：
1. 构造 AI 链等权指数 + 成交额占比序列；
2. 用滚动 20 日动量方向 + 波动率跃迁 + 领涨股更替，识别 regime 切换；
3. 切出的段，再回头找"那段时间发生了什么"，而不是先有故事再切段。

**两套方法必须给出一致的段数**，不一致的地方就是复盘的重点（往往是"事件很重要但市场没交易"或"市场先动了但事件还没发生"）。

### 3.2 段内要填的六件事

每一段都要回答，缺一不可：

1. **领涨环节**：这一段的钱去了产业链的哪一层？（上游/中游/下游/配套）
2. **领涨个股**：Top10 涨幅、市值分布、是否换人（龙头更替是段切换的最强信号）
3. **扩散度**：上涨家数占比、涨幅中位数 vs 均值（均值远高于中位数 = 少数股票拉动 = 行情不健康）
4. **量能**：板块成交额占全 A 比重、换手率分位
5. **波动结构**：日内振幅、涨停/跌停家数、连板高度
6. **估值位置**：板块 PE/PB 分位、龙头 PE 相对自身历史

### 3.3 横截面：龙头—跟风—补涨的三段结构

产业趋势行情的典型结构（需本数据验证，不可直接套）：

```
第 1 波：机构定价，龙头（业绩最先兑现、市值最大）领涨，涨幅 2-4 倍，回撤浅
第 2 波：二线（同一环节、弹性更大、市值更小）接力，涨幅 3-5 倍，波动加大
第 3 波：沾边股/低位股/跨界并购股补涨，涨幅 1-2 倍但回撤 50%+，行情见顶标志
```

复盘的输出不是"确认了这个结构"，而是量化它：**每一波的领涨股市值中位数、业绩增速中位数、机构持仓变化、持续天数**。如果第 3 波的特征（低业绩、高换手、高波动、大股东减持）提前出现，就是减仓信号。

## 4. L2 归因层：把"涨"拆成 EPS 和 PE

### 4.1 核心分解

对每个阶段、每只股票：

```
Δln(Price) = Δln(EPS_TTM) + Δln(PE_TTM)
```

- **EPS 贡献 > 60%** → 业绩驱动（可持续，回调可买）
- **PE 贡献 > 60%** → 估值驱动（依赖流动性和叙事，需跟踪拥挤度）
- **EPS 不动、PE 暴涨** → 纯故事（末段特征，必须单列）
- **EPS 涨、PE 跌** → 杀估值但业绩兑现（往往是行情中段的"黄金坑"）

要求：**按阶段分别算，再算全区间**。全区间数字会掩盖"先杀估值后杀业绩"这种关键结构。

### 4.2 产业验证：把股价拐点和基本面拐点对齐

| 验证维度 | 数据 | 判读 |
|---|---|---|
| 海外 capex | 四大 CSP 季度 capex 与指引 | 指引上修 → 领先股价 1 个季度 |
| 算力出货 | 英伟达数据中心收入、台积电 HPC 营收、ODM 出货 | 是"预期"还是"兑现" |
| 光模块 | 出货量、单价、800G/1.6T 占比 | 量价齐升 = 真景气；只有量 = 价格战 |
| PCB | 高多层板产能利用率、单价 | 产能瓶颈 = 涨价逻辑 |
| 国产算力 | 运营商/政府智算招标金额、国产 GPU 出货 | 国产链的"订单—收入"转化率 |
| 应用 | 付费用户、token 调用量、ARR | 大多数应用公司到此证伪 |

**关键产出**：一张"股价 vs 基本面"的领先滞后表——哪些指标领先股价、哪些同步、哪些滞后。这决定了下一次该盯什么。

### 4.3 估值体系迁移

不要只算 PE 分位（AI 链的 PE 分位长期失效），要算：

- **PE 中枢迁移**：阶段 1 的 20–30x → 阶段 3 的 50–80x，中枢抬升本身是"重估"还是"泡沫"，用 **PEG** 和 **增速二阶导** 判断
- **市值天花板法**：对标海外可比公司（Coherent/Lumentum/Fabrinet/Celestica/Vertiv 等）的市值/收入倍数，算"还有多少空间"
- **单位产能/单位订单估值**：市值 ÷ 产能、市值 ÷ 在手订单，用于制造业属性强的环节
- **隐含预期反推**：当前市值隐含未来 3 年复合增速是多少？这个增速产业能不能给？

## 5. L3 交易层：资金、情绪、拥挤、筹码

### 5.1 四类指标

| 类别 | 指标 | 阈值用法 |
|---|---|---|
| **资金** | 两融余额及占流通市值比、ETF 份额变化、公募季报 AI 持仓比例、龙虎榜游资净买 | 两融占比创新高 + 融资买入占比 >12% → 过热 |
| **情绪** | 板块成交额/全 A 成交额、换手率分位、涨停家数、连板高度、新增开户 | 成交占比 > 历史 95 分位 → 拥挤 |
| **拥挤** | 分析师覆盖数、研报数量、基金重仓集中度、一致预期上调幅度 | 覆盖数翻倍 = 预期已充分 |
| **筹码** | 大股东减持公告、定增/解禁规模、股权质押比例、限售解禁日历 | 减持潮 = 产业资本认为贵 |

### 5.2 节奏信号：主升浪的三段式

```
加速（斜率变陡、量能放大） → 背离（价格新高、量能/龙头不新高） → 破位（跌破 20 日线且反抽无力）
```

可量化的背离检测：
- 价格创 60 日新高，但板块成交额未创新高
- 龙头创新高，但板块上涨家数占比下降（扩散失败）
- 涨幅居前个股从"有业绩"切换到"无业绩"
- 融资余额增速 > 股价涨幅（杠杆追高）

### 5.3 顶部信号清单（做成打勾表，命中 ≥4 项即预警）

- [ ] 板块成交额占全 A 比重创历史新高
- [ ] 龙头股 PE 超过海外可比公司 2 倍
- [ ] 产业资本（大股东/高管）减持金额创年度新高
- [ ] 卖方研报数量/覆盖分析师数同比翻倍
- [ ] 出现"市值超越国际巨头"的叙事
- [ ] 二线/沾边股单周涨幅超过龙头
- [ ] 融资买入额占成交额比重 >12%
- [ ] 产业数据（capex/出货）增速二阶导转负

## 6. L4 规则层：把复盘变成 if-then

每条规则必须写成可回测的形式，包含：**触发条件、标的、仓位、退出条件、失效条件**。

### 6.1 待验证的五条假设（本轮行情提出，用数据检验）

| # | 假设 | 检验方法 |
|---|---|---|
| H1 | 产业趋势行情中，**业绩兑现最快的环节**涨幅最大，而非"想象空间最大"的环节 | 按环节算 EPS 贡献 vs 涨幅，做散点 |
| H2 | 龙头切换（领涨股更替）**领先**板块见顶 1–2 个月 | 事件研究：每次龙头更替后的板块收益 |
| H3 | 行情末段，**低业绩高弹性**组跑赢高业绩组，且回撤更大 | 分组的最后 3 个月收益与回撤 |
| H4 | 海外 capex 指引上修对 A 股映射的**持续性**取决于国内是否有对应环节的产能 | 分组：有产能 vs 纯概念 |
| H5 | 拥挤度（成交占比分位）对**未来 20 日收益**有显著负向预测力，但对**未来 60 日**不显著 | 分位数组合的 forward return |

### 6.2 规则模板

```
IF  产业指标（capex/订单/出货）二阶导 > 0 且 股价尚未突破前高
THEN 买入该环节业绩弹性最大的前 2 只（市值 100–500 亿），仓位 X%
EXIT 1) 产业指标二阶导转负；2) 拥挤度 >95 分位且出现量价背离；3) 跌破 60 日线
FAIL 若 3 个月内订单未转化为收入，视为逻辑破坏，无条件退出
```

## 7. L5 检验层：五道关

| 检验 | 问题 | 做法 |
|---|---|---|
| **基准** | 超额收益到底来自哪 | 对比沪深 300、中证 1000、等权全 A、AI 主题 ETF |
| **幸存者** | 失败样本长什么样 | 同期概念池内跑输组的特征（市值、业绩、减持、商誉） |
| **反事实** | 不买 AI 买什么 | 同期最强非 AI 板块（如红利、周期）的对照 |
| **可执行** | 真能赚到吗 | 涨跌停、流动性（日均成交额）、停牌、买入时点（T+1） |
| **样本外** | 框架是否普适 | 用 2019–2021 新能源行情跑同一套流程，看结论是否同构 |

## 10. 需要先拍板的四个口径

1. **复盘对象**：只做 AI 硬件链（海外算力 + 国产算力 + 配套），还是含应用/终端？
2. **时间起点**：2024-01-01（本轮起点）／2023-03（ChatGPT 首波，用于对照）／2024-09-24（政策底）？
3. **"10 倍股"定义**：区间收益 ≥900%，还是最低→最高 ≥900%（后者会把"先腰斩再翻倍"也算进去）？
4. **交付形态**：研究型报告（重结论）／数据看板（重可查）／可回测规则库（重可执行）？

> 建议默认：**A+B+C 全链但分三层统计**；起点 **2024-01-01，附 2023 对照段**；"10 倍"用 **最低→最高且起涨点需满足放量条件**；交付 **报告 + 数据表 + 规则库三件套**。
