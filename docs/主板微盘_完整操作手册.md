# 主板微盘 + 全天候 · 完整操作手册

> 本文是这套策略的**唯一操作依据**。所有规则在此定死，不再临场判断。
> 版本：2026-11-06 ｜ 适用资金：5 万 ~ 15 万

---

## 一、策略是什么

两条腿，一个引擎一个压舱石：

```
微盘 15 只（收益引擎）
   沪深主板 · 市值最小 15 只 · 等权 · 月初调仓
   + 国证2000 MA200 择时（下方半仓）
   + 1 月半仓 / 4 月空仓
   + 每只 +20% 触价止盈

全天候底仓（压舱石）
   城投债 65% / 黄金 15% / 红利 10% / 纳指 10%
   与微盘月度相关性 −0.07，微盘最差月份里平均 +0.74%
```

**微盘仓位之外的每一分钱，都在全天候里。不留现金空转。**

## 二、资金怎么分（唯一变量：e）

### 2.1 e 的规则（月末收盘后定，下月生效）

| 条件 | 微盘 e | 全天候 1−e |
|---|---|---|
| **4 月**（不管均线） | **0** | 100% |
| **1 月**（不管均线） | **0.5** | 50% |
| 其它月，国证2000 ≥ MA200 | **1.0** | 0% |
| 其它月，国证2000 < MA200 | **0.5** | 50% |

> ⚠️ 1 月且 MA200 下方 → **仍是 0.5，不是 0.25**。

### 2.2 两个金额

```
微盘目标   = 总资产 × e
全天候目标 = 总资产 × (1 − e)
总资产     = 微盘市值 + 4个ETF市值 + 现金
```

## 四、月初调仓：完整流程

> **时间线**：月末最后交易日收盘算信号 → **次月第一个交易日开盘**执行。

### T-1 日（月末最后交易日）15:30 之后

```
① 查国证2000 收盘价 和 它的 MA200
   → 定下个月的 e（按 §2.1）

② 算总资产
   = 14~15 只微盘市值 + 4 个 ETF 市值 + 现金

③ 算目标
   微盘目标   = 总资产 × e
   全天候目标 = 总资产 × (1 − e)

④ 生成微盘名单（市值最小 15 只，跑信号脚本）
   ★ 不要手工选，不要凭感觉

⑤ 算出四张清单
   微盘：要买哪几只、每只几手、要卖哪几只
   全天候：4 个 ETF 各自的目标手数 = 目标金额 ÷ 一手价，向下取整
```

### T 日（次月第一个交易日）9:30 开盘

```
⑥ 先卖
   卖出微盘里跌出名单的
   卖出超配的 ETF

⑦ 再买
   先买 ETF（1,045 / 825 / 337 / 216，好凑）
   再买微盘（整手约束，用剩下的钱凑）

⑧ 挂止盈单
   每只新买入的微盘股，立刻挂「最新价 ≥ 成本 × 1.20 → 卖出」条件单
   有效期选「长期有效」

⑨ 15:30 后对账
   实际成交价、滑点、未成交原因
   填记录表（§七）
```

### 4.1 为什么先 ETF 后微盘

微盘有整手约束，最后一笔必然剩零头。
**先用 ETF 把大头花掉，微盘用零头凑，才不会剩一堆闲钱。**

## 五、月中：止盈的钱怎么处理

### 5.1 止盈怎么触发

```
盘中最新价 ≥ 成本 × 1.20
    → 券商条件单自动按市价卖出
    → 一分钱都不用你判断
```

### 5.2 钱到手后怎么办（本节是重点）

```
当天收盘前，用这笔钱买城投债 511220
    → 能买几手买几手（1 手 1,045）
    → 剩余零头留现金
    → 零头累计够 1,045 再补一手
```

### 5.3 为什么是城投债，不是逆回购

| | 城投债 511220 | 逆回购 131810 |
|---|---|---|
| 门槛 | 1,045/手 | 1,000 起，1000 整数倍 |
| 操作 | **买一次，不用管** | **每天要滚动** |
| 收益 | 4.2% | 1.8% |

**一笔止盈回收约 1,700~2,000 元，正好买 1~2 手城投债。**

### 5.4 两个例外

**① 距月末 ≤ 2 个交易日 → 留现金，不要买**

反正月末就要调仓，买了又要卖，白付两次手续费。

**② 下个月 e = 1.0（满仓）→ 也留现金**

因为月末这笔城投债要卖掉换微盘，没必要先进后出。

> 判断方法：看当前是不是 12 月末（下月 1 月）、3 月末（下月 4 月）、
> 或国证2000 已站上 MA200。

### 5.5 止盈后的微盘仓位会低于 e

这是**设计如此**，不是异常。

```
策略原意：卖出 → 现金等到月末 → 月末按新信号重新分配
本手册：  卖出 → 城投债等到月末 → 月末按新信号重新分配
```

行为一致，只是这半个月钱不空转。

## 六、其他月中情况

| 情况 | 怎么处理 |
|---|---|
| **持仓一字跌停** | 不假设能卖出；能卖再卖，卖不掉持有 |
| **持仓停牌** | 保留，按最后收盘价估值；复牌后再处理 |
| **持仓变 ST** | 下一个可交易日卖出，钱进城投债 |
| **目标股一字涨停** | 放弃，不追；用备选补位 |
| **退市风险** | 监控公告，`is_quit_risk` 字段基本是空的，不能只靠它 |
| **组合回撤 > 25%** | 降到半仓（e 手动乘 0.5） |
| **组合回撤 > 35%** | 暂停，复盘后再开 |

## 九、禁止事项

- ❌ **月中因为"看着要跌"就降仓位** —— 只有月末才算
- ❌ **改全天候权重**（比如"纳指涨多了少买点"）—— 固定 65/15/10/10
- ❌ **改止盈阈值**（20% → 25%）—— 15~30% 是平台，改了就重新过拟合
- ❌ **止盈后不处理**，让钱躺着 —— 当天买城投债
- ❌ **为了用完零头买贵的票** —— 宁可留现金
- ❌ **用国债 ETF 代替城投债** —— 一手 14,145，买不起
- ❌ **补充微盘时手工选股** —— 必须跑信号

## 附录 A：为什么微盘仓位总是比目标少一点

**现状（2026-11-06）：**

```
微盘目标  25,715   （总资产 51,430 × e 0.5）
微盘实际  21,765
差         3,950
```

**三个原因，都不是错误：**

| # | 原因 | 金额 |
|---|---|---|
| ① | **建仓时整手约束**：25,000 预算，整手只能买进 22,493 | −2,507 |
| ② | **止盈卖出**：002529 卖掉后市值减少（钱变成现金） | −2,160 |
| ③ | **浮盈**：剩余 14 只赚了，抵消一部分 | +889 |
| | 净差 | ≈ −3,778 |

**怎么处理：**

1. **不要为了"凑满目标"去买贵的票** —— 宁可留现金
2. 差额在**月末调仓时补回**（从候选名单第 15 名往后补）
3. 长期低于目标是**正常状态**，不必每月强行配平

> 这也解释了为什么 e=0.5 时实际只有 42.3% —— 差额会一直存在，
> 只要不越界（比如 e=1.0 时只有 0.8），就不用干预。
