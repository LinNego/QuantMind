### 1.4 四个方法学缺口（本细案要修的）

**缺口 A：选型窗口与测试窗重叠（最严重）**

- 研究 300 的选型窗口：**2025-09-01 .. 2026-09-10**（`training_selection_300.json` 的 `params.window_start/window_end`）。
- Cross300 固定切分：train 2016-01-04..2023-06-18，valid 2023-06-29..2025-01-21，**test 2025-02-01..2026-08-28**。
- 两者重叠 **2025-09-01..2026-08-28**，约 **240 个交易日**，恰好覆盖 test 窗的绝大部分。
- 后果：Cross300 的 test RankIC 0.21–0.23 **不能当作无偏的模型能力**；它是「在同一段数据上先挑因子、再测模型」的结果。用于**同一选型下的模型之间横评**仍然有效（大家同一起跑线），但不能用来回答「这套因子在新数据上还行不行」。
- 同理，2026-10-16 那次训练的 split（train 2020-01..2025-11，valid 2025-12..2026-06，test 2026-06..2026-09）也与选型窗重叠，其 test 指标同样含选型泄漏；训练段也间接受影响——因子是在训练窗末尾之后的表现上挑出来的。
- **修复**：选型只用 2016-2024；2025 做模型选择/调参；2026-01..2026-10-19 做一次性 holdout。并重算一套 **Clean300**（用同一 20261016 算法、选型窗截到 2024-12-31、近期窗取 2023-01..2024-12，其余参数不变）作为公平 champion。

**缺口 B：冗余只做到值层**

现有流程只做了「月末截面 Spearman \|ρ\|≥0.9/0.85」的值层去重。两个因子可以值相关很低、但**每日 IC 序列高度同步**（同一经济信号的不同算法表达），也可以在值层不重复、但**对模型没有增量**（被更强的同类因子覆盖）。现有 300 里 \|ICIR\| 中位数 0.406，但同一簇最大 58 个成员（`JQ110_EMA5` 簇），说明值层贪婪去重后仍有大量同源变体。需要补两层：

- **信号层**：IC 序列相关 \|ρ\|≥0.60，抓「不同公式、同一信号」。
- **模型层**：分组 drop-one + 置换重要性，抓「值/信号都不重复、但对模型无增量」。

**缺口 C：分类是纯 √n 配额，不是经济覆盖**

√n 配额把 238 个量价因子压到 52 个，把 2 个成长因子抬到 2 个——比例上合理，但**经济含义上不均衡**：`other` 13.7%、基本面 3%、量价微观 56%。专业做法是「经济地板 + 统计天花板」：每个经济类别至少保留若干，单个大类不超过上限，未分类必须压到 5% 以下。

**缺口 D：生产 273 与研究 300 双轨**

见 1.2。没有单一 champion，导致「新方案有没有变好」无法定义。本细案要求先固定对比基线（研究线用 Clean300，生产线用 273 的重选版），再谈 challenger。

## 2. 设计原则（机构口径）

1. **选型必须在裁判窗之外**。任何用到评估窗数据的全局选型，都会把评估变成样本内；S 上的 CV 只做粗筛（选型也用了 S，指标会偏乐观），最终证据只看 V/H。
2. **每个因子回答三个问题**：有没有预测力（signal）？稳不稳定（stability）？有没有增量（incrementality）？三问全过才占席位。
3. **经济分类优先，统计排序其次**。一个因子必须能说清经济机制并归入类别；归不了类的，付出名额惩罚。
4. **固定预算，只做替换不做扩张**。特征数是容量约束，不是排行榜；500 已被实测证伪，不再触碰。
5. **Champion-Challenger**。没有干净样本外证据，不切生产。
6. **全链可复现**。窗口、门槛、排序键、随机种子、版本、指纹全部落盘；重跑同输入必须同输出。
7. **缺失是信息，不是零**。覆盖门槛 + 缺失指示列；不把「没算出来」当成「中性」。
8. **A 股制度约束内建**：ST/停牌/涨跌停/IPO 新股/复权/PIT 财报，先统一口径再谈 IC。

## 3. 阶段 0：全集与可训性审计

### 3.1 输入

- 14 个库的 `6_ml_datasets` 目录与 `factor_catalog` 版本表。
- 每个因子的：库、列名、首个可用日、最后可用日、逐日截面覆盖、缺失率、极值、是否常量、是否精确重复、是否 PIT、是否可实时推断。
- 训练目录键（`库:列`）与在线推理链路（`feature_defs`/`incremental_features`/baseline 快照）的可读性。

### 3.2 硬门槛（G1–G8）

| 门槛 | 定义 | 不通过的处理 |
|---|---|---|
| **G1 覆盖** | 选型窗内平均截面覆盖 ≥60%；有效交易日 ≥250 | 剔除；L2 库按 2022 起单独计 |
| **G2 变异** | 截面标准差 >1e-8；20 日内非常量；唯一值 ≥10 | 剔除（常量/近似常量） |
| **G3 缺失** | 缺失率 ≤30% | 10–30% 保留但加缺失指示列；>30% 剔除 |
| **G4 极值** | 逐日 1%/99% winsorize 后 max\|z\|≤10 | 缩尾；仍超限则剔除 |
| **G5 未来信息** | 财报用公告日 PIT；价格用 qfq；label 用 t+1 开盘后可交易价；level 型价格因子单独标记 | PIT 不通过 → 不进 Core；level 型 → 只进 Extended 并审计 |
| **G6 可训** | 命中 `6_ml_datasets` 目录键；`factor_catalog_versions` 有 published 版本 | 不进训练集；先补目录或剔除 |
| **G7 可推断** | 在线推理链路能取到该列（或能从热集/快照重算） | 不可推断 → 只做研究，不进实盘模型；见 8.3 |
| **G8 精确重复** | 逐日值哈希；>95% 交易日完全一致视为同一列 | 保留一个，记录别名 |

### 3.3 数据质量专项（机构尽调项）

1. **幸存者偏差**：检查 parquet/PG 是否包含已退市/暂停上市标的。若只含当前在市标的，所有 IC 都偏乐观；必须在报告中量化「缺失的退市样本占比」，并把依赖小市值/高波动的因子降级。
2. **PIT 财报**：`gap_mined` 财务/机构类因子必须用公告日，不得用报告期；抽查最近 8 个季度，确认公告日不晚于数据可见日。
3. **复权口径**：收益类因子用 qfq（前复权）；**禁止** daily_backward；价格水平类因子（如 52 周高点距离、价格分位）需确认 qfq 缩放不引入未来公司行为信息，无法确认的降级。
4. **ST/停牌/涨跌停**：因子统计与模型评估统一剔除 ST、停牌、IPO<60 日；涨跌停日的标签形成单独标记（不在涨停价买入、不在跌停价卖出）。
5. **缺失机制**：区分「库没有该日」（结构性缺失，如 L2 2022 前）与「个股当日无值」（随机缺失）；前者用库起始日截断，后者用缺失指示列。
6. **量纲/单位**：金额元 vs 亿元、收益率小数 vs 百分比、换手率 0–1 vs 0–100；抽样核对 `factor_selection.json` 的 ic 方向与单位，防止「单位错但 IC 显著」的假因子。

## 4. 阶段 1：统计筛选（只在 S 窗口）

### 4.1 窗口定义（先定裁判，再选因子）

| 窗口 | 区间 | 用途 | 是否可用于选型 |
|---|---|---|---|
| **S 选型窗** | 2016-01-04 .. 2024-12-31 | 因子统计、冗余、稳定性、模型层选型 | ✅ 唯一允许 |
| **S_L2 选型窗** | 2022-01-01 .. 2024-12-31 | L2 微观因子的可用区间 | ✅（单独计） |
| **V 验证窗** | 2025-01-01 .. 2025-12-31 | 模型超参、早停、候选集粗比 | ⚠️ 只用于模型，不用于因子选型 |
| **H 留出窗** | 2026-01-01 .. 2026-10-19 | 最终 champion-challenger，只看一次 | ❌ 绝不参与选型 |

- 标签与训练逐字一致：`label(t) = close(t+1+h)/close(t+1) − 1`，`h ∈ {5,10,20}`，主口径 h=5。
- S 窗末尾按 horizon 截断：要求 `t+1+h ≤ 2024-12-31`（标签完全在 S 内实现）。h=5 的最后有效信号日约 2024-12-19，h=20 约 2024-11-29；**不得为了凑满 2024-12-31 而用 2025 年的标签**（那会把 V 窗信息带进选型）。
- 每个 CV 折 purge h 个交易日、embargo 5 个交易日；禁止用同一日的截面信息跨折泄漏。
- L2 因子若在 S 窗内只有 2022 起的数据，统计量按 S_L2 计算，并在合并时标注 `window=S_L2`；不与 2016 起的老因子直接比 \|ICIR\|，只在同窗口内比。

### 4.2 指标（全部逐日留档）

| 指标 | 定义 | 用途 |
|---|---|---|
| IC_mean | 逐日截面 Spearman 的均值 | 预测力 |
| IC_std | 逐日 IC 的标准差 | 稳定性 |
| ICIR | IC_mean / IC_std | 主排序键 |
| NW_t | Newey-West t，lag=max(h,5) | 显著性（修正重叠） |
| IC_pos | 与均值同号的交易日占比 | 方向一致性 |
| n_dates | 有效交易日数 | 样本量 |
| turnover | 1 − 相邻日截面秩相关（或 Top 分位换手） | 交易成本 |
| coverage | 逐日非空截面占比均值 | 可投资性 |
| IC_year | 逐年 IC | 年度稳定性 |
| IC_regime | 分行情 IC（bull/neutral/bear） | 行情稳定性 |
| IC_last24m | 最近 24 个月 IC | 衰减 |
| stab_freq | 50 次块 bootstrap 中过门槛的频率 | 选型稳定性 |

### 4.3 门槛（比现有 984 更严）

一个因子进入候选池，必须同时满足：

1. `|IC_mean| ≥ 0.02`（与现有筛选一致）
2. `|ICIR| ≥ 0.30`（现有 0.20，上调）
3. `NW_t ≥ 2.0`（或 BH-FDR q ≤ 0.10）
4. `IC_pos ≥ 0.55`（按方向调整后）
5. `n_dates ≥ 250`（L2 按 S_L2 计，≥400）
6. `coverage ≥ 0.60`
7. `stab_freq ≥ 0.70`（Core 门槛；Extended 可 0.50–0.70）
8. **衰减检查**：`|IC_last24m| ≥ 0.4 × |IC_mean|` 且同号；若近 24 月反向或塌缩 >80%，剔除
9. **跨行情检查**：bull/neutral/bear 三段中至少两段同号；若只在单一 regime 有效，降级到 Extended
10. **跨周期检查**：h=5/10/20 三段中至少两段同号；Core 要求 3/3 或 2/3 且第三段不反向
11. **风格中性检查**：对每个因子做 6 风格因子（`fun_float_mv`、`mom_ret_20d`、`vol_std_20`、`turn_20`、`fun_bp`、`style_beta_20`）的截面回归，算残差 IC；Core 要求 `|IC_resid| ≥ 0.5 × |IC_raw|`，否则视为风格下注，降级到 Extended。风格列表与 Cross300 报告 §5 一致。

**多重检验**：**主检验只对 h=5 做 BH-FDR（q=0.10），跨 4,078 个因子**；h=10/20 只做方向一致性，不单独作为入选依据——否则等于把 3 个 horizon 当成 3 次独立抽奖，门槛会被稀释。BH 假设正相关/PRDS，IC 序列通常正相关，可接受；补 Benjamini-Yekutieli 作为敏感性分析，报告两套结果。

### 4.4 稳定性选择（Stability Selection）

- 对 S 窗做 **块 bootstrap**：20 日块、50 次重采样、每次按块无放回抽 80% 的日期块（固定种子，保持时间序列局部结构）。
- 每次重采样重算门槛 1–6，记录每个因子是否入选。
- `stab_freq` = 入选次数/50。
- 这是 Meinshausen–Bühlmann 稳定性选择的时间序列版本；比单次全样本选型更能抵抗「某一段行情造成的假显著」。

### 4.5 产物

- `ic_series_train.parquet`：`factor, date, horizon, ic, n_valid, coverage`（逐日可审计）
- `stats_train.parquet`：一行一个因子 × horizon，含 4.2 全部指标与 `pass` 标记
- `stability.parquet`：`factor, horizon, stab_freq, n_selected, ic_mean_by_rep`
- `funnel_stage1.json`：4,078 → 各门槛 → 候选数，逐条可对账

### 4.6 验收与淘汰

- **验收**：任取 10 个因子，手工重算 IC/ICIR/NW_t，与产物误差 <1e-6；漏斗数字与逐条标记自洽。
- **K1-a**：若阶段 1 存活 <200，**不放宽门槛**；先诊断是数据问题还是市场确实没信号，输出诊断报告。
- **K1-b**：若存活 >1,500，说明门槛过松或样本期太长；把 ICIR 提到 0.35 或 FDR 提到 0.05，并在报告里记录调整，不得事后改。
- **K1-c**：若某库的 `stab_freq` 中位数 <0.3，该库整体降级到 Extended/Reserve，不进 Core。

## 5. 阶段 2：三层冗余

### 5.1 L1 值层（已有基础，升级为聚类代表）

- 输入：S 窗内 **月末截面**（约 108 期）的因子值，逐期做截面 Spearman，再对期取平均，得到 `ρ_value`。
- 阈值：`|ρ_value| ≥ 0.85`。
- 方法：**average-linkage 层次聚类**，距离 `1−|ρ|`，在 0.85 处切树；每个簇选一个代表。
- 代表评分（归一化后加权）：
  `score = 0.50×|ICIR| + 0.20×stab_freq + 0.20×coverage + 0.10×(1−turnover)`
- 簇内额外保留规则：最多再留 2 个成员，条件是 (a) 与代表 `|ρ| < 0.75`，(b) 在不同 horizon 或不同 regime 上有独立增量，(c) 过阶段 1 全部门槛。
- 记录：`cluster_id, representative, members, max_rho, min_rho, n_members, kept_members`。

**与现有做法的区别**：现有 `dedup.py` 是贪婪直接去重（顺序依赖、无簇结构），本方案用平均连接聚类 + 代表评分，顺序无关、可复现、可解释。`cross_corr.npz` 可直接复用；若候选池变化，重算矩阵。

### 5.2 L2 信号层（新增）

- 输入：阶段 1 的逐日 IC 序列（每个因子 × horizon）。
- 相似度：两个因子 IC 序列的 Spearman 相关 `ρ_ic`；只在两者都有值的日期上算，重叠 <120 日不计算。
- 阈值：`|ρ_ic| ≥ 0.60`。
- 方法：同 L1 的平均连接聚类；簇内保留 `|ICIR|` 最高且 `stab_freq` 最高者；若簇内成员的 IC 序列相关高但值相关低，说明是「同一信号的不同表达」，只留代表 + 至多 1 个。
- 记录：`ic_cluster_id, ic_representative, ic_members, ic_max_rho`。
- **为什么需要**：值层抓「数值重复」，信号层抓「时点重复」。两个因子可以一个用均值、一个用中位数，值相关 0.6，但 IC 序列相关 0.9——对模型是同一份信息。

### 5.3 L3 模型层（新增）

**目的**：回答「去掉它，模型会不会变差」。值层/信号层都不重复的因子，仍可能被更强的同类因子覆盖。

**参考模型**：LightGBM，T+5，参数与平台默认一致（lr 0.02、num_leaves 31、min_data 300、ff 0.6、bagging 0.7/5、l1 0.5、l2 1.0），`num_boost_round=500`、`early_stopping=50`（L3 只做筛选，不用 2,000 轮）。

**折（扩张窗 + 6 个月验证块，purged）**：

| 折 | 训练 | 验证 | 边界处理 |
|---|---|---|---|
| Fold 1 | 2019-01 .. 2022-06 | 2022-07 .. 2022-12 | 验证前 purge 5 日、embargo 5 日 |
| Fold 2 | 2019-01 .. 2024-06 | 2024-07 .. 2024-12 | 同上 |

**执行顺序：先廉价、后昂贵**，避免一上来就做几百次重训。

**L3c 条件 IC（最廉价，先做）**
- 对每个候选因子，先对已选 Top-20 因子（按 \|ICIR\| 排序取前 20）做截面回归取残差，再算残差 IC；`|IC_resid| ≥ 0.01` 才保留。
- 这是「增量信息」的快速近似，用于在重训前砍掉明显冗余。

**L3b 置换重要性（单因子，不重训）**
1. 用全特征在每折训练基准模型，记录 valid RankIC。
2. 对每个因子，在**每个交易日截面内**随机置换该列（保留当日分布），重复 20 次，记录 `ΔRankIC` 分布。
3. `p = P(置换后 ΔIC ≥ 实际 ΔIC)`；保留 `p < 0.10` 或 `ΔIC > +0.0005`。
4. 成本：240 因子 × 20 次 × 2 折 ≈ 9,600 次向量化预测，**约 10–20 分钟**。

**L3a 分组 drop-one（最昂贵，只对入围簇做）**
1. 入围规则：L1 簇内至少 1 个因子通过 L3c 且通过 L3b；另抽 10 个「全簇都不显著」的对照簇，防止只测赢家。
2. 对每个入围簇，整簇移除后重训，记录 `ΔRankIC = full − drop`；同时记录单因子移除的 Δ（仅代表因子）。
3. 保留 `ΔRankIC > +0.0015` 的簇；若 `ΔRankIC < 0`（移除后更好），该簇整体降级。
4. 两折都为正才算通过；一正一负的进 Extended，并标注不稳定。
5. 预计入围 40–80 个簇 × 2 折 + 2 个基准 = **82–162 次训练**；8.6M×240、16 线程、500 轮，单次约 1–1.5 分钟，总 **1.5–4 小时**（串行）。超过 8 小时按 K2-c 降折。

### 5.4 冗余验收

- A+B 集合内：`max |ρ_value| ≤ 0.85`、`max |ρ_ic| ≤ 0.60`。
- 每个保留簇有代表与成员记录；每个被剔因子能指到 `conflict_with` 与 `abs_rho`。
- L1/L2/L3 三层淘汰数可对账：阶段 1 候选 → L1 剔 → L2 剔 → L3 剔 → 最终。

### 5.5 淘汰

- **K2-a**：若 L1+L2+L3 后 `max |ρ_value| > 0.85` 或 `max |ρ_ic| > 0.60` 仍存在，**不得交付**；回到聚类修阈值/代表规则。
- **K2-b**：若 L3 两折符号相反（一正一负）的簇 >30%，说明模型层信号不稳；这些簇只进 Reserve，不进 Core。
- **K2-c**：若 L3a 总时长 >8 小时或峰值内存 >32GB，减少折数到 1 折 + 保留 L3b/L3c，**不得整体跳过 L3**。

### 6.3 配额算法

```
B = 240
w_c = sqrt(n_c) / Σ sqrt(n_c)          # n_c = 该类过门槛候选数
q_c = clip(round(B * w_c), floor_c, cap_c)
余量按 |ICIR| 从高到低补；超出天花板的进 Reserve
```

- 类内排序键：`|ICIR|` → `stab_freq` → `|IC|` → `coverage` → 名称（确定性）。
- 小类（n_c ≤ 10）若全部过门槛，全取；不受 √n 压缩。
- `unclassified` 先按 6.1 重分类；仍归不了的，只有 \|ICIR\| 排前 12 且 \|IC\|≥0.03 才进，否则 Reserve。

### 6.4 分层定义

| 层 | 数量 | 入选条件 | 用途 |

| **Extended B** | 120 | 阶段 1 门槛 + (stab_freq 0.50–0.70 或 L3a 一折通过 或 L3b 通过但簇未入围 或 单一行情有效) | 默认训练（A+B=240） |
| **Reserve C** | ≤100 | 过阶段 1 但 L1/L2/L3 冗余被剔、或类别超天花板 | 只做替补/实验 |
| **Champion** | 300 / 273 | 现有研究 300 / 生产 273 | 对比基线，不直接替换 |

- 默认训练集 = **A+B = 240**。
- 若 Core A < 100：**K3**，不放宽门槛；交付 A + 报告缺口，240 目标作废。
- 若 A+B < 200：同样 K3，检查阶段 1 门槛是否过严（但只能下一轮调，不能本轮事后调）。

## 7. 阶段 4：模型级验证（Champion-Challenger）

### 7.1 候选集（同一 split、同一模型参数、同一随机种子）

| 代号 | 特征集 | 目的 |
|---|---|---|
| **CLEAN300** | 20261016 算法，选型窗截到 2024-12-31、近期窗 2023-01..2024-12，重选 300 | 公平 champion |
| **INC300** | 现有研究 300（选型窗含 2025-09..2026-09） | 参考，不参与胜负判定 |

| **CORE120** | 本细案 A | 简约性检验 |

- **口径提醒**：因子选型用了 S，模型也在 S 上训练，所以 S 上的 CV 指标只用于粗筛与早停，**不作为「谁更好」的证据**；V 用于模型选择，H 只用于最终 champion-challenger。

### 7.2 模型与切分

| 项 | 设置 |
|---|---|
| 主模型 | LightGBM T+5（平台默认参数，2,000 轮，early stopping 100） |
| 次模型 | NativeTFT T+5（序列窗口，验证跨模型族稳健性） |
| 线性 sanity | Ridge/Linear T+5（检验非线性依赖） |
| 训练窗 | 2016-01-04 .. 2024-12-31 |
| 验证窗 | 2025-01-01 .. 2025-12-31 |
| 留出窗 | 2026-01-01 .. 2026-10-19（只看一次） |
| 组合评估 | 10 亿资金，Top50，次日开盘/收盘成交（与 `backtest2026` 同口径），佣金 3bp + 卖出印花税 5bp + 滑点 0/5bp 两档 |
| 随机种子 | 固定 42；树模型 `deterministic=true`、`force_row_wise=true` |

### 7.3 指标

- **预测**：RankIC、ICIR、IC_pos、NW_t。
- **组合**：Top50 年化超额、最大回撤、换手、容量（1% 成交额约束下的收益衰减）。
- **稳定**：分行情 IC（bull/neutral/bear）、分年度 IC、分市值组 IC。
- **风格归因**：Top50 组合收益对 6 风格的暴露，单一风格贡献 ≤50% 超额；否则说明增益是风格下注，不是选股 alpha。
- **解释**：SHAP Top20 的跨折秩相关；Top20 是否覆盖 ≥6 个类别。
- **成本敏感**：0bp vs 5bp 滑点下的超额差；换手 q90。

### 7.4 预注册决策规则（先写死，后看结果）

**NEW240/CORE120 采用，当且仅当以下全部成立：**

1. 留出窗 H 上，`RankIC_NEW240 ≥ RankIC_CLEAN300 − 0.005`。
2. 至少一项主指标显著更优：
   - RankIC 提升 ≥0.005 且 NW t≥2，或
   - Top50 超额提升 ≥1.0pp 且块 bootstrap 95% CI 不含 0（20 日块、5,000 次、seed=7），或
   - 换手下降 ≥15% 且 RankIC 不降。
3. 没有任何主指标比 CLEAN300 差 >0.005（RankIC）或 >10%（Top50 超额）。
4. 改善不集中在单一 regime 或单一 3 个月窗口：任一 regime/季度的贡献 ≤60% 的总改善。
5. 分层收敛规则：若 `CORE120` 比 `NEW240` 差 ≤0.005 RankIC，说明 Extended 层没有增量，**采用 CORE120**（更简约、换手更低）；若差 >0.005，说明 Extended 层有效，**采用 NEW240**。两条路都必须满足规则 1–4。

**否则 KILL NEW240，保留 CLEAN300（研究线）/ PROD273（生产线）。**

### 7.5 消融（回答「哪一层起了作用」）

| 消融 | 对比 | 回答 |
|---|---|---|
| 冗余层 | CLEAN300 vs TOP240 vs BAL240 vs NEW240 | L1/L2/L3 各贡献多少 |
| 分层 | CORE120 vs NEW240 | Extended 120 是否值得 |
| 类别 | 逐类移除后重训 | 哪类是真增量、哪类是噪声 |
| L2 覆盖 | 含 L2 vs 不含 L2（2016 起 NaN vs 2022 起截断） | L2 的 2022 前缺失是否伤害模型 |
| 成本 | 0bp vs 5bp | 高换手因子是否被高估 |

### 7.6 淘汰

- **K4-a**：NEW240 在 H 上 RankIC 低于 CLEAN300 超过 0.005 → **KILL**。
- **K4-b**：NEW240 的改善 >60% 来自单一 regime/季度 → **REJECT**，视为行情下注。
- **K4-c**：CORE120 与 NEW240 差 ≤0.005 → Extended 层无增量，收敛到 CORE120；若 CORE120 差 >0.005，则 Extended 有效，保留 NEW240。两者都不满足规则 1–4 时，回阶段 3。
- **K4-d**：含 L2 的模型在 2016-2021 段显著差于不含 L2（RankIC 差 >0.01）→ L2 只进 Extended 或单独建模，不混入主集。

## 8. 防泄漏与口径（全阶段强制）

### 8.1 时间

- 选型 S 截止 **2024-12-31**；V=2025 只用于模型；H=2026-01..2026-10-19 只看一次。
- 任何调参、门槛调整、类别配额调整，都不得使用 H；一旦使用，H 作废，改用前向纸面跟踪。
- label 用 `close(t+1+h)/close(t+1)−1`；t 日收盘后生成信号，t+1 才可交易；purge h 日、embargo 5 日。

### 8.2 数据

- 财报 PIT：公告日，不用报告期；不用后来修订值。
- 价格：qfq；禁止 daily_backward；level 型价格因子单独审计。
- 域：剔除 ST、停牌、IPO<60 日；涨跌停日标签单独标记。
- 缺失：不无限 ffill；线性模型用截面中位数 + 缺失指示；树模型用 NaN。
- 极值：逐日 1%/99% winsorize；IC 用秩相关，减少极值影响。
- 精确重复：值哈希，不只靠相关。

### 8.3 可推断性（训练-实盘一致性）

- 每个 A+B 因子必须有 `inference_available` 标记：在线链路能取到原列，或能从热集/快照重算。
- 若某因子训练时有、实盘时无，模型在实盘会看到系统性 NaN；必须：
  1. 优先选可推断因子；
  2. 不可推断但重要的，加缺失指示列并单独监控；
  3. 完全不可推断的，不进实盘模型，只做研究。
- 交付前跑一次「训练-推理特征覆盖对账」：A+B 中可推断比例 ≥90%，否则缩到可推断子集重训。

### 8.4 版本与指纹

- `factor_catalog_versions` 逐库钉扎 published 版本。
- 选型指纹 = SHA256(排序后的 `库:列` 列表 + 窗口 + 门槛 + 代码 commit)。
- 模型 `metadata.json` 记录指纹；指纹不一致的模型不可比。
- 选型产物目录带日期：`selection_v2_20261021/`；不覆盖旧目录。

## 13. 监控与治理（选完之后）

### 13.1 季度复核（下一次 2027-01）

- 滚动 12 个月 IC、ICIR、IC_pos；与选型时相比，衰减 >50% 的因子进观察名单。
- 分行情 IC：某因子在单一 regime 持续失效 → 降级。
- 换手/拥挤：Top50 持仓重叠度、因子暴露集中度、成交额占比。
- 新增因子：新挖掘/新公式先过同一套阶段 1–3 门槛，才进 Reserve。

### 13.2 替换规则

- 每季度最多替换 **10%**（24 个席位）。
- 新因子必须：过全部门槛 + 在最近 24 个月有正增量 + 不与现有簇 \|ρ\|>0.85。
- 替换先影子跑 4 周，IC/超额不劣于 incumbent 才正式换。
- 替换记录进 `selection_v2_changelog.md`：谁、何时、为什么、替谁。

### 13.3 冻结与回退

- 实盘交易时段不改特征集；改动只在周末 + 重训 + 影子。
- 任何新模型必须记录选型指纹；指纹不一致的预测不可混用。
- 回退包：旧 `features_A/B` + 旧模型 + 旧指纹，保留至少 2 个季度。

### 13.4 角色与留痕

- 研究 → 模型注册表 → 生产，三处同一指纹。
- 选型报告、决策备忘录、git commit 三者对齐；缺一不可。
- 不在聊天/工单里口头改门槛；所有门槛变更写进 `selection_v2.json` 的 `params` 与 changelog。
- **公式变更治理**：任何因子公式改动必须升 `catalog` 版本号；旧模型锁定旧版本，新模型才用新版本；版本变更触发「新旧版本相关性 + 旧模型 IC 影响」评估，禁止原地覆盖。

## 附录 A：关键口径与公式

**IC（Rank IC）**

```
IC_t = Spearman( rank(factor_{i,t}), rank(label_{i,t}) )
label_{i,t} = close_{i,t+1+h} / close_{i,t+1} - 1
```

**ICIR**

```
ICIR = mean(IC_t) / std(IC_t, ddof=1)
```

**Newey-West t**

```
t = mean(IC) / sqrt( NW_var / N )
NW_var = γ0 + 2 Σ_{l=1}^{L} (1 - l/(L+1)) γ_l
L = max(h, 5)
```

**BH-FDR**

对每个 horizon 的 4,078 个 p 值升序排列，找最大 k 使 `p_(k) ≤ (k/m)·q`，q=0.10；前 k 个拒绝。

**块 bootstrap 稳定性**

```
for rep in 1..50:
    抽 80% 的 20 日块（有放回或按块无放回，固定种子）
    重算门槛 1-6
    selected[rep] = 通过的因子集
stab_freq_i = count(i in selected) / 50
```

**L1 代表评分**

```
score = 0.50*norm(|ICIR|) + 0.20*norm(stab_freq)
      + 0.20*norm(coverage) + 0.10*norm(1-turnover)
```

**类别配额**

```
w_c = sqrt(n_c) / Σ sqrt(n_c)
q_c = clip(round(240 * w_c), floor_c, cap_c)
```

**选型指纹**

```
fingerprint = SHA256( "\n".join(sorted(features)) + "|" + window + "|" + gates + "|" + git_commit )
```
