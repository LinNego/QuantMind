# 大盘指数预测模型训练规划（CatBoost / LightGBM / XGBoost）

- 日期：2026-10-24
- 状态：规划定稿（P0 训练待执行）
- 范围：沪深300、中证500、中证1000、上证综指（沪市）、深证成指（深市）
- 数据边界：**只用现有库内数据**（2016-01-04 ~ 2026-10-23），不新增外部数据源
- 关联：`backend/shared/market_regime.py`（规则 regime 基线）、`docs/大盘预测模型与大盘分析专业化_设计细案_20261024.md`（大盘分析展示设计）

## 0. 结论（先看这段）

1. **可以用现有数据训练**：5 条指数 2,623 个交易日（2016-01-04~2026-10-23）+ 全市场截面 1,096 万行（`stock_daily_latest`，151 列）+ 指数成分权重 + HK/US 指数日线。
2. **模型族按你指定**：CatBoost / LightGBM / XGBoost，三族分别训练、统一校准、统一评估；不做深度学习。
3. **和个股训练管线的关系**：**共用训练内核，不共用数据管线**。个股管线的 LightGBM/XGBoost/CatBoost 训练器、walk-forward 工具、模型注册/产物管理可复用；但个股管线绑定 151 维 qlib 因子与 `pred.parquet` 面板口径，指数模型需要新的大盘特征表（广度/估值/分化/跨市场）。硬套个股管线会污染两条链，且指数只有 2,623 行，不需要个股管线的分片/池逻辑。
4. **预期要诚实**：2,623 日、H=10 的有效独立窗口约 260 个。合理目标 OOS **AUC 0.55~0.62、方向命中率 55%~60%、ECE≤0.05**；达不到就只做风险仪表，不叫预测。任何「80%+ 准确率」都不现实。

### 1.2 预测周期

- H = 5 / 10 / 20 个交易日（三套标签，分别训练；同一特征表）。
- 主展示：T+10（与现有选股模型周期一致）；T+5/T+20 作为对比与稳健性检验。

### 1.3 模型矩阵

每个（指数 × 周期）训练 3 个模型 + 1 个基线：

| 模型 | 角色 | 说明 |
|---|---|---|
| 规则基线 | 必须打败的基准 | 现有 `classify_regime`（20 日收益/波动/量比）+ MA20 趋势 |
| LightGBM | 主模型 | 多分类/回归，早停，特征重要性 |
| XGBoost | 主模型 | 同上，参数独立 |
| CatBoost | 主模型 | 同上，类别特征友好 |
| 集成 | 稳健性 | 三族校准概率等权平均（仅当三族方向一致时） |

合计：5 指数 × 3 周期 × 3 模型 = **45 个模型**（另加基线/集成）；训练量可控（每模型 2,623 行 × ~60 特征）。

## 2. 标签定义（防前视）

对指数 i、信号日 T、周期 H：

- 进场：T+1 收盘
- 出场：T+1+H 收盘
- `fwd_ret = close[T+1+H] / close[T+1] - 1`

两种标签并行训练与评估：

1. **二分类**（主）：`y = 1 if fwd_ret > 0 else 0` → 输出校准后的 P(上涨)。
2. **三分类**（辅）：`up / flat / down`，阈值 θ_H 默认取历史 33%/67% 分位（自适应波动）；同时保留固定阈值（0.5%/1.0%/1.5%）作敏感性对照。

> 标签只用未来价格，特征只用 ≤T 数据；T+1 进场与展示口径（信号日 T → 指数日 T+1）一致。

## 3. 特征（全部来自现有数据）

### 3.1 指数技术面（每条指数各自）

- 收益：ret_1 / 5 / 10 / 20 / 60 / 120
- 均线乖离：close/MA5−1、MA10、MA20、MA60、MA120
- 动量/超买超卖：RSI6、RSI14、MACD(DIF/DEA/柱)、布林 %B、KDJ

- 位置：距 252 日高点回撤、距 20/60 日高低点位置
- 量能：成交量 z（20 日）、成交额 z、换手率 z

### 3.2 市场广度（全市场 / 指数成分，按所选指数口径）

- 站上 MA20 / MA60 的股票占比
- 涨跌家数比、上涨家数占比
- 涨停 / 跌停家数（`stock_daily_latest.limit_up_today/limit_down_today`）
- 全市场中位收益、等权平均收益
- 截面分化：当日个股收益标准差、Top-Bottom 收益差
- 成交额集中度、平均换手 z

### 3.3 估值与风格

- 全市场 PE_TTM / PB 中位数、市值加权 PE、3y/5y 分位
- 沪深300 vs 中证1000 相对收益（20/60 日）
- ST 占比、低价股占比
- 大小盘成交额占比

### 3.4 跨市场与日历

- HSI.HK / SPX.US 隔夜收益（各自 index_daily）
- 月/季末、长假前 N 日、期指交割周（第三周五）
- 星期几（可选，树模型可自行学）

### 3.5 明确不用（现阶段数据不足）

- 新闻情绪（仅 2 个月）、TDX L2/资金流（仅 2 个月）、两融/北向/宏观（未落库）——Phase 2 再增量，不塞进 10 年训练。

## 4. 与「个股训练管线」的关系（你问的重点）

### 4.1 能不能共用一个管线？

**结论：共用「训练内核 + 模型注册/产物管理 + 评估工具」，不共用「数据构建 + 推理落库」；不做强行合并。**

| 能力 | 个股管线（现有） | 指数模型需要 | 复用判断 |
|---|---|---|---|
| 数据形态 | 面板（股票 × 日期 × 151 因子），`model_features_{year}.parquet` | 单序列（指数 × 日期 × ~60 大盘特征） | ❌ 新建特征表 |
| 标签 | 个股 forward return（`pred.parquet`） | 指数 forward return | ❌ 新建标签 |
| 训练器 | LGB/XGB/CatBoost/MLP/GRU… | 仅 LGB/XGB/CatBoost | ✅ 复用训练器与参数封装 |
| 切分/验证 | 时间切分 + purged CV 工具 | purged walk-forward + embargo | ✅ 复用/扩展 |
| 模型注册 | `qm_user_models` + 产物目录 | 指数模型需独立命名空间 | ⚠️ 新表/新目录（避免污染股票模型列表） |
| 推理落库 | `engine_signal_scores` / `pred.parquet` | `qm_market_regime_predictions` | ❌ 新建表 |
| 回填/补推 | 逐模型逐日 `pred` 合并 | 指数每日一次，无补推概念 | ❌ 不需要 |
| 前端 | 模型管理/推理中心 | 大盘分析概率面板 | ⚠️ 新面板，复用图表组件 |

**推荐形态**：新模块 `backend/services/engine/market_regime/`（特征、标签、训练、推理），复用 `backend/shared/training/` 里的训练器/校准/purged 工具；模型产物独立目录 `data/market_regime/models/`；不注册进个股 `qm_user_models`，避免「一键补推/推理中心」把指数模型当股票模型处理。

### 4.2 为什么不能直接塞进个股管线？

1. **特征语义不同**：151 维是「个股价量因子」，没有广度/估值分位/跨市场；强行塞会把指数当一只股票（symbol=000300.SH），广度特征无法表达。
2. **样本量与切片逻辑不同**：个股 1,096 万行需要分片/池/年度文件；指数 2,623 行，分片是负担。
3. **推理语义不同**：个股推理是「全市场打分」，指数推理是「每日一次概率」；共用落库表会混淆消费方（选股/回测/门禁）。
4. **审计边界**：指数模型错了只影响「大盘分析」展示；混进个股管线会影响选股/回测/实盘。隔离更安全。

### 4.3 可以共用的部分（减少重复）

- `backend/shared/training/model_recipe.py` 式的参数/产物元数据规范；
- LightGBM/XGBoost/CatBoost 训练封装、早停、特征重要性；
- purged walk-forward 工具（`ml-purged-cv` 技能/现有实现）；
- 概率校准（isotonic/Platt）与评估指标（AUC/Brier/ECE）工具；
- 前端 ECharts 组件与颜色/布局规范。

## 5. 训练与验证协议

### 5.1 切分（禁止随机切分）

- **Purged walk-forward**：初始训练 ≥5 年（2016-2021），验证 6 个月（调参/校准），测试 6 个月；embargo = H+5 个交易日；滚动前进 6 个月。
- 2016-01 ~ 2026-10 约 8 个测试折；每条指数独立训练与评估，再汇总。
- 训练折内做特征标准化/缺失处理（树模型可跳过标准化，但仍需在折内拟合缺失统计）。

### 5.2 模型训练细节

- 二分类主任务（P(up)），三分类辅助。
- 类别不平衡：按训练折正负样本比设置 `scale_pos_weight`/class_weight，不做全局重采样。
- 早停：验证折 AUC 连续 50 轮不升停止；最大 2,000 轮；学习率 0.01~0.05。
- 校准：在**验证折**上拟合 isotonic/Platt，测试折只做 predict；报告未校准与校准两套指标。
- 特征重要性：三族分别输出 top20，检查是否依赖单一特征（如单边行情下的动量）。

### 5.3 指标

- 概率：AUC、PR-AUC、Brier、LogLoss、ECE、可靠性曲线。
- 分类：balanced accuracy、up/down 的 precision/recall、阈值 0.6/0.4 命中率。
- 经济：long/flat（P≥0.6 持有，P≤0.4 空仓）vs 买入持有：CAGR、MaxDD、Sharpe、换手、扣 3bp 成本；deflated Sharpe。
- 统计：bootstrap 95% CI；n_eff≈n/H；DeLong 检验（LR vs GBM）。

### 5.4 杀判据（不达标不叫预测）

1. OOS AUC ≥0.58 的测试折占比 ≥60%；
2. Brier 比「按基础上涨率」的基准改善 ≥5%；
3. ECE ≤0.05；
4. long/flat 的 MaxDD 优于买入持有，且扣费后 Sharpe 不低于基准；
5. 无前视（PIT 审计通过）；
6. 跨指数方向一致（≥4/5 条同向）。

未达标 → 只上线为「风险仪表/情绪代理」，不写「预测涨跌」。

### 6.1 产物

     - `data/market_regime/models/{index}/{horizon}/{model}/{fold}/model.pkl` + `metadata.json`
     - `data/market_regime/reports/index_regime_oos_{timestamp}.json` + `.md`
3. 首份 OOS 报告（5 指数 × 3 周期 × 3 模型 + 基线），包含杀判据逐条结论。

### 6.2 执行顺序

1. 特征表构建与校验（随机抽 10 天核对只含 ≤T 数据；广度/估值与 `stock_daily_latest` 对账）。
2. 规则基线 + LR 基线跑通 walk-forward。
3. LGB → XGB → CatBoost 依次训练（串行，最慢压尾）。
4. 校准 + 汇总报告 + 杀判据判定。
5. 报告出来后再决定 P1（API/UI/每日推理）是否开工。

### 6.3 资源与时间

- 数据量小（2,623 行 × ~60 特征 × 5 指数 × 3 周期），CPU 即可，单模型秒级~分钟级；总训练 <30 分钟。
- 不需要 GPU；不占训练队列的个股任务资源；可在容器内直接跑。

## 7. 预期与风险（提前写死）

- **预期**：AUC 0.55~0.62、命中率 55%~60%、ECE≤0.05；三族中 CatBoost/LGB 通常略优于 XGB；单边行情（如 2026-05~09 下跌）指标会虚高，必须看跨折一致性。
- **主要风险**：
  1. 样本少、H 重叠 → 有效独立窗口 ~260，过拟合风险高；用强正则、浅树、早停、purged CV。
  2. 特征在单边行情中退化（动量/广度同向）→ 分折报告，不报单点。
  3. 指数间高度相关（300/500/1000）→ 独立训练可能得到相似结果；汇总时按指数分层报告。
  4. 数据 PIT：`stock_daily_latest` 是「最新快照」，历史广度/估值需确认是否为当日截面；若快照被回填覆盖，需用 `stock_daily` 历史分区重建（P0 先核对，不通过则退回指数自身特征）。
- **回滚**：新模块独立，不影响个股管线；关闭大盘预测面板即回退。

## 11. 行业板块（一级 / 二级 / 概念）可训练性

### 11.1 数据事实

- `2_base_sector/sector_concept/sector_members.parquet`：**当前成分快照**（无日期列）
  - 行业板块（一级）**48 个**，成员 1,436 行

  - 概念板块 **420 个**，成员 67,723 行

- TDX 板块日线（`tdx_bkjy_long`）：仅 1,496 行、最近数日 → **不能做 10 年训练**。

### 11.2 可行方案与边界

| 层级 | 数量 | 方案 | 偏差/风险 |
|---|---|---|---|
| 行业一级 | 48 | 用当前成员合成等权/市值加权板块指数（2016-2026），逐板块训练 LGB/XGB/Cat | **当前成分回溯**：成分变更/退市未还原 → 幸存者偏差；先选成员数≥15、成交额达标的前 10-15 个行业试点 |
| 行业二级 | 80 | 先做 pooled 模型（板块 one-hot/特征），不做逐板块 | 成分重叠高、单板块样本少 |
| 概念板块 | 420 | 不做逐板块预测；可作为「概念热度」特征 | 重叠严重、成分变动大 |
| 地区板块 | 32 | 不做 | 无预测意义 |

- **升级路径**：接入历史行业成分（akshare 申万历史/聚宽等）后，再把板块指数升级为 PIT 口径；当前只能作为**代理**，报告必须标注。
- 板块标签/特征与指数一致（forward H 日收益、板块内广度/估值/两融），复用同一训练脚本（`index_code` 换成 `SECTOR_L1_xxx`）。
