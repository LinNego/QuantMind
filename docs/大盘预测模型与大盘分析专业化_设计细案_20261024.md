## 0. 先说结论（基于实测）

1. **现有选股模型不能直接拿来预测大盘涨跌。**
   实测 T+10 三模型（LightGBM/XGBoost/CatBoost，2026-05-11~09-08 纯 OOS 86 日；2026-01-12~04-15 验证期 61 日）：
   - 选股能力稳定：日截面 IC 0.125~0.179、ICIR 0.79~1.18、Top10%−Bottom10% 10 日价差胜率 67%~77%、价差 +1.5%~+4.2%/10 日；
   - 个股涨跌方向准确率仅 **51.8%**（接近抛硬币）——排序模型赚的是截面价差，不是方向；
   - 用「全市场均分/广度/20 日 z」预测沪深300 未来 10 日方向：验证期 AUC 0.39~0.58、测试期 0.57~0.71，**跨窗口不稳定，方向甚至反转**；1 日方向 AUC ≈0.51，无信号；
   - 沪深300 成分均分在测试期**从未转正**（结构性水平偏置），不能读作「看空」。
2. **可以做一套独立的大盘预测模型。**
   现有数据足够做 P0/P1：指数日线 2016-01-04~2026-10-23（2,623 个交易日 × 5 条指数）、全市场截面 2016 至今（`stock_daily_latest` 1,096 万行），可构造指数技术面、广度、估值、分化度、风格、跨市场特征。
3. **预期要诚实**：2,623 个日样本、10 日重叠标签的有效独立窗口约 260 个；合理目标是 OOS AUC **0.55~0.62**、方向命中率 **55%~60%**、校准良好（ECE≤0.05），不是 80%。达不到就只作为「风险仪表」，不叫「预测」。

## 1. 目标与非目标

### 目标
- 给「模型管理 → 大盘分析」提供一套**机构级展示**：指数、状态带、概率带、广度、风险、估值/资金、模型评估条。
- 独立训练**指数级**预测模型：对未来 H 个交易日（H=5/10/20）的涨/跌/震荡给出**校准概率**，而不是点预测。
- 全链路可复现、可审计、可回滚：PIT 特征、purged walk-forward、模型版本、每日预测落库、漂移监控。

### 非目标
- 不用选股模型的截面均分直接当大盘信号。
- 不做「保证准确率」的承诺；不做分钟级/日内高频预测（Phase 3 以后另议）。
- 不改变现有回测/实盘门禁口径；新模型先影子运行，不直接进交易决策。

## 3. 「大盘分析」曲线专业化设计

### 3.1 页面结构（自上而下）

1. **工具栏**
   - 指数多选：沪深300 / 中证500（沪深500）/ 中证1000（沪深1000）/ 上证综指（沪市）/ 深证成指（深市）/ 全部叠加
   - 窗口：6M / 1Y / 3Y / 全部
   - 预测周期：T+5 / T+10 / T+20（默认与所选指数模型一致）
   - 信号对齐：T+1（默认）/ T+H / T+0
   - 价格模式：归一（首日=100）/ 实际点位
   - 「概率阈值」：默认 60% 看多、40% 看空（可调）
2. **主图（价格 + 概率 + 状态）**
   - 指数收盘线（左轴，归一或实际）
   - **模型 P(上涨)** 折线（右轴 0–100%）+ 80% 置信带（bootstrap 或模型方差）
   - 50% 参考线；≥阈值绿色带、≤阈值红色带（半透明）
   - **regime 背景带**：bull 淡红 / neutral 灰 / bear 淡绿（来自 `qm_regime_daily`，不重算）
   - 事件标记：概率穿越 60/40、regime 翻转、回撤 ≥10%、模型重训日
3. **副图 1：广度与情绪**
   - 站上 MA20 / MA60 的股票占比
   - 涨跌家数比（或涨跌家数两条柱）
   - 涨停/跌停家数（有历史时；当前 TDX 仅 2 个月，先用 `stock_daily_latest` 的 `limit_up_today/limit_down_today`）
   - 全市场中位收益、截面分化度（收益标准差）
   - 选股模型派生（可选，Phase 3）：pred>0 占比、均分 20 日 z、pred 截面离散度
4. **副图 2：风险与波动**
   - 已实现波动率 20/60 日
   - ATR%（14 日）
   - 距 252 日高点回撤
   - 成交额/换手 z-score
5. **副图 3：估值与资金（Phase 2 逐步点亮）**
   - 全市场 PE_TTM / PB 中位数及 3y/5y 分位
   - 两融余额变化、北向净流入、ETF 份额变化（需新增同步）
   - 新闻情绪指数（FinBERT 聚合，2 个月后可用）
6. **模型评估条**
   - 滚动 126 日 AUC、命中率（P≥阈值）、Brier、ECE
   - 校准曲线（可靠性图）+ 有效样本数 + 最后训练日/版本
   - 显著性与置信区间（bootstrap）；不显示单点「准确率」不带区间

### 3.2 数据与展示纪律

- **PIT/防前视**：所有特征只用 ≤T 的数据；标签 T+1 进场、T+1+H 出场；图上标注「信号日 T / 指数日 T+1」。
- **缺失一律 `—`**，不 0 填充；每条线带 as-of 时间与来源。
- **概率不是点预测**：展示 P(up)、P(down)、P(flat) 与置信区间；不写「明天涨/跌」。
- **口径可追溯**：阈值、H、窗口、模型版本在 tooltip/页脚可见。
- **性能**：主图 ≤2 个 ECharts 实例，副图合并为 1 个多 grid 图；数据 >2000 点时按窗口抽样，不阻塞交互。

## 4. 大盘预测模型设计

### 4.1 标签

- 对每条指数、每个交易日 T：
  - 进场：T+1 收盘（与现有 T+1 错开口径一致）
  - 出场：T+1+H 收盘（H=5/10/20）
  - `fwd_ret_H = close[T+1+H]/close[T+1] - 1`
- 三分类（主输出）：
  - `up`：fwd_ret_H > +θ_H
  - `down`：fwd_ret_H < −θ_H
  - `flat`：其余
  - θ_5=0.5%、θ_10=1.0%、θ_20=1.5%（可配置；用历史分位校准，如 θ=33%/67% 分位）
- 二分类辅助：`P(fwd_ret_H > 0)`，用于连续概率带与校准评估。

### 4.2 特征（Phase 0/1，全部现有数据可算）

| 组 | 特征（示例） | 说明 |
|---|---|---|
| 指数技术 | ret_1/5/10/20/60/120、MA5/10/20/60/120 乖离、RSI6/14、MACD、布林 %B、vol_10/20/60、drawdown_252、volume/turnover z | 每指数 |
| 广度 | %>MA20、%>MA60、涨跌家数比、涨停/跌停家数、中位收益、截面收益 std、平均换手 z | 全市场，按指数成分或交易所口径 |
| 估值 | PE_TTM/PB 中位数、3y/5y 分位、市值加权 PE | 全市场/成分 |
| 风格 | 沪深300 vs 中证1000 相对收益、价值/成长代理（PE 差）、ST 占比 | 风格轮动 |
| 跨市场 | HSI/SPX 隔夜收益、美元指数（若有）、A50 期货（若有） | HK/US index_daily 已可用 |
| 日历 | 月/季末、长假前 N 日、期指交割周 | 纯日历 |
| 选股模型派生（Phase 3） | pred>0 占比、均分 20 日 z、pred 截面离散度 | 仅作可选增量，不单独当预测 |

特征工程纪律：全部 rolling 只用过去；缺失不 fillna(0)；标准化在训练折内拟合（避免泄漏）。

### 4.3 模型与校准

- **基线**：规则版（现有 `classify_regime` + MA20 趋势 + 广度阈值）→ 作为「必须打败」的基准。
- **P0**：L2 逻辑回归（多分类 softmax），可解释；Platt/Isotonic 校准（在验证折拟合）。
- **P1**：LightGBM / CatBoost（多分类），purged walk-forward，早停用验证折；概率校准同 P0。
- **P2**：等权集成（LR+GBM）+ 按 regime 条件训练（bull/bear 分开），只在样本充足时启用。
- 不做深度学习：2,623 日样本、H 重叠，深度模型只会过拟合。

### 4.4 验证协议（核心）

- **Purged walk-forward**（禁止随机切分）：
  - 初始训练 ≥5 年；验证 6 个月（调参/校准）；测试 6 个月； embargo=H+5 个交易日；滚动前进 6 个月。
  - 2016–2026 约 8 个测试折；5 条指数分别评估 + 合并评估。
- **指标**：
  - 概率：AUC、PR-AUC、Brier、LogLoss、ECE、可靠性曲线；
  - 分类：balanced accuracy、up/down/flat 的 precision/recall、阈值 0.6/0.4 的命中率；
  - 经济：long/flat（P≥0.6 持有，P≤0.4 空仓）vs buy-and-hold：CAGR、MaxDD、Sharpe、换手、扣 3bp 成本；deflated Sharpe；
  - 统计：bootstrap 95% CI、DeLong 检验、有效样本数（H 重叠 → n_eff≈n/H）。
- **杀判据（不达标就不叫预测模型）**：
  1. OOS AUC ≥0.58 的测试折占比 ≥60%；
  2. Brier 比基准（按基础上涨率）改善 ≥5%；
  3. ECE ≤0.05；
  4. long/flat 的 MaxDD 优于 buy-and-hold，且扣费后 Sharpe 不低于基准；
  5. 无前视（PIT 审计通过）；跨指数方向一致（≥4/5 条同向）。
  - 未达标 → 只作为「风险仪表/情绪代理」上线，不写「预测涨跌」。

### 4.5 工程落地

1. **特征构建**：`backend/scripts/market_regime/build_index_regime_features.py`
   - 读 `index_daily` + `stock_daily_latest` + `index_weights` + HK/US 指数；
   - 输出 `data/market_regime/features/index_regime_features.parquet`（或 PG 表 `qm_market_regime_features`，每日增量）。
2. **训练/验证**：`backend/services/engine/market_regime/train_index_regime.py`
   - 实现 purged walk-forward、校准、指标报告（JSON + md）；
   - 模型产物 `data/market_regime/models/{index}/{version}/model.pkl` + `metadata.json`。
3. **每日推理**：`backend/services/engine/market_regime/infer_daily.py`
   - 收盘后（16:30）生成次日生效概率，写 `qm_market_regime_predictions`：
     `(trade_date, index_code, horizon, prob_up, prob_down, prob_flat, confidence, model_version, feature_asof)`。
4. **API**：
   - `GET /api/v1/market-regime/predictions?index=&horizon=&window=` → 概率序列 + 状态带 + 评估指标；
   - `GET /api/v1/market-regime/metrics?index=&horizon=` → 滚动 AUC/命中率/校准；
   - 与现有 `GET /models/{id}/market-regime` 并存：旧端点保留（选股模型情绪），新端点服务指数模型。
5. **UI**：模型管理 → 大盘分析 增加「指数预测」子页/开关；概率带、状态带、评估条；影子模式标记「未接入决策」。
6. **监控**：
   - 每日记录预测与实现值；滚动 AUC/ECE 漂移 >阈值告警；
   - 训练/预测版本、特征 as-of、数据新鲜度写入 `system_events`；
   - 模型过期（>30 天未重训）自动降级为规则基线并标注。

### 4.6 分阶段

| 阶段 | 内容 | 产出 | 预计 |
|---|---|---|---|
| P0 | 特征构建 + purged walk-forward 骨架 + 规则/LR 基线 | OOS 报告（5 指数 × 3 horizon），杀判据初判 | 2–3 天 |
| P1 | GBM + 校准 + API + UI 概率面板（影子） | 可看的概率序列与评估条 | 3–5 天 |
| P2 | 外部数据同步（两融/北向/宏观/新闻情绪历史） + 重训 | 增量特征 A/B 报告 | 3–5 天 |
| P3 | 集成/regime 条件模型 + 3 个月影子监控 | 是否接入决策的评审材料 | 1 季度 |

## 5. 「基于现在的数据可以做吗？」

- **可以**：P0/P1 所需数据全部在库（2016–2026 指数 + 全市场截面 + 成分 + 规则 regime + HK/US 指数）。
- **不可以（暂时）**：宏观（利率/PMI/CPI）、两融、北向、资金流、新闻情绪历史——新闻/微观只有约 2 个月，不能进 10 年训练；需要新增历史同步（Phase 2）。
- **样本量现实**：2,623 个交易日；H=10 的有效独立窗口约 260；预期 AUC 0.55–0.62、命中率 55–60%。任何「80%+ 准确率」的说法都不现实，除非偷看未来或只在单边行情上评估。
