# 滚动建仓 · 可交易性与统计折叠 细案（2026-10-21）

## 1. 需求

用户原话：

> 顶部统计的窗口可以折叠吗、还有 st 的股票、成交量低的不能买入、需要根据成交金额调整买入的股票。

拆成三件事：

1. **顶部统计条可折叠**：`PortfolioMetricsStrip` 当前常驻三行，占满首屏；要能一键收起（状态本地记忆）。
2. **ST/退市、低成交额标的不建仓**：滚动建仓的每日批次里，入选但不可交易的标的不再按等权计入。
3. **按成交金额调整建仓金额**：单票建仓金额受 ADV20（20 日均成交额）× 参与率约束，超出部分留现金。

## 2. 数据事实（2026-10-21 实测）

- `stock_daily_latest.stock_name / is_st` 只有 **2026-09-07 ~ 2026-10-20** 的每日快照，且逐日**静态**
  （同一标的的名称在区间内不变；`is_st=198/日`、名称含 ST `209/日`，并集约 215 只）。
  历史回算只能按**当前截面**判定 → 展示面必须写明「静态口径，含前视偏差」，不得声称「已按历史时点剔除 ST」。
  参见记忆 `astock-no-per-day-st`。
- QuantDB `daily_unadjusted.amount` 与 `stock_daily_latest.amount` 单位均为**万元**，比较前 ×10,000 换成元。
- ADV20 计算：截至入选日（含）最近 20 个**有成交额**交易日，有效日 ≥15 才给出值；不足 → 视为「成交额缺失」。
- 滚动建仓的批次口径不变：入选日收盘建仓、次一交易日收盘结算；末列入选只作下一批次候选。

## 3. 交易口径（纯函数 `rolling_performance.py`）

每日批次的建仓计划：

```
budget = 当前权益 / 当日入选只数                  # 等权预算
for each pick:
    ST/退市                → skip_st          （静态截面）
    缺入选日收盘价          → skip_no_price
    缺 ADV20               → skip_no_amount
    ADV20 < min_adv        → skip_low_adv     （默认 1 亿）
    value = min(budget, ADV20 × participation) （默认参与率 1%）
    value <= 0             → skip_low_adv
    否则                    → bought（末日为 next_day：候选，不建仓）
```

- `invested = Σ value`，`cash = 权益 − invested`；**不为凑仓位放宽门槛、不做替补**。
- 批次收益：`w_i = value_i / 权益`，
  `batch_return = Σ_{可计价} w_i·r_i ÷ Σ_{可计价} w_i × Σ_{全部已建仓} w_i`
  —— 缺退出价的标的不计价但不改变仓位占比，现金按 `1 − invested` 拖累收益。
  - 当成交额不可用、每只都按 `budget` 建仓时，该式退化为旧的等权均值（现有金样不变）。
- 末日（最后一列）的标的不建仓：可交易者状态 `next_day`，不可交易者仍显示具体跳过原因。
- 成交额或风险标记数据源不可用：**不做隐性过滤**。成交额缺失 → 等权回退（警告
  `tradability_unavailable`）；ST 源故障 → 本轮不剔除（警告 `st_filter_unavailable`）。
  硬条件缺席必须在响应里说清楚，不能静默。

### 3.1 汇总字段

`summary.performance` 新增：

| 字段 | 含义 |
| --- | --- |
| `capacity_applied` | 是否实际应用了成交额约束 |
| `st_filter_applied` | 是否实际应用了 ST/退市过滤 |
| `evaluated_picks` | 各批次候选标的合计（不含末列） |
| `bought_positions` | 实际建仓标的合计 |
| `skipped_st` / `skipped_low_adv` / `skipped_no_amount` / `skipped_no_price` | 各类跳过计数 |
| `min_adv_yi` / `adv_participation` / `adv_lookback_days` / `min_adv_days` | 本轮生效门槛 |
| `no_position_batches` | 全部标的被跳过、实际未建仓的批次数；`unpriced_batches` / `partial_batches` 只在 `bought > 0` 的批次上判定，跳过不算「缺价」 |

`batches[]` 新增 `bought`；每个批次 `positions`（候选）> `bought`（建仓）。

### 3.2 格子字段

`cells.by_day[day][symbol]` 新增：

- `buy_status`：`bought` / `next_day` / `skip_st` / `skip_low_adv` / `skip_no_amount` / `skip_no_price`；
- `entry_weight_pct`：按当日计划**次日将持有**的权重（跳过者为 0）；
- `adv_yi`：入选日 ADV20（亿元），缺失为 `null`。

`weight_pct`（当日实际持有权重）改为取**前一交易日计划**的权重；旧调用不传计划时保持等权回退。

## 4. 服务层（`ModelBlendService.rolling`）

- 新增入参 `exclude_st=True`、`min_adv_yi=1.0`、`adv_participation=0.01`。
- 仅 A 股（`market == CN`）读取成交额与风险标记：
  - `_amount_history(symbols, start, end)`：`fetch_daily_kline_batch(adjust="none")`，`amount × 10_000`，
    起点向前多取 60 个自然日以覆盖 20 个交易日；`asyncio.to_thread` 包裹同步 IO。
  - 风险标记复用 `_risk_flags`（当前截面 + 缓存）。
- 新增警告码：
  - `st_filter_static`：已按当前截面剔除，历史重算含前视偏差；
  - `st_filter_unavailable`：ST/退市数据源不可用，本轮未剔除；
  - `tradability_unavailable`：成交额不可用，未校验容量（等权回退）。
- 响应新增 `filters`：`market / exclude_st / st_applied / st_error / capacity_applied /
  min_adv_yi / adv_participation / adv_lookback_days / min_adv_days`。
  `st_error` 只回固定原因码 `risk_flags_unavailable`，异常原文仅进服务端日志（响应面不泄漏内部信息）。
- API `GET /api/v1/models/blends/{id}/rolling` 新增 query：`exclude_st`（默认 true）、
  `min_adv_yi`（默认 1，[0,1000]）、`adv_participation`（默认 0.01，(0,0.2]）。

## 5. 前端

### 5.1 统计条折叠

- `PortfolioMetricsStrip` 新增 `collapsible` / `storageKey` / `collapsedSummary`：右上角
  「收起统计 / 展开统计」按钮（`aria-expanded`），折叠态只留一行摘要
  （窗口收益 · 收益金额 · 建仓覆盖 · 期末现金），状态写 `localStorage`（值 `1`，展开时删除）。
- 滚动建仓面板传入 `storageKey="qm:combo:rolling:metrics-collapsed"`；共享组件默认不折叠，
  周期收益面板行为不变。
- 折叠不影响数据请求；展开后恢复全部四段（收益 / 风险 / 批次 / 执行）。

### 5.2 建仓状态

- 卡片新增状态标签（**不用红绿**，且不出现「买入/卖出」字眼）：
  - `bought` → `建仓 12.3%`
  - `next_day` → `次日建仓`
  - `skip_st` → `未建仓 · ST/退市`
  - `skip_low_adv` → `未建仓 · 成交额不足`
  - `skip_no_amount` → `未建仓 · 缺成交额`
  - `skip_no_price` → `未建仓 · 缺收盘价`
- 悬停统计追加「建仓比例 / ADV20」。
- 页脚口径说明补：ST/退市与低成交额不建仓；单票金额 = min(等权预算, ADV20×参与率)，余下留现金；
  ST 为静态截面口径。

### 5.3 指标条新增「执行」段

- 建仓覆盖：`已建仓 / 候选（覆盖率%）`，候选为 0 或字段缺失 → `—`；
- 容量约束：`1 亿 · 参与率 1.0%`（应用时，hover 给 ADV 窗口与有效日要求）/ `未启用`
  （A 股数据源故障）/ `不适用`（非 A 股市场，无统一成交额口径）；
- ST 过滤：`已启用`（hover 说明静态口径含前视偏差）/ `未启用`（A 股数据源故障）/
  `不适用`（非 A 股）/ `已关闭`（请求显式 `exclude_st=false`）；
- 跳过明细：`N 只`，hover 拆分 `ST/退市 · 成交额不足 · 缺成交额 · 缺入选价`；批次 hover 追加
  `无建仓 N 批`（仅新后端有该计数时显示，跳过批次不计入缺价/部分缺价）。
- 旧后端完全缺这些字段时**整段省略**（不是渲染一串 `—`）。
- 告警条只展示前 3 条：可交易性告警码（`tradability_unavailable` /
  `st_filter_unavailable` / `st_filter_static`）优先置顶，避免被成员级告警挤掉。

## 6. 测试与验收

后端（`backend/tests/test_rolling_performance.py`、`test_blend_service.py`）：

1. `trailing_adv` 取入选日（含）前 20 日、有效日 ≥15；
2. ST 跳过但其余标的等权建仓，现金留存，批次收益按 `invested` 缩放；
3. ADV < 门槛 → `skip_low_adv`；缺 ADV → `skip_no_amount`；
4. 参与率上限：`value = min(budget, ADV×participation)`；
5. 成交额不可用 → 等权回退，金样数值不变；
6. `cell_stats` 携带 `buy_status / entry_weight_pct / adv_yi`，当日权重取前一日计划；
7. 服务层：ST 命中、容量应用、数据源故障告警、非 A 股不取成交额、参数校验。

前端（`electron/src/features/inference-center-shared/__tests__/`）：

1. 折叠/展开切换、`localStorage` 记忆、折叠态摘要不含 `undefined`；
2. 状态标签文案与颜色类（无红绿、无买卖字眼）；
3. 指标条「可交易性」段：覆盖数、容量/ST 状态、旧后端字段缺失显示 `—`；
4. `npm run typecheck` 通过。

## 7. 风险与回退

- **前视偏差**：ST 只能按当前截面判定，已在警告与页脚明示；不做「历史时点 ST」的伪精确。
- **性能**：每轮多一次 parquet 读取（与 `_close_history` 同量级），放线程池；失败降级为等权。
- **兼容**：新字段全部可选；旧后端响应在前端显示 `—`，不渲染 `undefined`。
- **回退**：前端隐藏「可交易性」段即可；后端把 `exclude_st=false, min_adv_yi=0` 即回到等权口径
  （成交额仍会读取，但门槛为 0 时只受参与率约束；如需完全关闭容量约束，可后续加 `adv_participation` 上限参数）。
