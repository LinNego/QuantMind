## 3. 已知风险点（请优先验证，不必重复发现）

### A. 选股时用到了 T+1 的可成交性（**我认为是真实存在的小偏差**）

`universe()` 在 175 行用 `panel.fwd_ret.notna()` 剔除「T+1 停牌 / 开盘一字涨停」的标的，
而 `run_strategy()` 之后才从**已剔除**的池子里选 top40。

含义：**用「明天买不进」来决定「今天选谁」**。严格做法是先选 40 只、再剔除买不进的、
用后面的票补位（或干脆只买 39 只）。

影响量级（已实测修正）：全样本 7,778 行被这条规则剔除（1.50%），拆开看是
**未来退出价缺失 2,740 行（0.53%）+ 涨跌停缺口 4,667 行（0.90%）+
停牌 513 行 + 入场价缺失 498 行**（有重叠）。

**这里我之前判断错了**：7,778 行里约三分之一与"未来退出价缺失"有关，
方向是**高估**收益（提前删掉了后来停牌/退市的票），不是低估。
对 top40 的实际影响：5,091 个槽位里 94 个（1.85%）被替换，129 期里有 56 期受影响。

详见 [代码审查报告](./代码审查报告_低价小市值回测.md) 的 P1-1。

### B. `features_daily` 的财务/估值字段时点未验证（**未验证，可能有时点问题**）

`pe_ttm` / `pb` / `net_profit_ttm` / `revenue_ttm` / `equity` 由外部特征服务写入，
**不清楚是否按公告日（`m_anntime`）滞后对齐**。若用「当期财报」而非「已公告财报」，
则「剔除亏损」「BP/EP 因子」这两处存在未来函数。

影响：这两项结论都已被否决（剔除亏损年化掉到 10.4%），**不影响主结论**，
但因子体检表里的 BP/EP 两行要打折看。

### C. `is_quit_risk` 的 point-in-time 性未验证

母文档验证过 `is_st` 是 PIT（600518 康美 2018=0、2020=1、2026=0），
但 `is_quit_risk` 只做了类型漂移修复（`pd.to_numeric`），**没有做过时点抽查**。

### D. 卖出侧不可成交未建模

只建模了买入侧（停牌 / 一字涨停），**没有建模跌停卖不出**。2024-01 那种连续跌停的月份，
真实亏损会比回测更深。已在文档 §5.2 说明。

### E. `simulate_lots()` 的估值口径（已重写三次，仍建议复核）

- 面板里 `o_in`/`o_out` 是**后复权**开盘价，不能直接当成交价；
- 代码用 `scale = adj_close / px` 还原真实买入价（`real_in = o_in / scale`）做整手取整；
- 收益用后复权价之比 `fwd_ret`；净值由逐期净收益重建。

需要确认：`scale` 在买入日与卖出日不同（分红除权）时，这个近似是否引入系统性偏差。

### F. `stress_survivorship()` 用了当期 `fwd_ret`

第 502 行 `drag = Σ (loss - h.fwd_ret[hit]) / n`，用当期实际收益去调整冲击幅度。
这是**压力测试的模拟**，不是回测，逻辑上可以接受；但审查时请确认它没有被当作收益来源。

### G. 对冲的贴水是外生假设

`run_hedge()` 里 `basis` 参数（5%/8%）是拍的，不是从真实基差数据估的。

### H. 择时在「当日收盘」判定、当日收盘下单

A 股月末收盘价在收盘那一刻才确定，实盘只能收盘前决策或次日开盘执行。
回测里用当日收盘价算 MA200 并假设当日成交，有轻微执行偏差（方向未知）。

## 4. 建议的验证手段

1. **时序插桩**：在 `build_panel()` 后 dump 某一期的 `signal_dt/entry_dt/exit_dt` 三元组，
   人工核对「信号日收盘 → 次日开盘买入 → 下次次日开盘卖出」是否符合 A 股 T+1 规则；
2. **未来数据探测**：把 `fwd_ret` 随机打乱后重跑，年化应掉到 0 附近；若不掉，说明还有别的泄漏；
3. **滞后一期的敏感性**：把全部因子整体 `shift(1)`，看结论是否崩塌；
4. **抽查事件表**：随机抽 20 条立案公告，去巨潮核对 `announce_date` 是否为披露日而非公告日；
5. **复算面板**：用 `--build` 重建 `/tmp/lp_panel.parquet`，与 `docs` 里的数字对照，
   确认「文档数字 = 代码输出」。
