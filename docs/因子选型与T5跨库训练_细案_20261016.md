### 1.4 训练机制（已核对代码，全部可用）

- **跨库组合**（2026-09-23 落地，`admin_training_utils._resolve_quantdb_factor_payload`）：
  载荷 `factor_source`（锚库）+ `factor_catalog_versions:{库: 版本}` + `features` 写裸名
  （锚库）或 `"库:列"`（副库）；产出 `factor_field_sources` 供训练容器
  `QuantDBFactorReader.read_range` 读时拼接。CN 市场 14 库全部有 published 版本。
- **训练不做筛选**：`factor_selection.method=""` 时筛选代码块整段跳过（train.py 判定
  `in ("ic_icir","combined")` 才执行）；配合 `pfs_enabled=false / dh_enabled=false` 显式关闭。
- **T+5 标签口径**（docker/training/data/loading.py）：直读因子源下
  `label = close(t+1+5)/close(t+1) − 1`（`_EXECUTION_LAG_DAYS=1`），先剔除节假日填充行
  （全市场 volume==0 的假交易日），再按标的 shift。收益目标做**截面 rank(pct)−0.5**。
- **产物**：LightGBM → `model.lgb` + `pred.parquet` + `pred.pkl` + `metadata.json` +
  `config.yaml` + `result.json`（`required_artifacts` 照录）。
- **串行锁**：训练单飞（P0-3），占用即 409；训练与 40G 级探针绝不同时跑。

## 2. 「近期预测性」口径（与训练逐字一致，可审计）

对 957 因子逐一计算**近窗截面 IC 时序**（产物留档）：

- **标签**：与训练完全同口径——锚库 l1_factors 的 close，剔节假日填充行，lag=1、horizon=5，
  `label(t)=close(t+6)/close(t+1)−1`。
- **窗口**：主窗 **2025-09-01 .. 2026-09-10**（≈245 交易日，t+6 完整）；
  对照窗近 6 个月（≥2026-03-10）。每因子按各自库分区可得日期计算，缺列/缺期的日期
  （成对完整样本 < 300 只）跳过并记 `n_dates`。
- **统计**：逐日 Spearman IC → 主窗 `ic_12m / icir_12m(=mean/std) / win_12m(与均值同号占比) /
  n_dates`，对照 `ic_6m / icir_6m`；全史口径沿用筛选产物（ic_mean/icir）入报告。
- **入选门槛**：`n_dates ≥ 120` 且 `|ic_12m| ≥ 0.01`（对齐平台默认 ic_threshold），
  门槛只用于剔除近期失效者，排序主键 = **|icir_12m|**（收益强度 × 稳定性），
  同分按 |ic_6m|、|全史 icir|、名称定序（完全确定）。
- 产物：`recent_ic.parquet`（因子 × 日期 × ic × n_valid，逐日可审计）。

## 3. 300 选型算法（确定性，可复跑）

1. **小类全取**：可训数 ≤15 的类别（风格 12、财务质量 6、概念 5、估值 3、成长 2）过门槛者
   全取（≈28 个）。
2. **大类配额**：其余 8 类按 √n 分配剩余 ~272 席（对极端不均衡做平方根压缩）：
   量价 51 / 其他 42 / 微观 39 / 经典 38 / 形态 37 / 资金流 26 / 波动 23 / 动量 16；
   类内按 |icir_12m| 取前 quota 名；某类不足则余额顺延给尚有结转的类。
3. **冗余终检**：用筛选产物的池化联合相关矩阵（`cross_corr.npz`，2520×2520）做
   **类内/全局 |ρ|≥0.85 贪婪剔除**（被剔者同类别顺位替补，替补亦须过 0.85 闸），
   记录剔除与替补明细（984 进 300 已过 0.9 闸，此处是位内精修，幅度预计很小）。
4. 产物：
   - `training_selection_300.json`：300 条明细（近窗统计 + 类别 + 库 + 全史口径 + 替补记录）
     + 配额表 + 排除清单（27 条）+ 训练载荷片段（`库:列` features 数组、版本 map、split、label）。
   - `训练选型报告_20261016.md`：984→957→门槛→300 全链漏斗、各类 Top 清单、排除说明。

## 4. 训练载荷（LightGBM T+5 跨库，参数定稿）

- 算法选型：**LightGBM**（首选）——平台先例（p2 树探针）、NaN 原生处理（跨库覆盖差异）、
  8.6M×300 规模下最快；XGB/CatBoost 变体由技能一键换参复跑（`model_type` 参数）。
- `job_name: T5_Cross300_LGB_20261016`，`display_name: T+5 跨库300因子 LightGBM`。
- **特征**：300 条 `库:列`（锚库 l1_factors 写裸名）；`factor_catalog_versions` 显式钉各库
  published 版本；`factor_source: l1_factors`。
- `label`: horizon=5、mode=return、effective_trade_date/training_window 空。
- `split`: train 2020-01-02..2025-11-25 / valid 2025-12-04..2026-06-15 / test 2026-06-25..2026-09-10。
- `model`: type=lightgbm、params={}（走平台默认：lr 0.02、num_leaves 31、min_data 300、
  ff 0.6、bagging 0.7/5、l1 0.5、l2 1.0）、num_boost_round=2000、early_stopping=100、
  ensemble=none。
- `factor_selection`: method=""、n_top=300、pfs/dh=false（显式关闭，防注入）。
- `explain`: SHAP 开（valid 抽样 30000，供后期分析）；`deploy_to_production: false`。
- `context`: market=CN、benchmark=SH000300、费率/滑点 0.0005、deal_price=close。
- 提交：`POST /api/v1/models/run-training`（admin 登录）；**提交后回读
  `data/training_jobs/<run_id>/config.yaml` 断言**：features 数=300、label.horizon=5、
  method 空、无被静默裁列。

## 6. 风险与回退

- **读取端 schema 断层**（某库某期缺列）：逐库 try→可用列交集+补 NaN 降级（沿用筛选器同款），
  缺列因子自然落入 n_dates 门槛；不静默出错。
- **训练 OOM**：先算后训、串行锁、不与重活并发；若 valid/test 帧峰值超限，回退
  train 2022-10 起（缩窗再训）。
- **31 条兜底**：若 0.85 终检把某小类掏空到 0，报告如实呈现（不为凑数放宽闸门）。
