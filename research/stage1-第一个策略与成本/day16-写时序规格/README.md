> 阶段 1 · 第一个策略与成本 ｜ 第 16 天 ｜ 状态：⬜ 未开始

## 今天要干嘛

画出一条时间线，标出「做决定」和「成交」两个点。

## 要看懂什么

- [常见陷阱与自检红线](../../参考/常见陷阱与自检红线.md) 第 2 节（未来函数）

## 具体做法

```markdown
### 时序
- T 日 15:00 收盘，用 **T 日收盘价**算出 score（此时已知，合法）
- T+1 日 **开盘价**成交（T+1 开盘时，T 日收盘数据已经知道）
- 持仓收益从 **T+1 收盘**算到 **T+2 收盘**（或按估值日对齐）
- 绝不允许：用 T 日收盘价打分，又用 T 日收盘价成交
```

## 完成判据

能画出一条时间线，标出「决定」和「成交」两个点，且**决定在前、成交在后**。

## 当天总结

这条线画错，后面全白做。

```
T 日 15:00  ── 收盘，数据到齐 ──→ 你算出 score（合法）
T+1 09:30  ── 开盘，你下单   ──→ 成交（合法）
T+1 15:00  ── 收盘          ──→ 开始吃收益
```

代码里对应的就是那一行：

```python
nav = (w.shift(1) * ret).sum(axis=1)   # ✅ 昨天的决定，吃今天的收益
nav = (w * ret).sum(axis=1)            # ❌ 拿今天的决定，吃今天的收益
```

**这是整个阶段 1 唯一需要你盯死的一行代码。** D19 会专门验收它。
