# D14 · 写因子规格

> 阶段 1 · 第一个策略与成本 ｜ 第 14 天 ｜ 状态：⬜ 未开始

## 今天要干嘛

把 `1/pe_ttm` 写成一段**别人照着能实现出同一个东西**的文字。

## 要看懂什么

- [核心概念速通](../../参考/核心概念速通.md) 第 4 节（因子）

## 具体做法

```markdown
### 因子
- 公式：score = 1 / pe_ttm
- 方向：越大越好（PE 越低越好）
- 用哪列：valuation.pe_ttm（**不是** features_daily 的同名列）
- 取值日：T 日**收盘后**已知的最新值
- 需要多少历史：0 天（只用当日）
- 异常处理：pe_ttm ≤ 0 剔除；pe_ttm 为 NULL 剔除
- 停牌复牌后前 20 个交易日不计算
```

## 完成判据

别人照着这段能写出**同一个**因子；没有一处写「大概」「差不多」。

## 当天总结

**三个必须写明的点：**

**① `pe_ttm ≤ 0` 要显式剔除。**
2024-06-28 全市场 5,278 只里有 **1,140 只 PE ≤ 0**（21.6%，都在亏钱）。
`1/负数` 得到负数，排名自动掉到最后——这是**偶然正确**，不是设计。
如果哪天出现 `pe_ttm = 0.5`（正数极小），`1/0.5 = 2.0` 会直接顶到第一名。**必须显式剔除。**

**② 停牌复牌后要冷却。**
`shift(20)` 数的是**行**不是天。深深房A 停牌 4 年，复牌当天往回数 20 行会拿到 2016 年的价格，
算出来的「20 日动量」其实是「四年涨幅」。

**③ 用哪一列要写死。**
`features_daily` 里也有一个 `pe_ttm` 列，但那张表**不含北交所**。用哪个必须写清楚。
