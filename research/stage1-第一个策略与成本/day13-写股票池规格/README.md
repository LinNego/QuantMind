# D13 · 写股票池规格

> 阶段 1 · 第一个策略与成本 ｜ 第 13 天 ｜ 状态：⬜ 未开始

## 今天要干嘛

写清「哪些股票可以进池子、哪些绝对不行」，以及**每项过滤剔掉多少只**。

## 要看懂什么

- [验收清单](../../参考/验收清单.md) 第 ② 问（股票池）
- [验收清单附录：给 AI 的规格模板](../../参考/验收清单.md)

## 具体做法

用模板填「股票池」一段，**四项缺一不可**：

```markdown
### 股票池
每个交易日 T，从全市场选出满足以下全部条件的股票：
1. 非 ST：剔除名称含 ST / *ST / S 的股票
2. 未停牌：剔除 volume = 0 的；且剔除「最近 20 个交易日无数据」的
3. 非新股：剔除上市不满 60 个交易日的
4. 可交易：剔除 T 日涨停（买不进）和跌停（卖不出）的

每项过滤后剩余多少只？（必须给出数字）
```

## 完成判据

四项过滤都写清，且每项都有「剔掉多少只」的实测数字。

## 当天总结

**为什么必须写四个数字**：不写数字，AI 会自作主张；写了数字，你才能验证它实现对了。

四个数字从哪来——阶段 0 已经全部算过：

| 过滤项 | 从哪来 | 已知量 |
|---|---|---|
| ST | D04 | 2024-12-31 有 **100 只** |
| 停牌 | D04 + D09 | `volume = 0` **254 行**；长期停牌**整行消失**（两种都要滤） |
| 新股 | D05 | 2024-12-31 上市不满 3 个月的有 **22 只** |
| 涨跌停 | D05 | 按板块分档：主板 10 / 双创 20 / 北交所 30 / ST 5 |

⚠️ **停牌是最容易漏的一项**：只写 `volume > 0` 滤不掉长期停牌，
只写「近 20 天有数据」滤不掉当天的临时停牌。**两条都要写。**
