# D24 · T+1 与成交价

> 阶段 1 · 第一个策略与成本 ｜ 第 24 天 ｜ 状态：⬜ 未开始

## 今天要干嘛

对比无 shift / shift(1) / shift(2) 三个版本，判断**哪种最接近现实**。

## 要看懂什么

- [验收清单](../../参考/验收清单.md) 第 ① 问

## 具体做法

改一行，跑三遍：

```python
nav = (w          * ret).sum(axis=1)   # 无 shift
nav = (w.shift(1) * ret).sum(axis=1)   # T+1
nav = (w.shift(2) * ret).sum(axis=1)   # T+2
```

再把成交价从不复权换成前复权，再跑一遍。

## 完成判据

三种差多少，**哪种最接近现实**，并说清为什么。

## 当天总结

**判据**：

- `shift(0)` → 用了当天收盘才知道的信息，**不可能实现**
- `shift(1)` → T 日收盘决策、T+1 建仓，**最接近现实**
- `shift(2)` → 保守，适合流动性差的票

**成交价必须用不复权**（`ku`），不是前复权。用前复权当成交价会**少算约 27% 的钱**
（2019-12-31 均值 12.06 vs 16.50）。
