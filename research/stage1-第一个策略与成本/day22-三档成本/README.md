# D22 · 三档成本

> 阶段 1 · 第一个策略与成本 ｜ 第 22 天 ｜ 状态：⬜ 未开始

## 今天要干嘛

成本设 0 / 0.1% / 0.3% 跑三遍，看三条线怎么分开。

## 要看懂什么

- [常见陷阱与自检红线](../../参考/常见陷阱与自检红线.md) 第 5 节（成本）

## 具体做法

同一份代码，只改滑点参数：

| 版本 | 滑点 |
|---|---|
| A | 0 |
| B | 0.1% / 边 |
| C | 0.3% / 边 |

画一张图，三条净值线放一起。

## 完成判据

三条线明显分开，且能读出「哪一段差得最多」。

## 当天总结

**看什么**：不是看最终差多少，是看**差距随时间怎么扩大**。

如果三条线几乎重合，说明你的换手率很低（好事），或者**成本根本没被扣**（坏事）。

先查后者。
