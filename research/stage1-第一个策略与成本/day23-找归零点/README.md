# D23 · 找归零点

> 阶段 1 · 第一个策略与成本 ｜ 第 23 天 ｜ 状态：⬜ 未开始

## 今天要干嘛

把成本从 0 扫到 0.5%，找出「多高成本下收益归零」。

## 要看懂什么

- 先看 [D22](../day22-三档成本/README.md) 的三条线

## 具体做法

滑点按 0.05% 步长从 0 扫到 0.5%，每次跑一遍，记录年化。

画一张「成本 vs 年化」的曲线，找它穿过 0 的位置。

## 完成判据

能答出「多高的单边成本下，这个策略收益归零」。

## 当天总结

**这个数字就是策略的「成本安全边际」。**

- 归零点在 0.3% 以上 → 还有点空间
- 归零点在 0.15% 以下 → 你的策略只能在**极低费率**下活，实盘基本没戏

**Gate 2 的第一问就是它。**
