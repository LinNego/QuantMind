# D20 · 验收 ③④

> 阶段 1 · 第一个策略与成本 ｜ 第 20 天 ｜ 状态：⬜ 未开始

## 今天要干嘛

查成本四项是否齐全，查热启动天数是否够。

## 要看懂什么

- [验收清单](../../参考/验收清单.md) 第 ③ 问（成本）与第 ④ 问（回测窗口）

## 具体做法

### ③ 成本四项

```bash
grep -n "commission\|stamp\|transfer\|slippage" code.py
```

逐项对照 D17 的规格，看费率、方向（单边/双边）对不对。

### ④ 窗口与热启动

- 回测区间是什么？起点是不是 **2017-01-16** 之后？
- 因子需要 20 日历史 → 前 20 个交易日是不是**只用于预热、不计入收益**？
- `pe_ttm` 在 2017-01-16 之前是 NULL，代码怎么处理的？

## 完成判据

能说出年换手、成本占比、热启动多少天。

## 当天总结

**这三个数字要能立刻报出来：**

| 数 | 怎么算 |
|---|---|
| 年换手 | 一年内买卖金额 / 平均持仓市值 |
| 成本占比 | 总成本 / 总收益 |
| 热启动天数 | 因子最长回看窗口 + 缓冲（20 日因子 → 至少 25 天） |

**最常见的错**：回测起点写了 2016-01-04，但 `pe_ttm` 到 2017-01-16 才有值。
结果 2016 年整年空仓，净值曲线是一条直线——**不报错**。
