```

   0.0  254.0     0.0  254.0
```

→ 254 条 `volume=0` 基本是**停牌日**（有收盘价、无成交），不是脏数据；但它会让换手率的分母为零，因子计算时要剔除或填 NaN。

## 5. 涨跌幅超档：不复权 vs 前复权

> 两个必须做的对齐：① 先按 `trading_calendar` 取**相邻交易日**，否则停牌半年后复牌那两行会被算成「一天涨 488%」；② 剔除 `volume=0` 的停牌行（数据里停牌日仍有行、价格不变），否则复牌那天会被算成暴跌；③ 再区分**上市满 60 日**，新股前 5 日无涨跌幅限制。

```
 口径  板块     范围      样本   超档条数   单日最大
不复权  主板 上市前60日  187972  164.0 177.74
不复权  主板 上市满60日 7100069 2688.0  76.46
不复权 北交所 上市前60日   20097    2.0  49.95
不复权 北交所 上市满60日  255642   82.0  71.35
不复权  双创 上市前60日  119074  216.0 257.42
不复权  双创 上市满60日 3130239 1896.0  76.67
前复权  主板 上市前60日  187972  120.0 177.74
前复权  主板 上市满60日 7100069    2.0  10.83
前复权 北交所 上市前60日   20097    0.0  30.00
前复权 北交所 上市满60日  255642    0.0  30.00
前复权  双创 上市前60日  119074  185.0 257.42
前复权  双创 上市满60日 3130239    0.0  20.55
```

→ **不复权**满 60 日仍有 4600+ 条「超档」，几乎全是**除权除息跳空**（10 送 10 就是 -50%）；**前复权**下同样的检查几乎归零。所以：算收益/算涨跌幅用前复权，看真实成交价用不复权 —— 这就是三套日线存在的理由。

## 6. 三套日线差多少（000001.SZ，平安银行）

```
      dt   不复权   前复权   后复权
20160104 11.33  6.87 11.33
20200102 16.87 12.97 21.40
20261023 11.20 11.20 18.48
```

→ 同一天同一只股票，三个价格差 1.6 倍。**不复权**回答「我买得起吗」，**前复权**回答「持有到今天赚多少」，**后复权**回答「从上市那天算涨了几倍」。混用就是静默错误。
