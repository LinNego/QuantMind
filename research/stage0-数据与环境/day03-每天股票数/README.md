# D03 · 每天股票数

> 阶段 0 · 数据与环境 ｜ 第 3 天 ｜ 状态：✅ 已完成

## 今天要干嘛

看清「每天有多少只股票在交易」，并且知道它是**逐年增长**的，不是恒定 5000。

## 要看懂什么

- [参考/表结构.md](../../参考/表结构.md) 里的 `trading_calendar`，以及日线的 `dt` 分区

## 具体做法

按年统计当年出现过的股票数：

```sql
SELECT dt // 10000 AS 年份, count(DISTINCT symbol) AS 只数
FROM kf GROUP BY 1 ORDER BY 1;
```

想更严格就只取每年最后一个交易日。

## 完成判据

能说出「2016 年 2 千多 → 2026 年 5 千多」，并知道为什么。

## 当天总结

```
2016  2804      2021  4492
2017  3232      2022  4920
2018  3337      2023  5233
2019  3539      2024  5333
2020  3972      2025  5449
                2026  5581
```

**单调上升，没有任何一年下降。**

2016 年只有 2,804 只，不是数据缺失——D09 验证过：2017 年新增的 428 只全部是真实 IPO
（首次出现日期散在 2017 各月，最大单日仅 5 只），对照现实 2017 年 A 股 IPO 438 家，量级吻合。

**为什么重要**：如果某天突然只有 500 只股票，你的截面排名当天就是垃圾。
这类问题只有这种统计能发现。
