# D08 · 复权三兄弟

> 阶段 0 · 数据与环境 ｜ 第 8 天 ｜ 状态：✅ 已完成

## 今天要干嘛

说清前复权 / 后复权 / 不复权各用在哪，并且**举一只股票证明它们不一样**。

## 要看懂什么

- [常见陷阱与自检红线](../../参考/常见陷阱与自检红线.md) 第 2.3 节（复权那几段）

## 具体做法

把同一天三个口径并排放：

```sql
SELECT
  (SELECT avg(close) FROM kf WHERE dt = 20191231) AS 前复权,
  (SELECT avg(close) FROM ku WHERE dt = 20191231) AS 不复权,
  (SELECT avg(close) FROM kb WHERE dt = 20191231) AS 后复权;
```

## 完成判据

能说清三个口径的锚点各是什么，以及**买入成交价该用哪个**。

## 当天总结

2019-12-31 全市场平均价：

| 口径 | 均值 |
|---|---|
| `kf` 前复权 | **12.06** |
| `ku` 不复权 | **16.50** |
| `kb` 后复权 | **23.65** |

| 序列 | 锚点 | 谁被改写 |
|---|---|---|
| 前复权 | 以**今天**为基准 | **历史**被改写（每次分红送股重算） |
| 后复权 | 以**上市首日**为基准 | **今天**被改写，历史永不变 |
| 不复权 | 交易所真实价 | 谁都不改 |

**一句话判据**：这个数字是**「钱」**还是**「涨跌幅」**？是钱 → 不复权；是涨跌幅 → 复权。

⚠️ 另有一个陷阱：`features_daily.close` **是后复权**，不是成交价（与 `kb` 逐行相同）。
