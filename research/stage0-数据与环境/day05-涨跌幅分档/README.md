## 今天要干嘛

按板块分档查单日涨跌幅超档，找出「不可能存在」的涨跌。

## 要看懂什么

- 先复习 [D04](../day04-脏数据/README.md) 的结论，再读 [常见陷阱与自检红线](../../参考/常见陷阱与自检红线.md) 关于涨跌停的段落

## 具体做法

**别用一刀切的 ±10%。**

| 板块 | 代码开头 | 档位 |
|---|---|---|
| 主板 | 60 / 00 | **±10%** |
| 创业板 / 科创板 | 30 / 68 | **±20%** |
| 北交所 | 43/83/87/88/92 | **±30%** |
| ST | 同上 | 主板 **±5%** |

```sql
WITH z AS (
  SELECT symbol, dt, close, lag(close) OVER (PARTITION BY symbol ORDER BY dt) AS pc
  FROM kf
)
SELECT symbol, dt, round((close/pc - 1) * 100, 2) AS 涨幅
FROM z WHERE pc > 0 AND abs(close/pc - 1) > 0.30 AND dt >= 20170101
ORDER BY 涨幅 DESC;
```

## 完成判据

得到异常条数，并且能解释它不是数据坏了。

## 当天总结

超档 **8 条，全部来自同一只股票 `301569.SZ`**，连续 8 天 `zaf = 401.71%`。

原因是**新股上市首日无涨跌幅限制**，而基准价用了发行价（不是首日收盘价），
所以第二天算出来的「涨幅」是几百个百分点。

**不是数据坏了，但必须从因子计算里剔掉**——否则这只股票会在动量因子里排第一名。
D13 的股票池因此要加一条「上市不满 60 天剔除」。
