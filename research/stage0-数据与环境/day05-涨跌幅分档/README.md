# D05 · 涨跌幅分档

> 阶段 0 · 数据与环境 ｜ 第 5 天 ｜ 状态：✅ 已完成

## 今天要干嘛

按板块分档查单日涨跌幅超档，找出「不可能存在」的涨跌。

## 要看懂什么

- 先复习 [D04](../day04-脏数据/README.md) 的结论，再读 [常见陷阱与自检红线](../../参考/常见陷阱与自检红线.md) 关于涨跌停的段落

## 具体做法

**别用一刀切的 ±10%。**

| 板块 | 代码开头 | 档位 |
|---|---|---|
| 主板 | 60 / 00 | **±10%** |
| 创业板 / 科创板 | 30 / 68 | **±20%** |
| 北交所 | 43/83/87/88/92 | **±30%** |
| ST | 同上 | 主板 **±5%** |

```sql
WITH z AS (
  SELECT symbol, dt, close, lag(close) OVER (PARTITION BY symbol ORDER BY dt) AS pc
  FROM kf
)
SELECT symbol, dt, round((close/pc - 1) * 100, 2) AS 涨幅
FROM z WHERE pc > 0 AND abs(close/pc - 1) > 0.30 AND dt >= 20170101
ORDER BY 涨幅 DESC;
```

## 完成判据

得到异常条数，并且能解释它不是数据坏了。

## 当天总结

同一件事，**四套口径四个答案**：

| 算法 | 超档条数 | 假在哪 |
|---|---|---|
| 不复权价算涨跌幅 | **5,227** | 除权除息日的会计缺口全被当成暴涨 |
| 前复权价算 | **338** | 复权对了，但还含停牌复牌首日 |
| 前复权 + 剔除复牌首日 | **297** | 剩下的是新股上市前 3 天 |
| `features_daily.zaf` | **0** | 上游已修复（2026-11 更新前是 8 条） |

**结论：超档全部是刚上市的新股。** 名单里每一只的首次交易日都在异常日前 2 天以内
（`601091.SH` 第 2 天、其余第 3 天）——新股头几天不设涨跌幅，而基准价用了发行价。

→ **股票池必须加一条：上市不满 60 个交易日的新股剔除。**

> 今天真正的收获不是「找到 297 条异常」，是**亲眼看见同一份数据在不同口径下能差 650 倍**。
> 以后别人给你一个「异常率 0.05%」的结论，你会先问一句：**复权了吗？跨停牌了吗？**
