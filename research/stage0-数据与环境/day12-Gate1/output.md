## Q1 三个价格序列分别用在哪

三者不是"三个数据源"，是**同一个价格的三种记法**。

2019-12-31 全市场平均收盘价：

| 口径 | 均值 |
|---|---|
| `daily_forward` 前复权 | 12.06 |
| `daily_unadjusted` 不复权 | 16.50 |
| `daily_backward` 后复权 | 23.65 |

同一批股票、同一天，三个数字。**用错了不报错，只是结论全错。**

### 三者的定义

| 序列 | 锚点 | 谁被改写 |
|---|---|---|
| `daily_forward` 前复权 | 以**今天**为基准 | **历史**被改写（每次分红送股后重算） |
| `daily_backward` 后复权 | 以**上市首日**为基准 | **今天**被改写（历史永远不变） |
| `daily_unadjusted` 不复权 | 交易所真实价 | 谁都不改 |

### 用在哪

| 场景 | 用哪个 | 原因 |
|---|---|---|
| 算收益率、画净值曲线 | forward | 除权日不会出现假跌 |
| 算因子（动量/波动率） | forward 或 backward | 只要全流程内部一致就行 |
| **真实成交价、整手计算** | **unadjusted** | 你下单时看到的就是这个数 |
| 市值 / 成交额 / 换手率 | unadjusted | 金额必须是真钱 |
| 涨跌停价判断 | unadjusted | 涨跌停按真实价格算 |
| 长期存档、结果要可复现 | backward | forward 会被**未来**的分红改写 |

### 一句话判据

> **问一句："这个数字是「钱」，还是「涨跌幅」？"**
> 是钱 → `unadjusted`；是涨跌幅 → 复权。

### 最容易犯的错

拿前复权价当成交价。2019-12-31 平均 12.06 vs 真实 16.50，**少算 27% 的钱**。
回测里这 27% 会变成"我能多买 37% 的股票"，净值凭空变好。

## Q2 数据规模

### 股票数逐年（最少的一年是 2016）

```
2804 → 3232 → 3337 → 3539 → 3972 → 4492 → 4920 → 5233 → 5333 → 5449 → 5581
2016   2017   2018   2019   2020   2021   2022   2023   2024   2025   2026
```

单调上升，无下降年份。2016 年少是因为当年上市公司本来就少（2017 年 IPO 438 家是历史大年），
**不是数据缺失**（见 `D09_survivorship.md` §4）。

| 数据集 | 最后一天 |
|---|---|

| `valuation` / `market_sentiment` | **2026-09-30** |

| 列 | 第一份非空 |

| `pe_ttm` / `pe_static` / `ps_ttm` / `net_profit_ttm` / `revenue_ttm` / `annual_net_profit` | **2017-01-16** |

## Q3 三个数据异常及其影响

### 异常 1：这份数据里没有退市股（幸存者偏差）

- **是什么**：十年里"消失"的只有 4 只，且全是长期停牌后复牌，**退市 0 只**。现实同期约 200 家。
- **影响**：**偏乐观**。你的股票池永远是"未来还活着"的股票，这是藏在数据里的未来函数，
  代码里 grep 不到。低 PE 策略受影响最大，粗估年化虚高 **1% 上下**。
- **处理**：结论写进日志；对外报收益时主动打折；不拿绝对收益数字做宣传。

### 异常 2：停牌有两种形态

- **是什么**：
  ① **短期停牌** —— 254 行有价格有行，但 `volume = 0`
  ② **长期停牌** —— 整行不存在（深深房A 4 年缺 1,006 天）
- **影响**：**偏乐观 + 假信号**。
  ① 给你一个假的可成交日，按收盘价"成交"了一笔不存在的交易；
  ② `shift(20)` 数的是**行**不是天，复牌当天往回数 20 行会拿到 **4 年前**的价格，
  算出的"20 日动量"其实是"四年涨幅"，代码里没有一行是错的。
- **处理**：股票池同时滤 `volume > 0` **和**"近 N 天有数据"（两条缺一不可）；
  因子加"复牌后 N 天内不计算"。

### 异常 3：各表时间终点与列起点不齐，join 静默出 NULL

- **是什么**：`valuation` 停在 2026-09-30，行情表到 2026-10-23，差 23 天。
  实测 join 后 **5,577 行、0 行有 `pe_ttm`**，不报错。
- **影响**：**偏悲观或直接算出垃圾**。若策略是 `1/pe_ttm`，PE 全空 → 全被剔除 → 那段时间等于空仓。
- **处理**：join 前先查两张表的 `max(dt)`；用 `INNER JOIN` 而非 `LEFT JOIN`；
  或在 SQL 里显式限定两边共同的日期区间。
