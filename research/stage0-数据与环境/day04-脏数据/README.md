# D04 · 脏数据

> 阶段 0 · 数据与环境 ｜ 第 4 天 ｜ 状态：✅ 已完成

## 今天要干嘛

找出「不可能存在」的行：收盘价 ≤ 0、成交量 ≤ 0、最高价 < 最低价。

## 要看懂什么

- [常见陷阱与自检红线](../../参考/常见陷阱与自检红线.md) 第 6 节（静默降级），理解为什么**不能靠看净值曲线发现问题**

## 具体做法

```sql
SELECT
  count(*) FILTER (WHERE close <= 0)  AS 收盘价非正,
  count(*) FILTER (WHERE volume <= 0) AS 成交量非正,
  count(*) FILTER (WHERE high < low)  AS 高低倒挂,
  count(*) FILTER (WHERE open <= 0 OR high <= 0 OR low <= 0) AS 其它非正
FROM kf;
```

## 完成判据

得到一张「异常条数」表，并且**能解释每一条是不是真异常**。

## 当天总结

| 检查 | 条数 | 解释 |
|---|---|---|
| `close ≤ 0` | **0** | — |
| `volume ≤ 0` | **287** | 临时停牌：有行、有价格（停牌前收盘价），但没有成交 |
| `high < low` | **0** | — |

**那 287 行是 D13 股票池必须滤掉的**——按收盘价「成交」一笔不存在的交易，是典型的假收益。

注意：这只覆盖了**短期停牌**。长期停牌（如深深房A 停牌 4 年）是**整行不存在**，
`volume ≤ 0` 查不出来，要用「近 N 天有没有数据」去查。两种形态见 [D09](../day09-幸存者偏差/README.md)。
