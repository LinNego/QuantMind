## 今天要干嘛

能用一行数字证明「我的单位是对的」。

## 要看懂什么

- [常见陷阱与自检红线](../../参考/常见陷阱与自检红线.md) 第 2 节（未来函数）

## 具体做法

算 `close * volume / amount` 的年度中位数：

```sql
SELECT dt // 10000 AS 年份,
       median(close * volume / amount) AS 比值中位数
FROM kf WHERE amount > 0 GROUP BY 1 ORDER BY 1;
```

## 完成判据

各年 ≈ 10000，并且**能说出这个 10000 是哪来的**。

## 当天总结

各年中位数都 ≈ **10,000**。

因为：`volume` 是**股**，`amount` 是**万元**。
`元 × 股 ÷ 万元 = 元 × 股 ÷ (元/10000) = 10000`。

**这条错了的后果**：所有换手率、资金流、成交额类因子会差 **1 万倍**，而代码**不会报错**。
