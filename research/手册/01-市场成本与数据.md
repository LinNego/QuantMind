## 1 先看清楚：你在跟谁做交易

### 1.1 牌桌上的六类人

| 参与者 | 靠什么赚钱 | 你的关系 |
|---|---|---|
| **散户** | 大多没有稳定优势，靠情绪和消息 | 你的主要对手盘，也是你自己 |
| **游资/短线** | 资金优势、情绪周期、封板 | 你抢不过他们的速度 |
| **公募** | 相对排名、规模、赛道 | 调仓慢、有最低仓位限制，行为可预测 |
| **私募/量化** | 因子、执行、风控、规模 | 你的直接竞争者 |
| **做市/高频** | 买卖价差、延迟 | 你打不过，别碰 |
| **产业资本/大股东** | 信息、成本、减持节奏 | 事件驱动的来源之一 |

**关键问题不是「谁厉害」，是「谁被迫交易」**：
指数调仓、基金申赎、解禁减持、打新冻结、季末考核——**被迫交易的人，才是稳定 alpha 的来源**。
这就是「结构性约束」类 alpha 的底层逻辑（见 README §1.1）。

### 1.2 你唯一的结构性优势

不是速度、不是数据、不是算力。是这三条：

1. **资金小**：可以进微盘、可以满仓几只票、可以一夜清仓。机构进不来也出不去。
2. **没有考核**：不用排名、不用季度汇报，可以承受 2 年不赚钱。
3. **可以不做**：没有仓位下限，看不懂就空仓。公募做不到。

> **推论**：你的策略应该长在「机构做不了」的地方，而不是「机构做得比你好」的地方。
> 所以微盘、低流动性、事件驱动、长持有期，比高频和因子竞赛更适合你。

### 1.3 一个判断练习

拿出一条你听过的策略，问三个问题：

1. 它赚的是谁的钱？（说不出来 → 大概率是数据挖掘）
2. 那个人为什么愿意亏？（被迫？情绪？信息差？）
3. 这个理由今天还成立吗？（2021 年的小市值逻辑，2024 年还成立吗？）

## 2 交易制度：每一条都会变成回测里的一个 bug

### 2.1 制度速查表

| 规则 | 内容 | 回测里会怎么错 |
|---|---|---|
| **T+1** | 当日买入，次一交易日才能卖 | 写成 T+0，日内反复交易，收益虚高 |
| **涨跌停** | 主板 ±10%；创业板/科创板 ±20%；北交所 ±30%；ST ±5% | 涨停价买入、跌停价卖出，实际成交不了 |
| **最小单位** | 主板/创业板 100 股整数倍；科创板 200 股起；北交所 100 股起、1 股递增 | 忽略整手，小资金实际买不满 |
| **停牌** | 重大事项可停牌数日到数月 | 停牌日当正常交易，或当 0 收益 |
| **退市** | 面值/财务/规范类退市；退市整理期可交易 | 只用「今天还活着」的股票 → 幸存者偏差 |
| **集合竞价** | 9:15–9:25 开盘，14:57–15:00 收盘 | 假设任意时点按收盘价成交 |
| **分红送转** | 除权除息日价格强制调整 | 不复权算收益 → 除权日凭空暴跌 |
| **融资融券** | 标的有限、券源有限、有成本 | 假设可以随便做空 |

### 2.2 涨跌停：不只是「不能成交」

三层影响，一层比一层隐蔽：

1. **买不进**：涨停价挂单排队，你的单子在队尾，大概率不成交。
2. **卖不出**：跌停时流动性消失，想止损也走不掉。
3. **信号失真**：涨停本身是强信号，但「涨停次日买入」的收益，和你回测里「按收盘价买入」完全是两回事。

仓库里的撮合器把这三层都实现了，值得逐行读：
[`ashare_matcher.py`](../../backend/services/simulation/services/ashare_matcher.py)
—— 停牌直接拒单、涨停拒买、跌停拒卖、成交价钳制在涨跌停内、按整手向下取整。

> **自检**：你的回测里，涨停日的买入单成交率是多少？如果接近 100%，这个回测是假的。

### 2.3 T+1 的连锁反应

T+1 不只是「当天不能卖」，它会改变策略的**可行域**：

- 日内反转、打板、T+0 网格，全部不可行（或用底仓模拟，成本另算）。
- 隔夜跳空成为主要风险来源：你 T 日收盘算信号，T+1 开盘才能买，中间隔着一条跳空。
- 止损变成「T+1 才能执行」，跌停时连 T+1 都执行不了。

**所以「信号价」和「成交价」之间必须至少隔一个交易日**，这是回测可信度的第一道门。

### 2.4 停牌、复牌、退市

| 情形 | 正确处理 | 常见错误 |
|---|---|---|
| 停牌期间 | 持仓按最后价冻结，不可交易，不计收益 | 当 0 收益 / 当可卖出 |
| 复牌首日 | 常有大幅补跌/补涨，涨跌幅限制可能不同 | 按停牌前价格直接算收益 |
| 退市 | 退市整理期卖出，或按退市价清算 | 直接从股票池消失，收益凭空保留 |
| ST/*ST | 涨跌幅 ±5%，流动性差，很多策略应剔除 | 不区分，和正常股一起排序 |

**幸存者偏差的定量影响**：只保留「今天还活着」的股票，会把每年退市/暴雷的样本删掉。
A 股每年退市几十家，十年累计几百家，且集中在「小市值+低价」——**恰好是微盘策略的重仓区**。
仓库里做过实测（[补退市股真实数据](../../docs/数据补全_退市股与监管事件.md)），结论是：
微盘类策略的真实收益比「干净数据」低一截，回撤更大。**这不是小数点问题，是策略生死问题。**

### 2.5 复权：三种口径，各管一件事

| 口径 | 定义 | 用在哪 | 不能用在哪 |
|---|---|---|---|
| **前复权** | 以最新价为基准，调整历史价 | 算收益率、算因子、画净值 | 算成交价、算涨跌停、算市值 |
| **后复权** | 以上市价为基准，调整后续价 | 长期收益、跨除权比较 | 同样不能当真实成交价 |
| **不复权** | 原始成交价 | 成交价、涨跌停价、整手、市值 | 直接算长期收益（除权日会断层） |

**仓库的约定**（`research/参考/表结构.md`）：

- `daily_forward` 前复权 → 收益与因子
- `daily_backward` 后复权 → 长期对比
- `daily_unadjusted` 不复权 → 成交与涨跌停

> **铁律**：收益用前复权，成交判定用不复权。混用一次，除权日的收益率就会出现 ±30% 的假跳变。

### 2.6 财报：报告期 ≠ 公布日

这是最容易被忽略的未来函数来源。

| 概念 | 例子 | 能不能用来做 2024-03-01 的决策 |
|---|---|---|
| 报告期 | 2023 年报（2023-12-31） | 不能，那时候还没出 |
| 公布日 | 2024-04-25 | 能，但只能从这天起用 |
| 预告/快报 | 2024-01-30 | 能，且更早，但数据质量差 |

**PIT（Point-in-Time）** 的要求：任何一条数据，都要带「市场第一次能看到它的时间」。
仓库的文本层用 `first_seen` 字段做这件事（见 [23 事件驱动系统总览](../参考/事件驱动系统总览.md)）。
财务数据没有现成的 PIT 字段时，**至少用公告日，不要用报告期**。

## 3 成本：唯一 100% 确定的负项

### 3.1 A 股费用表（2023-08-28 后）

| 项目 | 费率 | 方向 | 备注 |
|---|---|---|---|
| 佣金 | 0.025%（万 2.5） | 买卖双边 | **最低 5 元/笔** |
| 印花税 | 0.05%（万 5） | **仅卖出** | 2023-08-28 由千 1 减半 |
| 过户费 | 0.001%（万 0.1） | 买卖双边 | 沪深都收 |
| 冲击成本 | 默认 5bp | 买卖双边 | 与参与率非线性相关 |

来源：[回测费用配置说明](../../docs/回测费用配置说明.md)，代码常量在
[`ashare_matcher.py`](../../backend/services/simulation/services/ashare_matcher.py)。

### 3.2 最低佣金：小资金的隐形税

| 单笔金额 | 佣金 | 总成本（买卖一轮） | 占本金 |
|---|---|---|---|
| 10 万 | 25 元 | 102 元 | 0.102% |
| 1 万 | **5 元（触底）** | 15.2 元 | **0.152%** |
| 2000 元 | **5 元（触底）** | 约 11 元 | **0.55%** |

**结论**：本金越小、持仓越分散、调仓越频繁，最低佣金越致命。
10 万块分 20 只，每只 5000 元，一轮调仓光佣金就吃掉 0.2%——**这还没算滑点**。

> 所以小资金要么集中持仓（10 只以内），要么降低调仓频率。**分散是有成本的。**

### 3.3 滑点与冲击：平方根法则

滑点不是固定值，它随「你的成交量占市场成交量的比例」非线性上升：

```
单边冲击 ≈ k × 日波动率 × √(你的成交量 / 该股日均成交额)
k ≈ 0.5（经验系数，不同市场/流动性差异大）
```

| 参与率（你占 ADV） | 日波动 2% 时的单边冲击 |
|---|---|
| 1% | ≈ 0.10% |
| 5% | ≈ 0.22% |
| 10% | ≈ 0.32% |
| 25% | ≈ 0.50% |

**含义**：参与率从 1% 提到 10%，冲击只涨 3 倍；提到 25%，涨 5 倍。
**但容量是按「能接受的冲击」倒推的**：如果你只接受 10bp 冲击，参与率就得压到 1% 以内。

### 3.4 成本预算表（贴在墙上）

年双边换手 T = 全年成交金额 ÷ 平均资产。成本 ≈ T × 单边费率。

| 年双边换手 | 0.08%/边 | 0.12%/边 | 0.20%/边 |
|---|---|---|---|
| 200%（年调仓 2 次） | 0.16% | 0.24% | 0.40% |
| 600%（季度全换） | 0.48% | 0.72% | 1.20% |
| 1200%（月度全换） | 0.96% | 1.44% | 2.40% |
| 2400%（半月全换） | 1.92% | 2.88% | 4.80% |

**读法**：月频全换手的策略，成本底线是 2.4%~4.8%/年。
一个「年化 12%、IC 0.04」的策略，扣完成本可能只剩 8%——**这就是为什么低频策略更容易活**。

### 3.5 一个完整的例子（10 万本金，20 只，月度调仓）

| 项 | 计算 | 金额 |
|---|---|---|
| 月换手 | 假设每月换 50% 仓位 | 5 万/月 |
| 佣金 | 5 万 × 0.025% × 2（买卖） | 25 元/月 |
| 印花税 | 2.5 万 × 0.05% | 12.5 元/月 |
| 过户费 | 5 万 × 0.001% × 2 | 1 元/月 |
| 滑点 | 5 万 × 0.1% | 50 元/月 |
| **合计** | | **≈ 88.5 元/月 ≈ 0.089%** |
| **年化** | ×12 | **≈ 1.06%** |

> 这只是「温和换手」的成本。如果每月全换，年成本 ≈ 2.1%。**你的 α 必须先跨过这条线。**

## 4 数据：脏在哪，怎么体检

### 4.1 数据体检 10 项

以仓库 `data/quantdb` 为例（2016-01-04 ～ 2026-10-23，23 张表，约 10.8 GB）。

| # | 检查 | 怎么看 | 异常说明什么 |
|---|---|---|---|
| 1 | 股票数 / 交易日 / 区间 | `COUNT(DISTINCT symbol)` | 与预期不符 → 数据不全 |
| 2 | 每日有数据的股票数 | 按日计数画曲线 | 应从 3000 涨到 5000，断层 = 缺数据 |
| 3 | 各字段缺失率 | `SUM(col IS NULL)/COUNT(*)` | 财报类缺失高是正常的，行情缺失不正常 |
| 4 | 收盘价 ≤ 0、成交量为 0 | 过滤计数 | 脏数据，会污染收益率 |
| 5 | 单日涨跌幅超板块限制 | 按板块分别设阈值 | 超限 = 复权错/数据错 |
| 6 | 每年「消失」的股票数 | 上年有、下年无 | 应接近真实退市数，为 0 = 幸存者偏差 |
| 7 | **量纲自检** | `close*volume/amount ≈ 1e4` | 对不上 = 单位或复权口径错 |
| 8 | 前复权 vs 后复权收益率 | 两者应一致 | 不一致 = 复权数据错 |
| 9 | 停牌标记 | 停牌日 volume=0？ | 停牌识别错 → 回测能交易停牌股 |
| 10 | 时间戳时区 | 日期是否错位一天 | 时区错 → 全盘未来函数 |

第 7 项最重要，也最容易错：**个股 `volume` 单位是股、`amount` 是万元**，而**指数 `volume` 是手**。
一个数量级错，换手率、资金流、流动性因子全废。详见
[`skills/quantdb-fields/SKILL.md`](../../skills/quantdb-fields/SKILL.md)。

### 4.2 涨跌幅阈值要按板块设

| 板块 | 阈值 | 用 ±11% 一刀切的后果 |
|---|---|---|
| 主板 | ±10% | 正常 |
| 创业板/科创板 | ±20% | 把涨停全算成「异常」，几百条假警报 |
| 北交所 | ±30% | 同上，更严重 |
| ST | ±5% | 漏掉真异常 |

**体检报告必须分板块统计**，否则你会被假异常淹掉，然后放弃体检——这是最坏的结果。

### 4.3 缺失与异常的处理顺序

```
原始数据
  → 剔除明显错误（close<=0、volume<0、重复行）
  → 标记停牌（不是删除，是标记）
  → 复权对齐
  → 缺失值处理（前向填充 / 行业中位数 / 直接剔除，按字段定）
  → 去极值（MAD 或分位数）
  → 标准化（z-score 或 rank）
  → 中性化（行业 + 市值）
```

**每一步都要记录**，否则三个月后你不知道某个因子为什么和别人的不一样。
处理链的代码应该是一个函数，而不是散落在十个 notebook 里。

### 4.4 数据字典模板

```markdown
| 字段 | 表 | 单位 | 口径 | 何时可用 | 缺失率 | 已知问题 |
|---|---|---|---|---|---|---|
| close | daily_forward | 元 | 前复权 | T 日收盘后 | 0.1% | 除权日需对齐 |
| amount | kline | 万元 | 成交额 | T 日收盘后 | 0.2% | 指数是手，别混 |
| pe_ttm | valuation | 倍 | TTM | T 日收盘后 | 8% | 亏损股为负/空 |
| ... | | | | | | |
```

这张表建一次，能用三年。**没有它，你每次读数据都要重新猜单位。**

## 5 回测：它为什么假

### 5.1 时间对齐：一条时间轴定生死

```
T 日 15:00 收盘
   ↓ 用 T 日及之前的数据算信号（只能用 <= T 的信息）
T 日 晚上 / T+1 开盘前 决策
   ↓
T+1 日 开盘或收盘 成交（不能用 T 日收盘价成交）
   ↓
T+1 ~ T+h 持有，标签 = 未来 h 日收益（shift(-h)）
```

三个必须记住的写法：

```python
# ✅ 信号：只用今天及以前
signal = close.pct_change(20)          # T 日已知
# ✅ 成交：T+1
position = signal.shift(1)             # T 日的信号，T+1 才持仓
# ✅ 标签：未来（只用于评估，不能进特征）
fwd_ret = close.shift(-5) / close - 1
```

> **最常见的一种假回测**：`ret = close.pct_change() * signal`——信号和收益同一天，等于用今天的涨跌决定今天买不买。

### 5.2 十二个致命 bug

| # | bug | 后果 | 怎么查 |
|---|---|---|---|
| 1 | 当日收盘算信号、当日收盘成交 | 年化虚高几十个点 | 看有没有 `shift(1)` |
| 2 | `SELECT *` 吃进 `future_return_*` | 模型直接作弊 | 技术指标表里真有这些列 |
| 3 | 只用当前上市股票 | 幸存者偏差 | 看每年股票数是否单调增 |
| 4 | 前复权价当成交价 | 除权日假跳变 | 成交价必须用不复权 |
| 5 | 停牌当可交易 | 虚假成交 | 检查停牌日订单 |
| 6 | 涨停买入/跌停卖出 | 收益虚高 | 统计涨停日买入成交率 |
| 7 | 成本只算单边 | 成本减半 | 对照费用表 |
| 8 | 忽略整手/现金拖累 | 小资金收益虚高 | 小资金必须模拟整手 |
| 9 | 分红送转没处理 | 收益错 | 用前复权收益 |
| 10 | 行业/成分股用当前快照 | 未来函数 | 用历史成分股 |
| 11 | 全样本调参 | 过拟合 | 必须有真 OOS |
| 12 | 用「现在知道」的股票池 | 未来函数 | 股票池按日期构建 |

第 2 条在仓库里是真实存在的坑：`technical_indicators` 表里就有 `future_return_1d` 到 `future_return_60d`。
**一个 `SELECT *` 就能让模型 IC 从 0.03 飞到 0.6**，而且你还会以为自己发现了圣杯。

### 5.4 绩效指标：口径比数值重要

| 指标 | 公式 | 口径陷阱 |
|---|---|---|
| 年化收益 CAGR | `(末值/初值)^(252/天数) - 1` | 用算术平均会高估 |
| 年化波动 | `日收益标准差 × √252` | 样本期短会低估 |
| 夏普 | `(年化收益 - 无风险利率) / 年化波动` | 不扣无风险利率 = 虚高 |
| 最大回撤 | `min(净值/历史最高 - 1)` | 要看水下时间，不只看幅度 |
| Calmar | `年化收益 / |最大回撤|` | 对小样本敏感 |
| 换手率 | `年成交额 / 平均资产` | 单边还是双边，必须说清 |
| 胜率 | 盈利笔数 / 总笔数 | 高胜率 ≠ 赚钱（盈亏比更重要） |

完整定义与例子见 [docs/从回测到因子 §1](../../docs/从回测到因子.md)。

### 5.5 可信回测的最小规格

一条回测要能被别人复现，至少要有：

```yaml
数据: 表名 + 起止日期 + 快照版本
股票池: 构建规则 + 剔除规则（ST/停牌/上市天数/流动性）
信号: 公式 + 用到的字段 + 方向
成交: T+1 开盘/收盘 + 涨跌停/停牌处理 + 整手
成本: 佣金/印花/过户/滑点/冲击 + 最低佣金
组合: 持仓数 + 权重 + 调仓频率 + 约束
评估: 分年收益 + 基准 + 换手 + 回撤 + 成本占比
复现: 一条命令
```

**缺任何一项，三个月后你自己都复现不出来。**
