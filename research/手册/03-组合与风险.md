## 1 从分数到权重：四种方案

### 1.1 四种做法

| 方案 | 权重 | 优点 | 缺点 | 什么时候用 |
|---|---|---|---|---|
| **Top-N 等权** | 前 N 名各 1/N | 稳健、透明、无需估计 | 忽视分数差距 | **默认，90% 的场景** |
| **分数加权** | `w_i ∝ score_i` | 利用排序信息 | 极端分数会集中 | 分数有明确经济含义时 |
| **风险平价** | `w_i ∝ 1/σ_i` | 降低高波动股权重 | 仍需估波动 | 持仓波动差异大 |
| **均值方差** | `max w'μ − λw'Σw` | 理论最优 | 估计误差放大，极不稳定 | 有可靠风险模型时 |

> **忠告**：新手直接上均值方差，结果通常比等权差。因为 `μ` 的估计误差远大于它带来的信息量。
> **先用等权把流程跑通，再考虑优化。**

### 1.2 持仓数 N 怎么定

| N | 单票权重 |  idiosyncratic 风险 | 容量 | 适合 |
|---|---|---|---|---|
| 5–10 | 10–20% | 极高，一只暴雷就重伤 | 小 | 极高确信度、小资金 |
| 15–30 | 3–7% | 中 | 中 | **散户主战场** |
| 40–60 | 2% | 低，接近因子暴露 | 大 | 机构、大资金 |
| 100+ | <1% | 几乎纯因子 | 很大 | 指数增强 |

**规律**：N 越小，α 越集中，但 idiosyncratic 风险越大；N 越大，越像因子组合，α 被稀释。
**A 股散户的甜点区是 15–30 只**，再少就变成赌个股，再多就变成买指数。

### 1.3 有效持仓数

```
HHI = Σ w_i²
有效持仓数 N_eff = 1 / HHI
```

等权 20 只 → HHI = 0.05 → N_eff = 20。
如果前 5 只占了 60% 权重，N_eff 可能只有 8——**你以为分散了，其实没有。**

## 2 约束：每一条都在防一种死法

| 约束 | 典型值 | 防什么死法 | 代价 |
|---|---|---|---|
| **单票上限** | 5% | 单只暴雷 | 限制 α 集中 |
| **行业上限** | 30% | 押注单一行业 | 限制选股空间 |
| **换手上限** | 单期 35% | 成本吃光收益 | 信号滞后 |
| **流动性门槛** | 日均成交额 > 5000 万 | 买得进卖不出 | 排除小盘 α |
| **持仓数下限** | ≥ 15 | 过度集中 | 稀释 α |
| **停牌/ST 剔除** | 强制 | 不可交易 | 缩小股票池 |
| **上市天数** | > 120 日 | 新股异常波动 | 排除次新股 |
| **单日成交占比** | < 10% ADV | 冲击成本 | 限制容量 |

仓库里的融合配置就是这套约束的实例：
[`fusion_config.py`](../../backend/services/engine/services/fusion_config.py)
—— `max_single_weight=0.05`、`max_industry_weight=0.30`、`max_turnover=0.35`，
外加流动性闸门和波动率闸门。

> **约束不是越多越好。** 每加一条，你都在缩小可行域，也在增加「约束本身在拟合历史」的风险。
> 先用 3 条（单票、行业、换手），不够再加。

## 3 组合优化：公式与真相

### 3.1 标准形式

```
maximize    w'μ − λ · w'Σw − c · turnover(w, w_prev)
subject to  Σw = 1
            0 ≤ w_i ≤ u           （单票上限）
            |行业暴露| ≤ b         （行业中性）
            turnover ≤ τ          （换手上限）
            w_i = 0 for 不可交易股
```

- `μ`：预期收益（你的因子分数映射）
- `Σ`：协方差矩阵
- `λ`：风险厌恶系数
- `c`：交易成本系数

### 3.2 为什么它经常还不如等权

| 误差来源 | 后果 |
|---|---|
| `μ` 估计误差 | 优化器会重仓「估计值偏高」的股票，恰好是噪声 |
| `Σ` 估计误差 | 样本协方差在 N > T 时不可逆，求出的权重极端 |
| 约束过拟合 | 约束边界刚好卡在历史上最好的位置 |
| 换手/成本建模误差 | 优化器利用成本模型的漏洞频繁交易 |

**结论**：优化的收益，取决于 `μ` 和 `Σ` 的质量。
**在你的因子 IC 只有 0.03 的时候，`μ` 的信噪比极低，优化器主要在拟合噪声。**

### 3.3 一个务实的中间方案

```
1. 用因子分数排序，取前 N 名（等权）
2. 对权重做行业/单票上限的「事后裁剪」
3. 用缓冲带控制换手
4. 不做均值方差优化
```

这套流程 80% 的场景够用，而且**可解释、可复现、不会突然抽风**。

## 4 风险模型：你到底暴露了什么

### 4.1 三个层次

| 层次 | 内容 | 怎么估 |
|---|---|---|
| **市场 β** | 对指数的敏感度 | 滚动回归 |
| **风格暴露** | 市值、价值、动量、波动、质量 | 多因子回归 |
| **行业暴露** | 申万/中信行业权重 | 直接加总 |

### 4.2 协方差估计：为什么不能用样本协方差

- 5000 只股票，2500 天 → 协方差矩阵 5000×5000，但只有 2500 个观测 → **不可逆**。
- 即使可逆，噪声也极大，优化器会利用噪声。

**三种修法**：

1. **收缩估计**（Ledoit-Wolf）：`Σ_shrunk = (1-δ)·Σ_sample + δ·Σ_target`
2. **因子模型**：`Σ = B·Σ_f·B' + D`（B 是因子暴露，D 是特质风险对角阵）
3. **降维**：只对前 K 个主成分建模

对散户：**用因子模型 + 对角特质风险**就够了，不需要精确的协方差。

### 4.3 风险预算

不要问「每只买多少」，要问「每个风险来源放多少」：

| 风险来源 | 预算 | 说明 |
|---|---|---|
| 市场 β | 0.8–1.0 | 不主动择时就是 1.0 |
| 小市值 | 受控 | 别让市值成为唯一收益来源 |
| 行业 | 中性 ±5% | 除非你有行业观点 |
| 单票特质 | 每只 ≤5% | 防暴雷 |
| 风格动量 | 受控 | 动量崩塌时回撤集中 |

## 5 归因：钱到底从哪来

### 5.1 Brinson 归因（单期）

```
配置效应 = Σ (w_p,i − w_b,i) × r_b,i
选择效应 = Σ w_b,i × (r_p,i − r_b,i)
交互效应 = Σ (w_p,i − w_b,i) × (r_p,i − r_b,i)
```

- **配置**：你超配了哪些行业，对不对
- **选择**：你在行业内部选股，对不对
- **交互**：两者叠加

### 5.2 回归归因（更实用）

```
r_p − r_f = α + β_mkt·(r_mkt − r_f) + β_size·SMB + β_value·HML + β_mom·MOM + ε
```

- `α` 显著 → 真有选股能力
- `β_size` 很大 → 你其实在赌小市值
- `R²` 很高 → 你的收益大部分能被风格解释

**这一步是「α 还是 β」的唯一裁判。** 没做归因就说自己有 alpha，是在自欺。

### 5.3 成本归因

| 项 | 计算 | 典型占比 |
|---|---|---|
| 佣金 | 成交额 × 0.025% | 20% |
| 印花税 | 卖出额 × 0.05% | 25% |
| 过户费 | 成交额 × 0.001% | 1% |
| 滑点 | 成交额 × 滑点率 | 40% |
| 冲击 | 非线性，按参与率估 | 14% |

**成本归因告诉你：优化哪一项最值钱。** 通常是滑点和冲击，不是佣金。

## 6 换手控制：成本的第一道闸

### 6.1 缓冲带（buffer zone）

```
持有排名前 N 名的股票；
只有当排名跌出前 N×(1+b) 时才卖出（b = 20%~50%）；
新买入只补足到 N 只。
```

效果：换手下降 30%~50%，收益几乎不变（因为排名 20 和排名 25 的股票差异很小）。

### 6.2 分批调仓

一次性全换 → 冲击集中。分成 2~3 天执行 → 冲击分散，但暴露时间变长。
**低频策略（月频）用缓冲带 + 单日执行即可；高频才需要分批。**

### 6.3 整手与现金拖累

- 100 股整数倍（科创板 200 股起），买不满的部分留现金。
- 小资金持 20 只，每只 5000 元，高价股（如 300 元）只能买 16 手 = 4800 元，现金拖累 4%。
- **现金拖累在牛市是负收益，在熊市是正收益**——回测必须模拟，否则小资金收益虚高。

### 6.4 换手的三个来源

| 来源 | 占比 | 怎么降 |
|---|---|---|
| 信号变化 | 60% | 缓冲带、拉长调仓周期 |
| 权重漂移 | 30% | 不强制回归等权（设阈值） |
| 整手/现金 | 10% | 减少持仓数、选低价股 |

## 7 容量：策略的物理上限

```
单票容量 ≈ 日均成交额 × 参与率上限
组合容量 ≈ Σ 单票容量（受持仓数限制）
```

| 策略 | 持仓 | 日均成交额 | 参与率 | 单票容量 | 组合容量 |
|---|---|---|---|---|---|
| 大盘低波 | 40 | 5 亿 | 2% | 1000 万 | 4 亿 |
| 中盘多因子 | 30 | 1 亿 | 2% | 200 万 | 6000 万 |
| 微盘轮动 | 15 | 2000 万 | 1% | 20 万 | **300 万** |

**微盘策略的容量，可能只有几百万。** 这不是缺陷，是这类策略的物理属性。
**知道容量，才知道自己能管多少钱；不知道容量，就会在加钱的那一刻失效。**

## 8 组合检验：五个必须看的图

| 检验 | 看什么 | 危险信号 |
|---|---|---|
| **净值曲线** | 与基准对比 | 只有某一段跑赢 |
| **滚动 1 年收益** | 稳定性 | 大部分时间为负 |
| **回撤曲线** | 深度 + 水下时间 | 回撤越来越深、恢复越来越慢 |
| **集中度** | HHI、前 5 权重 | 前 5 占 60% 以上 |
| **风格暴露漂移** | 市值/行业权重随时间 | 悄悄变成小盘/单行业 |

### 8.1 参数敏感性（热力图）

`topk ∈ {10,20,30,50}` × `调仓周期 ∈ {5,10,20,60}`，看年化/夏普/回撤。

**读法**：
- 一片平滑 → 稳健
- 孤立亮点 → 过拟合
- 悬崖 → 策略在边缘上，参数稍变就崩

**绝对不许挑最亮的那一格。** 那是把热力图用成了过拟合工具。

### 8.2 样本外

- 时间切分：前 70% 设计，后 30% 验证
- **验证集只跑一次**，跑完不许改参数
- 衰减 > 50% → 过拟合；衰减 20%~30% → 正常

## 9 案例：两种组合的取舍

| | 低波核心（as26） | 微盘轮动（15 只） |
|---|---|---|
| 持仓 | 40 只 | 15 只 |
| 调仓 | 10 个交易日 | 月度 |
| 选股逻辑 | 低波 + 低 beta + 市值门槛 | 小市值 + 流动性过滤 |
| 年化（2024 回测） | 26.2% | 更高 |
| 夏普 | 1.40 | 通常更低 |
| 最大回撤 | -9.7% | 更深（-25% 以上常见） |
| 容量 | 大（亿级） | 小（千万级以内） |
| 主要风险 | 风格反转 | 流动性枯竭、退市、政策 |

**没有「更好」的策略，只有「更适合你的资金和性格」的策略。**
- 资金大、怕回撤 → 低波/多因子，40 只以上
- 资金小、能扛回撤 → 微盘，但必须接受容量限制
- 两者可以组合：核心（低波）+ 卫星（微盘/事件），按风险预算分配
